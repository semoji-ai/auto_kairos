# proofread

원고가 사실관계 OK라는 전제 하에, **언어 감각·말맛·흐름·반복·표기 일관성**만 점검한다. 읽기 전용. 수정은 PD가 직접.

## Reads
- `drafts/v{n}.md` (기본: 최신)
- (참고) `plan.md` — 톤·화법 결정 기준

## Writes
- (선택) `review/proofread-v{n}-{date}.md` — 점검 노트

## Input resolution
1. **Auto**: 최신 draft + plan
2. **명시 버전 또는 범위**: brief에서 지정 가능
3. **실패**: draft 없으면 종료

## 실행 절차

1. 단락별로 읽으며 다음을 체크:
   - **반복**: 같은 단어·표현이 가까이 반복되어 어색
   - **흐름**: 문장 간 연결이 끊기거나 점프
   - **말맛**: 영상 내레이션으로 읽었을 때 호흡이 끊기거나 어색한 곳
   - **표기 일관성**: 인물명·기관명 표기가 갈리는지(예: "트럼프" vs "도널드 트럼프")
   - **외래어**: 한자·일본어 가나·불필요한 외래어
   - **수동/능동, 시제** 일관성
2. 발견 항목별로 (단락 위치, 원문, 제안)을 decisions에 정리
3. summary는 전체 인상과 개선 우선순위(높음/중간/낮음)

## 금지
- 사실관계 검증(fact-check 책임)
- 원고 자체 수정
- `pd_notebook.md`, `final_manuscript.md` 수정

## 한국어 작성 규칙
- 가타카나/히라가나/한자 금지
- 외래어는 한글 표기 또는 영어
