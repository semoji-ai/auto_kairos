# draft-write

PD가 선택한 경로에 따라 입력이 다르다. 가벼운 영상은 fresh 보고서만으로도 작성 가능하고, 깊은 영상은 wiki 중심으로 작성한다.

## Reads (입력 우선순위)

1. `wiki/index.md` + `wiki/*.md` — **있으면 1차 자료**(깊은 경로)
2. `research_reports/*.md` (kind 무관) — wiki가 없으면 직접 사용(가벼운 경로)
3. `research_targeted/*.md` — 있으면 보완 자료
4. (선택) `plan.md`, `pd_notebook.md` — 톤·기획 의도
5. (선택) `drafts/v{n-1}.md` — 이전 초안에서 출발하는 경우

## Writes
- `drafts/v{n}.md` (n = 기존 최대 + 1)

## Input resolution
1. **Auto**: 위 우선순위로 자동 발견
2. **외부 자료 normalize**: brief에 외부 자료 경로가 있으면 임시로 표준 위치로 복사
3. **Brief 직접**: brief에 톤 가이드와 자료 요약이 충분하면 그것만으로 작성
4. **실패**: 자료가 전무하고 brief도 부실하면 decisions에 사유 명시 후 종료

## 책임 구조
- 1차 라이터 서브 = 외부 책임자(메인은 라이터 한 명만 본다)
- 챕터 워커는 라이터 내부에서만 사용. 라이터가 통합·일관성 책임

## 실행 절차

1. `discover.snapshot` 으로 가용 자료 파악, 경로 결정(wiki 우선, 없으면 research_reports)
2. brief에서 기획 의도, 톤 가이드, 분량, 챕터 구조 확인. 부족 부분은 합리적 기본값으로 가되 decisions에 가정 명시
3. 챕터 분할 후 본문 작성(필요 시 라이터 내부에서 챕터 워커 분기)
4. 통합 후 `drafts/v{n}.md` 저장
5. 200~400단어 요약과 decisions(가정·약점·추가 자료 권장 영역) 반환

## 금지
- `pd_notebook.md`, `final_manuscript.md` 수정
- 원본 wiki/research 변경

## 한국어 작성 규칙
- 가타카나/히라가나/한자 금지
- 외래어는 한글 표기 또는 영어

## 도입(훅) 작성 규칙

영상의 첫 30초는 시청자 보유율을 결정한다. 메타 프레임은 정보 가치 0이고 첫 박자를 낭비한다.

### 금지 — 메타 도입
"지금부터 ~할 거예요"를 알리는 문장으로 시작하지 말 것.
- "질문 하나로 시작합니다 / 시작해 보겠습니다"
- "오늘은 ~에 대해 알아보겠습니다 / 다뤄 보겠습니다"
- "지금부터 ~를 설명드리겠습니다"
- "먼저 ~부터 짚고 가겠습니다"
- "이번 영상에서는 ~"

이런 표현은 시청자에게 "곧 본론이 옵니다"를 알릴 뿐, 본론 자체가 아니다. 분석체 채널에서도 거의 빠져 있다.

### 권장 — 즉시 진입
다음 4가지 중 하나로 첫 줄을 쓴다.

1. **충격 사실 선타격** — 본문에서 가장 회수율 좋은 단일 숫자·사실을 첫 문장으로
2. **명제 선언** — 영상이 도달할 결론을 단언으로 먼저
3. **외부 시선 인용** — 외신·해외 기관·외부자 표현으로 시작
4. **질문 직진** — "질문하겠습니다" 없이 바로 질문

### 자체 검증
초안 완성 후 첫 문단을 점검:
- 첫 문장이 본론인가, 본론을 알리는 메타 문장인가?
- 첫 30초 내레이션 안에 시청자가 외워서 가져갈 단일 숫자·사실·이미지가 1개 이상 있는가?
- "이 영상은 ~를 다룹니다" 류 영상 자기 소개가 들어 있다면, 본문 자체가 그걸 보여주지 못하고 있다는 신호다.
