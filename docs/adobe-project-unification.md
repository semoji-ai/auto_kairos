# 어도비 패널과 v3 프로젝트를 하나로 — 사본을 없앤다

> **결정 (2026-08-22)**: 디아지오 편을 끝낸 뒤에 착수한다.
> 그전까지는 v3 에서 그림을 고칠 때마다 어도비로 옮기고, 옮겼다고 보고한다.

---

## 무엇이 문제인가

분기는 **렌더 단계에서만** 일어나야 한다 — 리모션으로 뽑을지 애프터이펙트로
뽑을지. 그런데 지금은 **프로젝트가 통째로 복제**된다.

```
output/f772e15c_…          v3 프로젝트 (scene_specs.json, images/, audio/)
        │
        │  v3_import.py — shutil.copy 가 9군데
        ▼
adobe/projects/7184ea44/   완전히 독립된 사본 (scenes.json, storyboard/, audio/)
```

`AK_PROJECTS_ROOT` 가 `adobe/projects` 를 가리키고, 어도비 백엔드는 자기
스키마의 `scenes.json` 을 읽는다.

| | 필드 |
|---|---|
| v3 에만 | `imageAsset` · `infoStructure` · `items` · `headline` · `cast` · `chapter` · `beat` |
| 어도비에만 | `imageRef` · `image_prompt` · `visual_summary` · `videoRef` |
| **양쪽에** | `sceneId` · `sceneNumber` · `narration` · `title` · `layout` · `mood` |

**마지막 줄이 화근이다.** 같은 값이 두 파일에 저장되니 언제든 갈린다.

### 실제로 터진 것

잔 모양을 고쳐 v3 에서 9씬을 다시 뽑았는데 패널에는 옛 그림이 그대로였다.
패널이 보는 사본은 **01:31 에 복사된 것**이고 고친 그림은 **13:38** 이었다.
21씬을 손으로 옮겨 맞췄다.

옮기면서 **109·110·112 를 되돌릴 뻔했다** — 그 셋은 패널에서 안경을 지운
쪽이 더 최신이라, v3 판으로 덮으면 그 작업이 날아간다. 확인하고 되돌렸다.
**손으로 옮기는 한 이 위험은 매번 있다.**

## 어떻게 고치나 — 필드마다 주인을 하나로

사본을 두지 않고 **같은 폴더를 보되, 필드마다 주인을 정한다.**

| 무엇 | 주인 |
|---|---|
| 나레이션 · 제목 · 레이아웃 · items · 프롬프트 | `scene_specs.json` |
| 선택된 그림 | `images/image_assets.json` 의 `selected` |
| TTS 텍스트 · 자막 텍스트 · 비디오 · 레이어 메타 · 테마 | `adobe_state.json` (어도비 전용 사이드카) |

`AK_PROJECTS_ROOT=output` 으로 돌리고, `scenes.py` 가 셋을 읽어 합쳐 내놓고
쓰기는 주인에게 보낸다.

```
scene_specs.json ─┬─ 리모션 렌더
                  └─ 어도비 패널 → AE 조립
```
