# SEMOJI 기능 이식 — 프리셋 개방, 출처 자막, 도구 구역

작성일: 2026-08-15
대상: `backend/motion.py`, `backend/schemas/motion_plan.schema.json`, `backend/manifest.py`,
`backend/srt.py`(신규), `backend/router.py`, `cep/com.autokairos.pd/jsx/build_scene.jsx`,
`cep/com.autokairos.pd/jsx/tools.jsx`(신규), `cep/com.autokairos.pd/js/storyboard.js`,
`cep/com.autokairos.pd/index.html`

전제: 평면 컴프 전환(2026-08-15-flat-comp)이 끝나 있다. 컴프는 `Final` 하나,
씬은 `S{번호}_` 접두사 그룹, 씬마다 가이드 널이 있다.

출처: 사용자가 만든 AE 스크립트 패널 `SEMOJI_TOOL_1.57`(SMB 공유의 448줄 jsx).
버튼 7개 중 까딱까딱은 이미 `bob`으로 있고, 일러배치(씬 배치·가이드 페어런팅)는
평면 전환이 흡수했다. 남은 것을 이식한다.

## 결정 1 — 모션 프리셋을 레이어 종류별로 개방한다

지금 `motion.py`는 LLM 출력을 `{"bob", "fade_in"}`으로 전역 강제하고 캐릭터에만
모션을 준다. 스키마와 jsx는 8종을 구현해 두고 안 쓴다.

레이어 종류별 허용 목록으로 바꾼다.

| 종류 | 허용 프리셋 |
|---|---|
| 인물(character) | `bob` `zoom_emphasis` |
| 사물(object) | `slide_in` `fade_in` `pop` `drift` `shake` `zoom_emphasis` `exit_fade` `stamp` `wiggle` |
| 배경(bg) | 없음 — 카메라가 담당 |

**인물에 fade를 넣지 않는 이유:** 기존 규칙 "캐릭터는 오퍼시티 키프레임 금지"가
`manifest.py`에 있다(`_char` 레이어의 fade류를 걷어내고 `noFade`를 단다). 허용
목록에 넣어도 걷히므로 처음부터 빼서 LLM이 낭비하지 않게 한다. 매니페스트의
걷어내기는 안전망으로 유지한다.

LLM 프롬프트도 바뀐다 — "인물에만"이 아니라 인물·사물 각각의 허용 목록과 원칙을
준다. 사물 모션의 원칙: 등장(slide_in/pop/stamp)은 씬 앞부분, 강조(zoom_emphasis/
shake/wiggle)는 내레이션의 해당 시점, 퇴장(exit_fade)은 씬 끝. 기본은 "모션 없음" —
모든 사물에 모션을 주지 않는다.

`kinds`가 없는 구버전 분리는 지금처럼 이름의 `_char` 접미사로 인물을 가른다.

## 결정 2 — 신규 프리셋 `stamp`·`wiggle`

SEMOJI의 도장효과·위글위글이다. 스키마 enum과 jsx `applyMoves`에 더한다.

**`stamp`(도장):** 레이어가 300% 크기·투명 상태에서 5프레임 만에 제 크기·불투명으로
내리찍힌다. 동시에 복제 효과로 원래 스케일의 2배로 퍼지며 30프레임 동안 사라지는
잔상을 만든다 — SEMOJI는 레이어를 복제했지만, 우리는 결정적 빌드라 복제 레이어가
재빌드 청소를 복잡하게 하므로 **잔상을 생략하고 내리찍기만** 구현한다(스케일
300→100 + 오퍼시티 0→100, 5프레임, easy ease). `amount`는 시작 배율(기본 300).
캐릭터에는 오퍼시티 금지 규칙이 있으나 stamp는 사물 전용이라 충돌하지 않는다.

**`wiggle`(위글):** Position에 `wiggle(freq, amp)` 익스프레션. `amount`가 진폭
px(기본 8), 주파수는 1Hz 고정. 익스프레션은 레이어 수명 전체에 걸린다 — 구간
제어가 필요하면 나중에 시간 조건을 더한다(범위 밖).

`PRESET_GUIDE`에 두 줄을 더해 LLM이 알게 한다.

## 결정 3 — 출처 자막

씬에 `source` 문자열이 있으면(v3 지도 임포트가 이미 넣는다) 화면 우하단에 출처
표기를 그린다. SEMOJI 출처자막의 구조를 따른다.

- 검정 판(불투명도 60) + 흰 텍스트. 판 폭은 텍스트 폭 + 50px을 따라가는
  익스프레션(SEMOJI 그대로), 높이 50px 고정.
- 위치: 우하단, 여백은 컴프 폭의 3%(1920 기준 57px).
- 폰트·크기: 테마 토큰의 `subtitle` 폰트, 크기는 24px 기준(`S` 배율 불필요 —
  평면 컴프는 항상 1920×1080).
- 레이어 이름 `S{번호}_출처`(텍스트)·`S{번호}_출처판`(셰이프). 접두사가 있으므로
  재빌드 시 함께 지워지고 다시 만들어진다.
- **가이드 널에 페어런팅하지 않는다.** 카메라 줌이 출처 표기까지 키우면 안 된다 —
  화면에 고정된 정보다. in/out은 씬 구간.
- `manifest.py`가 씬 엔트리에 `source`를 싣는다(현재는 버려진다). 빈 문자열이면
  싣지 않는다.

## 결정 4 — 패널 도구 구역과 `tools.jsx`

패널 하단에 접이식 "도구" 구역을 만든다. AE 안에서 손으로 쓰는 보조 기능이며,
빌드 파이프라인과 무관하게 현재 AE 상태에 작용한다.

### SRT 가져오기

외부에서 만든 SRT 자막을 `Final`에 넣는다. 파이프라인 자막(TTS 타임스탬프)과
별개의 수동 경로다.

- 패널의 파일 선택(`<input type="file">`)으로 SRT를 읽어 **백엔드로 보낸다**:
  `POST /api/tools/srt-parse`, 본문 `{"srt": "<내용>"}` → `{"cues": [{"start": s,
  "end": s, "text": "..."}]}`. 파싱을 백엔드에 두는 이유는 pytest로 검증하기
  위해서다.
- 파서는 SEMOJI의 결함을 고친다: SEMOJI는 시작 타임코드만 읽어 **마지막 자막
  길이가 0**이었다. 종료 타임코드를 읽어 각 큐가 자기 종료 시각을 갖는다.
  큐 사이 공백은 그대로 둔다(다음 큐 시작으로 늘리지 않는다).
- 파서 규약: `HH:MM:SS,mmm`(쉼표)와 `HH:MM:SS.mmm`(마침표) 둘 다 받는다. 번호
  줄이 없거나 깨진 블록은 건너뛰고 나머지를 살린다. 여러 줄 텍스트는 `\n`으로
  합친다. BOM·CRLF를 정리한다.
- jsx `akImportSrt(cuesJson, tokensPath)`가 `Final`에 텍스트 레이어
  **`가져온자막`** 1장을 만들고 Source Text 키프레임으로 큐를 찍는다 —
  `subtitle_layers.jsx`와 같은 1레이어 방식(577레이어 사태의 교훈). 스타일은
  테마 토큰의 자막 스타일. 같은 이름 레이어가 있으면 지우고 다시 만든다.
  파이프라인의 `말자막`과 이름이 달라 서로 건드리지 않는다.

### 널 끼우기

SEMOJI NULL추가 그대로. 선택한 레이어와 그 부모 사이에 널을 끼우고 계층을
보존한다. `akInsertNull()` — 선택 레이어가 없으면 안내 문구를 돌려준다.

### 선택 레이어에 프리셋 적용

드롭다운(프리셋 9종)에서 골라 선택 레이어들에 건다. `akApplyPreset(type, amount)` —
각 레이어의 `inPoint`를 시작으로 하고 길이는 프리셋 기본값(등장류 0.5초, 강조류
0.8초, wiggle은 익스프레션이라 무기한). `tools.jsx`가 자체 구현한다 —
`build_scene.jsx`의 `applyMoves`는 `akBuildScene` 클로저 안이라 밖에서 못 부르고,
수동 적용은 매니페스트 좌표·씬 시각이 없는 단순 버전이 맞다. 위치·스케일 기준값은
레이어의 현재 값이다.

`tools.jsx`는 `json2.jsx`와 함께 로드한다(패널의 기존 방식 — `readLocal` 이어붙여
`evalScript`).

## SEMOJI에서 가져오지 않는 것

- **기본세팅의 부위 페어런팅** — 캐릭터 부위 분리는 별도 설계(범위 밖).
- **도장효과의 잔상 복제본** — 결정적 재빌드와 충돌, 내리찍기만.
- **일러배치** — 평면 전환이 이미 흡수(씬 In/Out은 TTS 누적, 페어런팅은 가이드 널).
- **버튼 8·9·10** — SEMOJI에서도 빈 버튼이다.

## 오류 처리

| 상황 | 처리 |
|---|---|
| SRT에 유효한 큐가 하나도 없음 | 422 `{"error": "유효한 자막 큐 없음"}` |
| SRT 블록 일부가 깨짐 | 그 블록만 건너뛰고 나머지 파싱 |
| 프리셋 적용 시 선택 레이어 없음 | "레이어를 선택하세요" 반환, 예외 없음 |
| 널 끼우기 시 선택 없음 | 동일 |
| `source`가 빈 문자열/공백 | 출처 자막을 만들지 않는다 |
| LLM이 허용 밖 프리셋을 냄 | 종류별 허용 목록으로 걸러낸다(지금의 필터 확장) |

## 테스트

pytest로 검증한다.

- 종류별 필터: 인물에 낸 `slide_in`이 걸러지고 `bob`은 남는다. 사물에 낸 `stamp`·
  `wiggle`이 남고 `bob`은 걸러진다. 배경에 낸 모션은 전부 걸러진다.
- 스키마 enum에 `stamp`·`wiggle`이 있고 LLM 출력이 검증을 통과한다.
- SRT 파서: 정상 2큐, 마지막 큐가 자기 종료 시각을 갖는다(0이 아니다), 쉼표·마침표
  타임코드, 깨진 블록 건너뛰기, 여러 줄 텍스트, BOM·CRLF, 빈 입력 → 빈 목록.
- 엔드포인트: 정상 200, 큐 없음 422.
- 매니페스트: `source`가 실리고 빈 값은 안 실린다.
- jsx는 정적 구조 검사: `stamp`·`wiggle` 분기, `S{번호}_출처` 생성과 가이드
  미페어런팅, `tools.jsx`의 세 함수, ES5.

**자동 검증이 안 되는 것:** AE에서의 실제 동작(이 맥에 AE 없음). 도장의 타격감,
위글의 진폭, 출처 자막의 위치·판 폭 익스프레션, SRT 키프레임 타이밍은 테스터 PC에서
확인한다.

## 범위 밖
