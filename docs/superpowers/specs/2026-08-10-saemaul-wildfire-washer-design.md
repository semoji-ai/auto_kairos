# 〈잿더미 앞에 세탁기 35대가 도착한 이유〉 — 콘텐츠 설계

- 작성일: 2026-08-10
- 클라이언트: 새마을운동중앙회
- 형태: 세모지 계열 롱폼 애니메이션, **5분** (나레이션 약 1,400자, 씬 25~35)
- 시리즈: 「한 사람의 위기 → 지역 공동체 → 중앙회 연결 구조 → 존립 이유」 공식의 1편

---

## 1. 이 콘텐츠가 증명하려는 것

재난이 나서 사람을 모으는 조직은 늦습니다.
이 조직은 재난 전부터 마을에 있었습니다.

결론은 "새마을이 좋은 일을 했다"가 아니라 **"왜 이런 조직이 존재해야 하는가"** 입니다.
세탁기 35대는 그 논증의 증거이지 자랑거리가 아닙니다.

---

## 2. 시점 — 사람이 아니라 사물

**세탁기와 세탁차의 이동 경로를 따라갑니다.** 특정 이재민 개인을 주인공으로 세우지
않습니다.

### 왜 개인 서사를 접었나

자료 조사 결과 **이재민 개인의 세탁 관련 인터뷰·수기가 존재하지 않습니다.**
없는 사연을 지어내면 두 가지가 무너집니다.

1. 신뢰도 — 2025년 실제 재난이고 피해자가 생존해 있습니다
2. 논증 — 지어낸 할머니 한 명은 감정을 만들지만 **구조를 증명하지 못합니다.**
   이 기획의 결론은 "평소에 연결돼 있었다"인데, 개인 서사로는 그게 안 보입니다

대신 **사물 경로가 곧 조직도**입니다.
"부산에서 출발한 세탁차가 왜 안동 임하면에 있었나"라는 질문 하나가
계통 조직 전체를 화면으로 끌어냅니다. 창작 0, 재현 배지 0입니다.

감정 이입은 개인 대신 **숫자와 사물**로 만듭니다 — 3,318명 대부분 어르신,
"핸드폰도 못 들고 나왔다", 개어서 돌려주는 침구.

## 3. 확보된 사실

### 중앙회 활동 (2025.4.4)

| 항목 | 내용 |
|---|---|
| 규모 | 20억 원 상당, 의류 22,000벌 + 세탁기 35대 |
| 지역 | 경북 안동·의성·영양·청송·영덕, 경남 산청 — **6개 시군** |
| 설치처 | 임시 대피소로 쓰인 **마을회관·경로당** |
| 세탁기 중 5대 | **전국청년새마을연합회** 추가 지원 |
| 세탁차 | **부산시새마을회** 제공 이동식 세탁차량 |
| 현장 | **안동시 임하면 복지회관** 임시대피소 — 의류·침구 수거 → 세탁·건조 → 재전달, 4월 6일까지 |
| 참여 | 김광림 회장, 회원단체장, 새마을지도자, **대학 새마을동아리** 등 20여 명 (전달식 당일) |
| 전국 | 11개 시도·31개 시군구, 지도자 2,600여 명 — 성금·물품 + 세탁·청소·배식 |

### 배경 (제3자 자료 — 자화자찬 방지용)

- 이재민 **36,878명**, 주택 **3,766채** — 단일 산불 최대 피해
- 4월 1일 기준 대피소 잔류 **3,318명, 대부분 고령**
- 대피 증언: **"나올 때는 핸드폰도 못 들고 나왔어요"**
- **이철우 경북지사: "식량 위주 구호물품을 옷·생필품·이불 등으로 바꾸겠다"**
  → "왜 세탁이었나"를 행정 책임자가 대신 증언. **이 영상의 핵심 외부 근거**
- 희망브리지 배분 계획에 **"세탁구호" 2억 원** 별도 편성

### 조직

- **법정단체** — 「새마을운동조직 육성법」 근거. 1980년 설립,
  2000년 현 명칭 + UN NGO 가입, 2011년 4월 22일 '새마을의 날' 국가기념일
- **계통 조직** — 중앙 → 시도지부 → 시군구지회 → 읍면동협의회 → 마을
- **회원단체** — 새마을지도자협의회, 새마을부녀회, 직장·공장협의회, 새마을문고 (법 명시 4개)
  + 청년연합회, 대학 새마을동아리 등
- **규모 감각** — 부산시새마을회 한 곳만 회원 22만여 명, 새마을지도자 12,838명
- **변천** — 1970년대 마을 길·지붕 개량 → 생명살림·나무심기 → 지구촌새마을운동
  (2010년까지 103개국 5만여 명 교육)

### 확인 필요 / 미확보

- 중앙회 보도자료 원문 (사이트 접근 차단 — 중앙회에서 직접 수령 필요)
- 현장 사진·영상 원본
- 1990년대 전환기 세부 (국가기록원 원자료 확인 필요)
- 회장 변경: 2018년 정성헌 → 2025년 김광림. **2025년 시점만 언급**

### 순서에 담긴 설계 의도

**0:15에 불을 꺼 버린다.** 보통의 재난 영상은 불길에 시간을 쓰지만, 이 영상은
"불이 꺼진 다음부터가 본론"이라고 15초 만에 선언합니다. 그 선언이 곧 차별점이고,
제목의 "잿더미 앞에"도 그때 성립합니다.

**④를 3분대에 둔다.** 시청자가 "부산 세탁차가 왜 안동에?"라는 의문을 품은 직후여야
조직 설명이 **답**으로 들립니다. 앞에 두면 회사 소개, 뒤에 두면 결론과 겹칩니다.

**⑤가 ④보다 뒤다.** 구조를 이해한 눈으로 다시 보는 세탁 장면은 "봉사 활동"이 아니라
**"구조가 작동하는 장면"** 이 됩니다. 같은 화면이 두 번째에 다르게 읽히도록 짰습니다.

## 5. 1970년대 이미지 처리

새마을운동은 관제 운동 이미지가 강합니다. 안 꺼내면 시청자가 속으로 꺼냅니다.
**먼저 말하되, 단절이 아니라 연속으로 말합니다.**

```
❌ "1970년대에 멈춰 있다고 생각하시겠지만, 2025년 4월 그 조직이 안동에 있었습니다"
   → 화자가 밖에서 구경하는 말투. 남 얘기가 된다

✅ "마을 길을 넓히던 조직이 나무를 심고, 다른 나라 마을을 돕는 조직이 되었습니다.
    하는 일은 계속 바뀌었습니다. 바뀌지 않은 것은 마을마다 사람이 있다는 것 하나입니다."
   → 이어져 온 변화. 그리고 이 문장이 곧 세탁차가 안동에 온 이유
```

별도 구간을 만들지 않고 ④의 첫머리에서 15초 안에 처리합니다.

## 6. 에셋 방침

**사람은 일러스트, 사물·숫자는 실물.** 프로젝트 규칙은 실물 우선이지만 이번은
현장 보도사진에 신원이 드러나는 이재민이 찍혀 있어, 홍보 성격 영상에 쓰면
초상권과 윤리가 걸립니다.

| 대상 | 처리 | 근거 |
|---|---|---|
| 이재민·봉사자 | **generate** + `일러스트 재현` 배지 | 신원 보호 |
| 불길·잿더미 마을 | **generate** | 실제 피해 가옥 특정 회피 |
| 세탁기·이동식 세탁차 | **search 우선** (중앙회 제공 자료), 없으면 generate | 사물이라 문제없음 |
| 숫자·지도·계통도 | 그래픽 | 36,878 / 3,766 / 35 / 22,000 / 2,600 / 6 |
| 도지사 발언, 육성법 | 인용 카드 | 외부 근거임을 화면에 명시 |

### 재난 재현의 선

- 인명 피해(26명 희생)는 **숫자로만.** 장면으로 그리지 않습니다
- 우는 얼굴·오열 없음. 감정은 사물로 — 개어 놓은 이불, 같은 옷, 비닐봉지에 담긴 빨래
- 불길은 ①-a 한 컷뿐. 재등장 없음

### 계통도는 아래에서 위로 그린다

마을 → 읍면동 → 시군구 → 시도 → 중앙 순으로 쌓아 올립니다.
위에서 내려오게 그리면 **하달 구조**로 읽혀 이 영상이 하려는 말과 정반대가 됩니다.
