# 중국어판 지도 자체 심의 (2026-10-26)

대상: B053 코카콜라 2편 190.6~197.7초 세계지도(원본 `21 세계지도` footage 1324225412) → `episodes/B053/assets/zh/world_map_cn.png`
방식: 사용자 결정(A안) — 원본 그림체(국경선 없는 파란 단색)를 유지하고 중국 영토 표현만 중국 관점으로 다시 그림. 중국 《地图管理条例》상 공개 지도는 원칙적으로 送审 대상이므로, 공식 심의 대신 아래 항목을 자체 점검해 통과한 경우에만 사용한다.

## 근거 데이터
- Natural Earth 10m admin-0 **worldview CHN** (`ne_10m_admin_0_countries_chn`) — 대만·장난(藏南)·악사이친·西沙·南沙·钓鱼岛가 중국에 속함
- 黄岩岛(Scarborough Reef)는 데이터상 별도 항목 → 중국 섬과 같이 표시
- 남해 단속선 10단(남해 9단 + 대만 동쪽 1단): 대략 위치를 스크립트에 고정(`scripts/cn_world_map.py` DASHES). 지도 축척 약 3px/도라 1도 안팎 오차는 화면에서 구분되지 않음
- 원본 지도와의 정합: 정거원통 투영, 육지 모양 IoU 0.878
