# B052·B053 코카콜라 1·2편 중국어판 — 중국 관점 수정안 (초안 v1, 2026-10-25)

원칙: 출처 확인된 사실만. 소문(蝌蚪啃蜡·蒋彝 공모)은 "据说/坊间流传"으로만. 대만·中华民国 국호·청천백일기 노출 금지, 홍콩은 "经香港"처럼 지명으로만(국가 나열 금지). 1949년 철수는 중립 표현("新中国成立后退出中国大陆").

## B053 (2편) — 교체 삽입 구간

### 한국전쟁 대목 교체 (원래 257~265초, n074~n075)
원래: "1950년 6월 25일 한국전쟁 발발, 미군과 함께 코카콜라가 우리나라에 들어옴" → 중국 대륙 플랫폼 민감 + 한국 시청자 관점. 아래 장면으로 교체(zh_inserts `china`).

### 문장 단위 수정 (번역 단계에서 반영)
- n053~054 "1920년대까지 중국, 홍콩, 필리핀…": 홍콩을 국가처럼 나열하지 않게 → "到1920年代，可口可乐已经走进中国、菲律宾、中美洲和欧洲。"
- n077 "하루 평균 19억 잔, 1초에 2만 1990만 잔"(원문 수치 오류) → "可口可乐公司旗下饮料，每天在全球被饮用约22亿杯" (2025 10-K, 회사 전체 음료 기준)
- n079 "글로벌 브랜드 가치 5위" → "在2025年Interbrand全球品牌榜上排名第七" (가치 601억 달러)
- n027 "(약 5,800만 원)" → 원화 환산 삭제
- 끝(n205 이후, 선택): "在中国，从2001年起，每到春节，可口可乐的广告里还会出现一对泥娃娃——阿福和阿娇。" — 그림은 일반 춘절 장식만(阿福 캐릭터 형상권 분쟁 이력 → 재현 금지)

## B052 (1편) — 문장 단위 수정
