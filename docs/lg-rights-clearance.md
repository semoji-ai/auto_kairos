## 화면에서 확인하는 법

협의가 끝나지 않은 자료는 렌더 화면 오른쪽 아래에 **붉은 글씨**로 뜹니다.

```
협의 필요 · 연합뉴스        ← 아직 못 나감 (빨강)
출처: 국가기록원             ← 정리 완료 (흰색 40%)
```

협의가 끝나면 원장의 `license`를 `owner_cleared`로 바꾸고 `python3 scripts/build_rights.py`를 다시 돌립니다.
