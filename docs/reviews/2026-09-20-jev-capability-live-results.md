## 혼합 후보와 입력 구조

5개 과제에서 최대 40개를 요청했지만 실제 수집된 최초 후보는 **35개**입니다. 실험 태그 `mixed40`/`opaque40`은 요청 상한을 가리키며 실제 후보 수가 아닙니다. 주제가 다른 후보들을 섞은 뒤 선택했고, ID의 주제명 힌트를 제거한 R001… 형식으로도 5개 과제 모두 해당 주제 자료를 골랐습니다. 이는 관련 후보군을 구분한 결과이며 최상의 사진 선택·사용권·팩트 정확도 100%를 뜻하지 않습니다.

주제명이 포함된 ID로 순서를 뒤집은 실험에서는 QCIM·모션의 최상위 후보가 바뀌었습니다. 익명 ID 통제는 과제당 한 번만 실시하여 순서 안정성을 추가 입증하지 못했습니다. 후보 순서에 강건하다는 결론은 낼 수 없습니다.

기존 간단 문장형 입력에서 흔들린 4개 과제(J09 편 배정, J28 의미 회귀, J42 레이어 묶음, J26 소구점)는 목적·관찰·후보를 구분하고 판단 기준을 구체화한 사후 시험에서 8/8 잠정 기대 선택을 반환했습니다. 구조만이 아니라 지시문 내용·일부 입력 길이도 함께 바뀌었고 같은 사례를 재사용했습니다. 원인을 구조 하나로 확정하거나 독립 검증 성적으로 합산하지 않습니다.
