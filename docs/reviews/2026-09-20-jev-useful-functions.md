# Jev 실효성 후보 기능 전체 목록

2026-09-20. 앞선 실험 결과에 근거한 도입 후보 분류이며 기존 방식보다 품질/시간이 개선됐음을 입증한 목록은 아닙니다.

A: 실제 자료와 도구를 연결해 좁은 범위의 동작을 확인. B: 통제 사례/계획 인터페이스에서 가능성을 확인, 실제 업무효과는 미검증. C: 판단 변화·정보 부족·라벨 모호성으로 제한적인 검토 보조만 후보이며 자동 확정은 보류. A도 운영 도입 완료나 최종 품질 보증을 의미하지 않습니다.

실제 레퍼런스 흐름에서 확인한 세부 동작: 검색어 후보 선택, 검색결과 열람 우선순위, 문서/이미지 후보 선택, 시각 관찰을 반영한 보완 검색어 선택, 재검색 실행 연결, 명시적 종료 기준에 따른 검색 종료, 관련 후보가 전부 없을 때 none 선택. 세부 동작은 아래 기존 기능과 겹치므로 별도 신규 기능 수로 더하지 않습니다.

이미지·음성·영상 관련 기능은 인식 도구가 전달한 관찰이나 메타데이터가 필요합니다. Jev가 픽셀/음성을 직접 평가한 성과로 해석하지 않습니다. 모션 프리셋·카메라 계획은 스키마 연결까지 확인했으나 렌더 품질은 확인하지 않았습니다.

효과가 아직 검증되지 않은 확장: 영상 레퍼런스의 실제 움직임 비교, 스타일 일관성/미적 선호, 썸네일 클릭률 예측, 실제 청취 품질 판정, 저작권 사용허가 확정, 성과 원인의 인과 추론.
