# Jev 전 영역 실효성 검증 결과

2026-09-20. 사용자 요청: 60개 기능에 실효성을 확인할 실험을 설계하고 실행.

**60개 기능 모두에 실험 설계·실행 기록·평가를 남겼습니다. 다만 모든 기능의 실효성을 확인한 것은 아닙니다.** J04 조사 우선순위, J56 시청자 피드백, J57 성과 학습은 필요한 실제 데이터가 없어 결측 대응만 시험했으며 본기능 검증으로 세지 않았습니다. 나머지도 통제 변형이나 제한된 대리 과제가 섞여 있습니다. 범위 한계를 항목별로 보존했습니다.

판정: **좁은 실효성 확인 1개 / 조건부 기능 근거 29개 / 추가가치 미입증 27개 / 본기능 자료 부족 3개**. 조건부는 “도입 효과 입증”이 아니라 명시된 작은 과제에서 유용한 선택이 가능했다는 뜻입니다.

이번 라운드 **348호출·448판단**, 입력 391,630토큰, Jev 추정비용 **$0.016448**. API 중앙값 0.539초, 95백분위 0.611초. 전체 파이프라인 시간이나 Codex 비교자의 비용을 포함하지 않습니다. 추가 검색/이미지/TTS 생성 API 호출은 없고, 보관된 자료를 사용해 FFmpeg 프리뷰6개를 렌더했습니다.

## 실험이 이전과 달라진 점

- BTQ 실제 원고·브리프·개정 이력, 원료의 시간/Diageo/Hynix 씬과 배포안, 실제 검색 썸네일16개, BTQ 음성·문자 정렬, 자막·실패 로그를 사용했습니다. 실험을 위한 변형은 원본과 구분했습니다.
- 사례/잠정 기대답을 API 호출 전에 동결하고 기본·선택지역순으로 반복했습니다. 반복은 독립 사례가 아닙니다.
- 첫 후보·키워드·저장 결정이라는 약한 기준선 외에, **정답과 Jev 결과를 보지 않은 다른 Codex 세션**이 같은 입력을 판단했습니다. 별도 사람 평가가 아니며 현재 운영 에이전트 전체를 재실행한 비교도 아닙니다.
- 모델이 틀린 것과 시험 정답이 잘못된 것을 분리했습니다. 같은1819년 브로라 씬을 새장면으로 정답 처리한2건은 제외했고, 없는1999년을 인용한 자막결함 입력도 감사에 기록했습니다. 원점수를 조용히 고치지 않았습니다.

## 가장 분명한 실효성: 관찰을 활용하는 이미지 레퍼런스 선택

실제 검색 썸네일16개를 직접 관찰하고 다음6목적을 시험했습니다: 건물+해안, 방문객+위스키잔, 실제 손+식품포장+마트, 읽을 수 있는 날짜, 일러스트 구도, 모든 조건을 함께 만족하는 후보 없음. 각 목적에 동일 후보를 정순/역순/섞기3조건으로 제공했습니다.

| Jev + 제목/출처/이미지URL | 6/18 반복판단 | 나머지는 정보 부족으로 none. 무관 이미지를 강제로 고르지 않은 보류도 있음 |

## 모션·음성·자막·배포에서 확인한 것

- 기존 이미지3개로 고정/확대2종, 총6개2초 프리뷰를 렌더했습니다. 확대 시 건물 꼭대기·인물 발·화면 오른쪽 인물이 더 잘리는 것을 표본 프레임에서 확인했습니다. “피사체 잘림 금지” 조건의 카메라 선택은 보조할 수 있지만 자연스러운 모션·연출 선호를 검증한 것은 아닙니다. FFmpeg 대리 렌더이며 Remotion 원래 모션 프리셋 렌더가 아닙니다.
- BTQ 정렬598문자는 입력과 일치했고 정렬 끝57.77초와 실제MP3 57.771247초의 차이는 약0.00125초였습니다. 이는 코드가 잘하는 검사입니다. 실제 발음·호흡·자연스러움은 청취 검증하지 않았습니다.
- 저장 배포안의 SK 인수 타임스탬프0:17과 저장 음성 구간 합산37.538초가 다릅니다. 편집 버전 차이일 수 있으므로 최종 렌더와 대조가 필요합니다. Jev의 청취 발견으로 포장하지 않았습니다.
- 제목/카드에서 HBM의 범위를 보존하도록 명시한 사후 후보선택과 잘못된 자막결함 입력 수정은6사례·2순서=12/12 잠정 일치했습니다. 사후에 제약을 구체화한 시험이며 독립 일반화 성능으로 기존 점수에 더하지 않습니다.

## 큰 모델과의 연계

오퍼스·페이블·아스트라·솔 등 큰 모델을 호출할 수 있는 실행 환경이 있다면, 모델별 호출부 뒤에 같은 텍스트/JSON 계약을 두고 Jev를 연결할 수 있습니다. 특정 모델 이름의 독립 공개 API 존재나 현재 저장소에서의 연결 완료를 전제하지 않습니다. 이번에 실제 검증한 조합은 Codex 관찰/후보/기준 작성 + Jev 선택입니다. 네 모델 간 품질/비용 비교는 미실행입니다.

| 담당 | 역할 |
|---|---|
| 큰 모델 | 목적 해석, 원문/이미지/영상/음성 분석, 후보·수정안 생성, 복잡하거나 애매한 판단 검토 |
| Jev | 전달받은 텍스트/JSON에 근거한 관련성 분류, 조건 충족 후보 선택, 없음/추가관찰/재검색 같은 제한된 다음 행동 선택 |
| 코드/실행기 | 검색·파일·렌더·합성 도구 실행, 상태 저장, 시간/길이/좌표 계산, 예산·권한·반복 횟수 제한 |

예시 흐름: 큰 모델이 씬 요구와 후보를 만들기 → 검색 도구가 자료 확보 → 시각 인식 가능한 모델이 실제 이미지를 관찰 → Jev가 조건에 맞는 후보를 추리기 → 충돌·정보 부족은 큰 모델 검토 → 실행기에서 후속 작업. Jev가 직접 원고/이미지를 생성하거나 자유로운 근거 설명을 하는 모델로 가정하지 않습니다.

저비용 분류가 가능한 큰 후보군에는 Jev를 먼저 사용해 상위 모델에 전달할 자료를 줄일 수 있습니다. 모든 항목을 매번 큰 모델과 Jev에 모두 보내면 비용/시간 절감이 사라질 수 있습니다. 관찰 결과는 저장·재사용하고, 후보가 부족하거나 판단이 불안정할 때만 상위 검토를 요청하는 방식이 적합합니다. confidence 수치만으로 검토 생략을 결정할 만큼 보정 성능을 검증하지 않았습니다.
