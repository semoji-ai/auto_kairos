# Jev 기존 래칫 평가 및 평가의 신뢰성 검토

2026-09-20. 결론: **큰 서사 붕괴를 찾는 보조 판단에는 가능성이 있지만, 재미의 미세한 개선과 최종 래칫 통과를 결정하는 평가자로 대체하기에는 이번 결과가 부족합니다.** 실제 API 실험을 완료했으며 운영 코드와 원고는 변경하지 않았습니다.

## 기준과 입력

- 실제 저장소 [manuscript-reviewer](../../auto_agent/data/skills/agents/manuscript-reviewer/SKILL.md)의 원고 100점: 시청자 50 + 문체·구조·정합성 50.
- [script-reviewer](../../auto_agent/data/skills/agents/script-reviewer/SKILL.md)의 시청자 100점: Hook, 깊이, 근거, 인과, 재미·몰입, 이해도, Flow, Pacing, Payoff, 이탈 위험. 이 두 평가표를 합산하지 않았습니다.
- 기준 문구와 배점을 추출해 Jev의 정수 선택형 질문으로 옮겼습니다. 각 항목 0~배점, `unknown` 허용. 세부 점수별 행동 기준은 없는 실험용 변환이므로 기존 LLM 채점과 완전히 동일한 도구는 아닙니다.
- 블로킹 게이트 5개와 브리프 감점 6개도 별도로 판단시켰습니다. 이 부분은 원문 규칙의 요약·적용 질문이며 전체 운영 평가 실행을 재현한 것은 아닙니다.
- 원고만 제공했습니다. 영상 연출·실제 음성·해당 버전에 대응하는 TTS 측정·outline·활성 문체 스킬 전문은 제공하지 않았습니다. 영상 호흡과 연출의 실효성을 검증했다고 해석하면 안 됩니다.
- 동일한 현재 editorial brief와 claims ledger를 공급하고, 승인된 쇼츠의 장편 접속사 빈도/챕터 비율 예외를 명시했습니다. 이전 버전명과 점수는 숨겼습니다.

| 익명 ID | 원고 | 성격 |
|---|---|---|
| A | user_manuscript_candidate_01 | 사용자 최초 초안 |
| B | manuscript_candidate_03 | 수정 원고 |

원본 경로는 `output/0a58cdad_btq_quantum_shorts/reviews/`. [manifest](../../experiments/jev_ratchet_20260920/manifest.json)에 경로와 SHA256을 기록했습니다. A의 과거 점수83, B의91은 당시 증거·브리프·TTS 조건이 달라 정답으로 쓰지 않았습니다. C의 현행 리뷰는 PENDING_REVIEW이며 91점을 승계할 수 없습니다.

## 수행한 실험

1. A~D 각각 기본 평가, 동일 요청 반복, 질문과 선택지 순서 역전: 12회.
2. A/C 및 C/D 선호 비교를 양방향 순서로 수행: 4회.
3. 게이트 및 감점 평가: 4회.
4. 발견된 흔들림을 분리하기 위해 C에서 질문 순서만 역전, 선택지 순서만 역전, 증거 ledger 제거: 3회. 이 추가 실험은 탐색적 후속 실험이며 독립 검증 세트가 아닙니다.
5. 동일 입력을 Jev 결과 없이 Claude Opus 구독 CLI로 독립 평가. 최초 응답이 A만 반환하여 제외하고, A~D 필수 JSON schema를 적용한 재시도로 완성했습니다. 최초 결과도 보존했습니다.

Jev 모델 `jev-1.13.0`: **23회 호출, 329개 판단, 입력 296,365토큰, 추정 $0.01244733**. 기존 클라이언트의 $0.042/백만 입력토큰 계산이며 청구서 대조 금액은 아닙니다. 주요 16회 호출 중앙 지연0.831초. Opus CLI의 비용 필드는 최초$0.315183 + 완성$0.389445 = $0.704628로 표시되지만 구독 호출의 사용량 환산값이며 별도 API 실결제액이 아닙니다. 이 서로 다른 작업량으로 비용 절감 배수를 주장하지 않습니다.

## 재현성과 평가의 타당성

- 동일 요청 반복: 76개 채점 항목 중66개 동일(unknown 포함). 양쪽 숫자가 있는60개 항목 평균 절대 변화0.233점, 최대3점. 판단 가능/불가 전환은0개였습니다. 소계는 안정적이어도 개별 Hook가7→10으로 변해 미세 래칫에는 문제가 남습니다.
- 질문+선택지 역순: 76개 중32개 동일. 판단 가능/불가 전환9개. 공통 숫자60개 평균 변화0.95점, 최대4점. 배점이 서로 다른 원시 점수 변화이며 정확도 지표가 아닙니다.
- 최약 문단: 각 원고의 세 조건 모두 같은 문단을 선택했습니다(A p8, B p9, C p3, D p6). 반복 안정성은 확인됐지만, Opus가 고른 문단은 각각 p3, p3, p8, p1으로 달랐습니다. 안정적인 선택이 곧 정확한 진단이라는 뜻은 아닙니다.
- 실제 A/C 비교: Jev는 두 순서 모두C, Opus는A를 선호했습니다. 정상 원고 사이의 재미 우열을 일치시켰다고 할 수 없습니다. Opus도 정답은 아닙니다.
- C/D 비교: 두 모델 모두C 선호. Jev는 두 순서 모두C를 선택했고, D의 시청자 Hook를0점으로 평가했습니다. 명백한 전개 붕괴 탐지는 성공한 사례입니다. 합성 통제본1개이므로 보편 성능을 뜻하지 않습니다.
- Jev와 Opus의 공통 숫자60개 평균 절대 차이2.25점. 같은 축에서 다른 점수 척도를 쓰는지, 한쪽이 틀렸는지는 이 수치만으로 알 수 없습니다.

### 평가자 자체에서 발견한 문제

**Jev의 문체0점 일괄 판정:** 모든 원고 기본 평가에서 문체를0/15로 처리했습니다. 문체 전문이 없고 쇼츠 빈도 예외가 명시된 입력에서 확정적인0점을 주는 근거는 확보되지 않았습니다. 장편 수치 기준을 과잉 적용했을 가능성이 있으나 Jev가 자유서술 근거를 반환하지 않아 원인을 확정할 수 없습니다. 입력 완전성과 예외 우선순위 처리를 먼저 개선해야 합니다.

**게이트 간 판단 혼입 의심:** G5(수치·고유명사 근거)는 C에서pass, D에서fail입니다. D는 첫 훅을 빼고 문단을 재배치했으며 새로운 사실 주장을 추가하지 않았습니다. 흐름 악화가 증거 게이트에 섞였을 가능성이 있어 이 판정을 자동 반려에 쓰기 어렵습니다. 문맥 변경에 따른 의미 변화 여부는 별도 검토 대상입니다. G1/G2/G4는 전부unknown인데, 일부는 프롬프트에서 입력 부족을 명시했으므로 모델이 독자적으로 결손을 발견한 성공 사례로 세지 않습니다.

**증거 결손 반응:** C의 데이터 정합성 질문에서 ledger를 제거하고 브리프 앵커도 미검증이라고 표시하자unknown을 반환했습니다. 적절한 보류 사례지만 증거 제거와 명시적 설명을 함께 바꾼 실험입니다.

**Opus도 완전한 심판이 아님:** 최초 요청은4개 중1개만 반환했고, 수정된 출력 schema로 재시도해야 했습니다. 완성 응답은 원문에 기반한 비교 설명을 줬지만 일부 한국어가 깨지고, 실제 영상 없이도 Pacing7/7/7/5점을 줬습니다. 이는 텍스트 대리 추정이며 실제 영상 호흡 검증으로 받아들이지 않았습니다. 초기와 재시도 사이 프롬프트·effort가 달라 두 응답을 동일 조건 재현성 검사로 사용할 수도 없습니다.

**기존 rubric 정비 필요:** script-reviewer 전문가 표는 섹션 소계와 개별 배점 합계가 어긋나며 개별 항목 합은110입니다. 이번에는 시청자100점 부분만 사용했고 전문가 전체 총점으로 확장하지 않았습니다.

## 운영 판단

- **시험적으로 활용할 범위:** 검토할 문단 후보를 좁히기, 큰 인과 단절·훅 붕괴 신호, 사람이 확인할 비교 후보 만들기. 아직 검증된 정확도로 간주하지 않습니다.
- **현재 대체하지 않을 범위:** 재미1~2점 향상 판정, 최종90점 통과, unknown의 자동 실패 처리, 근거 없이 문단 삭제·수정 결정. 최종 재미·연출·개선 방향은 Codex/Claude 리뷰를 유지하는 편이 타당합니다.
- **다음 검증 설계:** 별도 주제의 실제 수정 전후30쌍 이상을 확보하고 사람 편집자가 먼저 블라인드 선호와 근거를 기록합니다. 점수별 구체 기준을 정의하고 활성 문체·예외·영상 정보의 공급을 맞춘 뒤, 숫자 정밀 채점과 `개선/유사/악화/판단 불가` 비교 방식을 비교합니다. 순서를 균형 배치해 반복하고, 미세 개선 역전·근거 없는 실패·보류율과 실제 LLM 재검토 시간까지 측정해야 합니다. 평가 대상에 보지 않은 주제를 남겨 일반화 여부도 확인합니다. 이 후속 대규모 검증은 이번에 수행하지 않았습니다.

단일 BTQ 주제의 실제3개+합성1개 실험이며, 실제 시청자 반응·시청 지속률과 대조하지 않았습니다. 결론은 **현재 질문 변환 방식의 Jev를 래칫 최종 심판으로 채택할 근거가 부족하다**는 것이며 Jev의 모든 구성에서 재미 판단이 불가능하다는 뜻은 아닙니다.
