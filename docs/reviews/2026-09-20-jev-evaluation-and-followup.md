## 다음 실험 설계: 실제 자료와 결과물 기준

1. **소재 발굴:** 실제 채널의 과거 채택/미채택 소재를 같은 기간에서 수집하고, 시의성·기존 영상 중복을 가린 상태에서 현재 선택자와 비교합니다. 채택 이유가 다른 경계 사례를 포함합니다.
2. **기획·시리즈:** 원본 브리프와 실제 인터뷰 응답에서 필수 조건을 추출하고, 별도 검토자가 편 배정/범위/추가 질문의 허용답을 확정합니다. 필요한 정보가 없는 사례를 포함합니다.
3. **자료 수집·볼트:** 저장된 검색결과와 볼트 문서를 그대로 사용해 중복·보완·무관을 비교합니다. 검색 순위 그대로 사용하는 기준선과 유용 자료 상위 5개 비율을 비교합니다.
4. **근거·조사 전략:** 같은 실제 원문에서 지지/모순/미언급 주장을 구성하되, 출처를 유지한 채 숫자·범위·주체만 바꾼 어려운 사례를 추가합니다. 집필 가능 여부는 주장별 근거 충족률로 평가합니다.
5. **원고 구성·표현:** 같은 실제 원고에서 기존 작성자가 만든 3개 수정 후보를 익명화해 선별하고, 사람이 의미 보존·가독성·길이를 독립 평가합니다. 후보 전체 미달 조건도 넣습니다.
6. **래칫·수정:** 실제 수정 이력에서 테스트넷/운영망·예정/완료·일부/전체 변경을 추출해 검토자가 라벨링합니다. 변경 없는 문장을 같은 수만큼 넣고 미탐·과잉 경보를 나눕니다.
7. **씬·화면 구성:** 실제 씬 10개 이상에서 같은 시각화 후보를 기존 선택자/Jev가 고르게 합니다. 선택 이유 텍스트가 아니라 화면 시안과 흐름을 익명 비교합니다.
8. **캐릭터·자료·에셋:** 같은 인물의 시점/복장/외형 변형과 실제 이미지 후보를 준비합니다. 관찰 없는 군과 시각 관찰을 준 군을 비교하고, 완전 일치·부분 참고·사용 불가를 분리합니다.
9. **레이아웃·모션·조립:** 같은 씬에 대해 레이어·카메라·모션 후보 계획을 만든 뒤 짧은 미리보기를 렌더합니다. 접촉 깨짐·중복 줌·화면 밖 이탈과 연출 선호를 분리 평가합니다.
10. **음성·자막·제작 흐름:** 기존 실제 TTS 구간과 원고·ASR·청취 관찰을 활용합니다. 발음/호흡/자막/원고 문제를 균형 있게 배치하고, 재합성 후 개선 여부까지 확인합니다.
11. **배포·멀티포맷:** 같은 완성 영상에서 제목·썸네일·쇼츠 구간·카드 후보를 비교합니다. 내용 정합성과 독립 이해도를 먼저 평가하며 실제 클릭률 효과는 별도 실험으로 남깁니다.
12. **성과 학습·운영 제어:** 실제 실패 로그와 사람의 복구 이력을 재생합니다. 행동만 제안하는 모드로 현재 규칙과 비교하고, 종료·재시도·다른 도구 선택의 적절성을 평가합니다.
