## 그래서 v5는 v3의 이름 정리다

```
로컬 폴더   auto_kairos_v3  →  auto_kairos
원격        semoji-ai/auto_kairos          ← 이미 그 이름이다
버전        5.0                            ← v4 번호는 건너뛴다
adobe       adobe/ 로 흡수 (git subtree, 이력 보존)
v4          실험 갈래로 동결. 쓸 것만 뽑아 온다
```

v4 번호를 건너뛰는 이유 — v4는 갈라졌다가 되돌아온 갈래다. 그 번호를 다시 쓰면
어느 v4인지 헷갈린다.

## v4에서 흡수할 것

**하나뿐이지만 값어치가 크다.**

### ① 발 축 까딱을 CSS로

`projects/f793a99b/remotion/src/Scene.tsx`가 이렇게 한다.

```tsx
transformOrigin: "50% 100%",
transform: `scaleY(${1 + Math.sin(sec / period * 2π) * amp * 0.5})`
```

**`transformOrigin: 50% 100%` 한 줄이 발 고정을 대신한다.** 오늘 파이썬에서는
알파 채널 최하단을 훑어 발 위치를 찾고 회전축으로 썼는데, 브라우저는 그걸
공짜로 해 준다. 레이어 아래쪽이 곧 발이므로 계산이 필요 없다.

### ② 렌더 경로로서의 Remotion

오늘 파이썬 렌더가 564프레임에 8분 걸렸다. 프레임마다 SVG를 다시 그려서다.
Remotion이면 브라우저가 그리므로 훨씬 빠르고, **쇼츠 자동화로 바로 이어진다**.

지금 12편이 DB에 물려 있어 이관 비용이 크다. `AK_PROJECTS_ROOT`로 폴더를 공유하는
것만으로 adobe 연동은 된다.

### 레이어 분리는 시드림 5.0으로 확정

옛 방식(`scene_layer_v2.py`·`split_characters.py`)은 **codex imagegen으로 캐릭터를
다시 그려** 분리했다. 다시 그리는 순간 얼굴이 흔들린다 — 편 전체 인물 일관성을
어렵게 만든 원인 중 하나였다.

시드림 5.0 `layerize`는 **원본을 그대로 쪼갠다.**

| | 옛 방식 | 시드림 5.0 |
|---|---|---|
| 인물 | 다시 그림 → 얼굴 흔들림 | 원본 픽셀 그대로 |
| 좌표 | 연결요소 크롭 — 겹치면 한 덩어리 | **bbox를 API가 준다** |
| 배경 | 따로 생성 | **인페인팅된 배경판 포함** |
| 가려진 부분 | 없음 | **가려졌던 하반신까지 복원** |

EP03 씬 41에서 인물 bbox가 작업대 아래 `y=860`까지 내려왔다 — 상판에 가려져
보이지 않던 다리를 시드림이 그려 넣었다. 그래서 순서만 바로잡으면 자연스럽게
작업대 뒤에 서게 된다.

v3의 옛 스크립트 둘에도 대체 표시를 달았다. 옛 프로젝트 호환용으로만 남긴다.

## 순서

1. **`Scene.tsx`의 발 축 방식을 v3 렌더에 반영** — 가장 싸고 확실한 이득
2. **Remotion 씬 렌더러에 카메라·SVG 레이어 지원 추가** — 오늘 파이썬으로 한 것을 옮긴다
3. **adobe를 `adobe/`로 subtree 이관** — 이력 보존
4. **로컬 폴더명 정리 + 5.0 태그**
5. **v4 동결** — README에 「실험 갈래, v5로 흡수됨」 명시

1~2가 실익이고 3~5는 정리다. **먼저 1~2를 하고, 쇼츠 자동화가 실제로 도는 것을
본 뒤에 이름을 바꾼다.** 이름부터 바꾸면 되돌리기 어렵다.
