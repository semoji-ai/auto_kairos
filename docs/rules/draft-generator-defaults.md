## 2. 단어 큐 (모든 연출 시점의 기준)

- timing.json 의 씬마다 `words: [{w, start, end}]`(어절 단위, 챕터 음성 기준 초).
  키워드 시각은 `auto_agent/tools/word_timing.find_cue(words, "키워드")`. — **구현**
- 등장 시점 = 그 대상을 부르는 단어의 시작. 템플릿 고정 타이밍·씬 시작 기준 금지.
  - 연결 화살표: 단어 −0.1s · 화살표 라벨: 화살표 +0.075s
  - 음성에 없는 보조 정보(괄호 환산값): 본 수치 단어 +0.4~0.5s
  - 말자막 전환: 단어 글자 시작 −0.03s
- 짧은 씬(2~3초)은 모션을 빨리 끝내고 컷 전 0.4~0.6s 여유. 씬 끝을 넘는 등장 키 금지.
- 정지 레이어 조립에서는 `--cues` 로 요소 레이어 in 을 단어 프레임에 맞춘다. 못 맞춘 큐는
  `<out>.cues_report.json`. — **구현**(정지 레이어 in 점까지). 모션 키는 미구현.

## 4. 기준점(anchor) — 가운데 기본값 금지

| 요소 | 기준점 |
|---|---|
| 대사 말풍선 | 말하는 인물 쪽 꼬리 끝, 화자에게 parent |
| A→B 화살표 | 출발점(꼬리) |
| 카드+화살표 묶음 | 화살표 끝(가리키는 대상) |
| 허브→가지 카드 | 화살표 닿는 변 |
| 바닥에 선 건물·사물 | 알파 bbox 하단 중앙(바닥 접점) |
| 라벨 | 가리키는 대상 쪽 가장자리 |

상태: 미구현. elements.json 에 `kind`·bbox 가 있으니 `object`(바닥 접점)부터 옮길 수 있다.

## 5. 등장·숨쉬기 상수

| 항목 | 값 |
|---|---|
| 뿅 | 0.27s, 스케일 0→110→97→100% |
| 같은 종류 순차 | 읽는 방향(왼→오, 위→아래), 0.07~0.08s 간격 |
| 선(연결선·지시선) | 뿅 금지 → 페이드 또는 트림 그리기 |
| 숨쉬기 | 발 기준점, 세로 ±0.9%, 회전 ±0.4°, 인물마다 위상 다르게 |
| 한 그림 여러 인물 | 반 박(0.167s) 엇갈림 |
| 흔들림 상한 | 회전 ±0.5°, 주기 2.4s 이하, 상체만(하체·주변 사물 고정) |
| 화면 밖 진입 | 씬 시작부터 켜 두고 화면 밖 완전 대기(≥400~1200px), 출발 키 선형·착지 이즈 |

상태: 미구현(모션 생성기). `layerize_scenes.py` 가 인물 이름에 `motion: "bob"` 만 표시한다.

## 6. 카메라

- 정적 씬: 줌 100↔110%, 패닝은 108% 에서 ±60px(좌우)·±45px(상하). 2~4%·30~40px 금지(어중간).
- 고정 씬: 패턴 배경+액자 사진, 인포그래픽·도식, 원인→결과 비교.
- 방향은 그림 구도(길·소실점·열린 하늘 쪽). 감정 씬 = 얼굴 쪽 줌인(~185%).
- 줌 공식: 대상 (X,Y), 배율 s → 카메라 널 = (960 − (X−960)(s−1), 540 − (Y−540)(s−1)).
- **±2씬 같은 무빙·같은 연출 금지** — `scripts/check_repetition.py <project>` 로 보고. — **구현(보고만)**

## 7. 효과음

- **모션을 만들 때 효과음까지 한 세트로** 넣는다(나중에 키프레임 이벤트로 자동 배치하면 표현식
  모션·새 레이아웃이 빠진다). 씬당 3~4개 이하, 연속 뿅은 첫 하나만, 텍스트마다 소리 금지.
- 레벨: Hollow pop·뽁 −4dB, 반짝 −16dB, Swoosh −18dB, Soft Slide −10dB, SE014 −12dB, 도장 −3dB.
  프리컴프 바깥 레이어 Audio Levels 에서. 상태: 미구현.
