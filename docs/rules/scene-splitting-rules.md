# 씬 나누기 규칙 — 한 씬은 한 화면이다

> LG 1편을 174씬으로 다시 나누며 세운 기준이다. 이 편은 나누기 전에
> **65씬 · 평균 77자**였고, 한 씬에 서로 다른 장면이 서너 개씩 들어 있어
> 화면이 말을 따라가지 못했다. 나눈 뒤 **평균 29자**가 됐다.

---

## 0. 순서를 지킨다

```
① 원고를 고친다        말만 고친다. 씬 경계는 건드리지 않는다
② 문장으로 쪼갠다      원고 전체를 문장 단위로 편다
③ 앞뒤를 보고 배분한다  붙일지 가를지 문장마다 정한다
④ 화면을 정한다        재연·도해·실물·지도 + 컷 관계·크기·인물
⑤ 그림을 물려준다      있는 그림을 실제로 보고 다시 붙인다
⑥ 모자란 것만 그린다
```

**①과 ②를 한 번에 하면 안 된다.** 원고를 고치면서 씬 경계까지 정하면
지금 경계에 갇힌 채 말을 다듬게 된다 — 순서가 거꾸로다.

**④를 ①보다 먼저 하면 안 된다.** 말이 바뀌면 화면 판단의 전제가 통째로
달라진다. 그림을 먼저 그려 놓으면 원고를 고치기가 아까워진다.

---

## 1. 나누는 기준은 「화면이 바뀌는가」다

**무조건 나누는 것이 아니다.** 순서는 이렇다.

```
① 모든 문장을 목록에 담는다        파이썬으로. 원고가 새지 않게
② 앞뒤 문장을 보며 정한다          묶을지 나눌지
```

①은 사람이 눈으로 훑지 않는다. 문장을 하나도 빠뜨리지 않으려고 기계에
맡기는 단계다. 판단은 전부 ②에서 한다.

### 나누는 자리 — 화면이 달라져야 할 때

```
장면이 달라진다        때 · 곳 · 주체가 바뀐다
앵글이 달라져야 한다    같은 자리라도 크기나 각도가 바뀌어야 말이 산다
표현이나 타입이 바뀐다  재연 → 도해 · 실물 자료 · 인용 · 반전 카드
```

**세 가지 중 하나라도 걸리면 나눈다.** 걸리지 않으면 앞뒤와 묶는다.

### 묶는 자리 — 혼자 설 수 없을 때

**가리키는 사물이나 동작이 있는가**를 본다. 없으면 **앞이나 뒤에 붙인다.**

```
선다      종업원은 스무 명 남짓
          기계는 그해 8월 무렵에야 들어왔습니다
          상인들은 공장 앞에 줄을 섰습니다

안 선다   확실한 것은 이겁니다 · 중요한 건 하나입니다
          순서가 흥미롭습니다 · 문제가 있었습니다
          이런 말이 있습니다        ← 다음 말을 여는 문장
          실제로도 그랬습니다        ← 앞을 받기만 하는 말
          ~한 게 아니었습니다        ← 부정문
          ~했다면 ~했을 겁니다       ← 가정문
```

**부정문과 가정문이 특히 그렇다.** 그림은 하지 않은 일을 그릴 수 없다.
무엇을 했는지가 이웃 문장에 있으므로 함께 두어야 화면이 선다.

**앞이냐 뒤냐**는 답을 어느 쪽이 들고 있는지로 정한다.

```
「확실한 것은 이겁니다」          → 뒤가 답을 들고 있다
「실제로도 그랬습니다」            → 앞을 받는 말이니 앞에 붙인다
```

이때는 **길이를 보지 않는다.** 혼자 설 수 없는 것이 먼저다.

### 붙일 때 지킬 것

- **뒤가 반전 카드면 카드에 붙이지 않는다.** 카드는 한 마디로 홀로 서고,
  뒤집을 내용이 **앞에** 있어야 한다. 카드를 건너뛰고 그 다음에 붙인다
- **연쇄로 붙이지 않는다.** 이미 무언가를 받은 씬에 또 붙이면 한 씬이
  200자까지 자란다 — 나누기 전보다 나빠진다. 한 번만 붙인다

### 길이는 나중 기준이다

같은 장면을 이어 말하는데 문장이 짧으면(각각 25자 안팎) 한 호흡으로 묶을
수 있다. 다만 **묶어서 60자를 넘기지는 않는다.**

```
값은 깎아 주지 않았습니다. 대신 자를 속이지 않았죠.
```

**혼자 설 수 없어 묶는 경우는 이 길이 규칙을 따르지 않는다.** 그건 리듬이
아니라 화면이 서느냐의 문제다.

### 그릴 컷 수는 목표가 아니다

씬을 묶어 그릴 컷을 줄이려 하지 않는다. 그릴 것이 많으면 그리면 된다.
묶는 이유는 **화면이 서지 않아서**이지 품을 아끼기 위해서가 아니다.

---

## 2. 반전 접속사는 독립 씬이다

「그런데」·「하지만」·「그러나」가 흐름을 뒤집는 자리에 오면 **떼어 낸다.**
말에 묻어 두면 그냥 지나가지만, 흰 화면에 한 마디로 띄우면 그 순간이 보인다.

```
씬 A   여기서 보통 상인이라면 재고부터 줄였을 겁니다.
씬 B   그런데,                        ← 흰 화면, 1.2초, 타이핑
씬 C   지금 물에 잠긴 시장이 아니라, 물이 빠진 뒤의 혼례집을 본 겁니다.
```

- 화면 글자는 쉼표 없이 「그런데」
- **음성은 넣되 쉼표를 붙인다** — 「그런데,」. 소리가 있어야 끊긴 느낌이 산다
- 1.2초. 빠르게 넘어가고 다음 화면이 이어받는다

### 떼면 안 되는 자리

접속사 뒤에 **조사가 붙으면** 접속사가 아니다. 「그때까지는 말입니다」의
「그때」를 떼면 「까지는 말입니다」라는 말이 안 되는 문장이 남는다.
접속사 뒤에 **빈칸이나 쉼표**가 와야 뗀다.

편당 3~7회가 적당하다. 스무 번이 넘으면 장치가 눈에 띈다.

---

## 3. 챕터는 씬이 들고 다닌다

여러 챕터를 한 묶음으로 나눌 때, 묶음 하나의 챕터를 전부에 찍으면 원고의
챕터가 뭉개진다 — 실제로 113씬이 전부 챕터0이 된 적이 있다.

> **씬마다 제가 온 곳의 챕터를 들고 다닌다.**
> 반영할 때도 씬이 들고 온 값이 먼저고, 없으면 원본의 챕터, 그다음이
> 묶음의 챕터다.

챕터 경계는 **챕터 카드**다. 카드 앞은 도입부(0).

---

## 4. 번호는 함부로 새로 매기지 않는다

이미지는 **씬 번호로** 묶여 있다(`image_assets.json`). 음성은 **sceneId**로
묶인다. 번호를 새로 매기면 그림이 통째로 어긋난다.

```
1:1   원래 번호를 그대로 쓴다 → 그림이 저절로 따라온다
합침  첫 번호를 쓰고, 합쳐진 다른 씬의 그림은 후보로 얹는다 (버리지 않는다)
쪼갬  첫 조각이 원래 번호를 갖고, 나머지는 새 번호(700번대)를 받는다
      원래 씬에 그림이 여러 장이면 나눠 갖고, 모자라면 「그려야 함」으로 남긴다
```

**그림 파일은 지우지 않는다.** 항목만 옮긴다.

한 씬에서 갈라진 조각들이 **같은 그림을 물려받으면 화면이 되풀이된다.**
원본에 여러 장이 있으면 나눠 갖게 한다.

---

## 5. 다시 쓰면서 뺀 씬은 실제로 지운다

제안 파일에서 문장을 지워도 씬은 그대로 남는다. 원본을 손대지 않는 구조라
그렇다 — 다섯 씬을 뺐다고 생각했는데 일곱 씬이 화면에 그대로 있었다.

`apply_rewrite.py --drop-missing` 을 쓴다. 제안이 다룬 챕터 안에서 어느
항목도 가리키지 않는 씬을 지운다.

---

## 6. 나눈 뒤에 반드시 세어 본다

```
평균 글자 수        30자 안팎
60자 넘는 씬        한 자릿수
두 문장 이상인 씬   한 자릿수
반전 카드           편당 3~7
같은 프롬프트를     0
나눠 가진 씬
혼자 못 서는 씬     0    ← 그려 보면 「말이 화면에 없음」으로 걸린다
```

마지막 항목은 세어서 알 수 없다. **그려서 봐야 걸린다** —
그림마다 「① 사람 수가 맞는가 ② 말이 화면에 보이는가」를 묻는다.

LG 1편: 나누기 전 65씬 · 평균 77자 · 60자 초과 43 → 나눈 뒤 174씬 ·
평균 29자 · 60자 초과 3.
