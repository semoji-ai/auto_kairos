# 연출 레시피 — 통한 방식을 이름 붙여 남긴다

규칙은 「하지 마라」를 적는다. 여기는 반대다. **실제로 화면에서 통한 방식**을
이름 붙여 모아 둔다. 다음 편에서 비슷한 자리를 만나면 처음부터 다시 궁리하지
않는다.

레시피는 **쓸 자리**와 **쓰지 말 자리**를 함께 적는다. 좋은 방식도 아무 데나
쓰면 버릇이 된다.

---

## 도장 — 판정을 화면에 꽝 찍는다

붉은 둥근 네모 안에 판정 한 마디를 넣어 대상 위에 겹친다.

```
말풍선(손자 증언)  ┃확인불가┃      서류철(사료 조사)  ┃확인불가┃
```

**도장이 찍혔다는 것 자체가 「해 봤다」는 뜻이다.** 그래서 「확인 시도」니
「둘 다 조사했지만」이니 하는 설명이 필요 없어진다. 글자 두 줄이 사라지고
화면이 한 문장이 된다.

### 쓸 자리

- **견줄 대상을 두고 판정을 얹을 때** — 이것이 본령이다.
  대상이 둘 이상 나란히 있고, 그 각각에 같은(또는 다른) 판정이 붙는 자리.
  「이쪽은 되고 저쪽은 안 된다」가 도장 색과 글자만으로 읽힌다
- 결과가 **한 마디로 떨어질 때** — 확인불가 · 승인 · 반려 · 폐기 · 완료
- 「없음」을 보여야 할 때 — 빈 칸을 따로 두면 앞의 대상들이 붕 뜬다.
  **찾아본 것들 위에 직접 찍는 편**이 낫다

### 쓰지 말 자리

- 대상이 하나뿐일 때 — 견줄 것이 없으면 그냥 라벨이다
- 판정이 한 마디로 안 떨어질 때 — 문장을 도장에 넣으면 읽히지 않는다
- 잇달아 나올 때 — 두 씬 연속 도장이면 장치가 눈에 띈다

### 만드는 법

요소는 **도장 없이** 그린다(말풍선·서류철·문서). 도장은 렌더러가 얹는다 —
`marks` 에 `style: "stamp"`. 이미지에 구우면 글자를 고칠 수도, 어도비에서
옮길 수도 없다.

```json
{"text": "확인불가", "left": 30, "top": 50, "style": "stamp", "size": 40}
```

어도비로 넘어가면 **붉은 둥근 네모 셰이프 + 텍스트 레이어** 둘로 올라간다.
글자도 자리도 그쪽에서 바꿀 수 있다.

## 계단 — 등급을 대각선으로 보인다

칸이 비스듬히 내려오는 계단 하나를 그리고, 칸마다 하나씩 올린다.

```
사   ▀▀
농      ▀▀
공          ▀▀
상              ▀▀
```

세로로 쌓으면 겹쳐 보이고 아래가 잘린다. 계단은 **대각선이 곧 순서**라
「내려앉는다」는 말이 화면에 그대로 있다.

### 쓸 자리

신분·직급·단계처럼 **순서가 있는 여러 항**. 그중 하나가 어디에 놓이는지가
내용일 때 특히 좋다.

### 만드는 법

계단과 사람을 **한 덩어리 그림 하나**로 그린다. 요소를 따로 올려 계단 위에
맞추려 하면 어긋난다. 글자는 칸 옆에 `style: "label"` 로 하나씩 놓는다.

## 같은 것 여럿 — 배수를 눈으로 센다

「다섯 배」는 **똑같은 물건이 다섯 개** 있어야 읽힌다. 하나를 그려 놓고
`×5` 라고 적으면 글자를 읽어야 안다.

```
궤짝 하나        →     궤짝 다섯
구인상회 자본금         이번에 들어간 돈
```

기준이 되는 하나를 왼쪽에 두고, 오른쪽에 같은 그림을 그 수만큼 늘어놓는다.
**같은 에셋을 되풀이해 쓴다** — 다른 그림을 쓰면 배수가 아니라 종류가 된다.

## 환산 — 앞 씬의 숫자를 끌고 온다

「쌀 844가마」만 있으면 얼마나 큰지 모른다. **앞 씬에서 나온 돈**을 화면
왼쪽에 두고 `=` 로 잇는다.

```
지폐 세 뭉치   =   쌀가마 산더미
3,800원            쌀 844가마
```

기호는 **화면 안에** 둔다. 제목에만 적으면 화면은 그냥 나열이다.
