# 세모지 원고 문체 및 스토리텔링 스타일 가이드

> 13개 세모지 원고(삼성 1~8, 아디다스 1~2, 포드 1~2, 스팸)를 분석하여 도출한 가이드.
> Writer 에이전트의 시스템 프롬프트에 삽입하여 세모지 채널 톤을 재현하는 데 사용한다.

---

## 1. 문체 특징

### 1-1. 어조 및 존칭
- **기본 어체**: 합니다체(~입니다/~했습니다/~됩니다)가 메인 톤. 정보 전달 시 신뢰감 부여.
- **친근한 높임말 혼용**: ~었다고 합니다, ~라고 합니다, ~인데, ~이었습니다 등 서술 높임말을 유지하면서도 딱딱하지 않게 구어체 느낌 가미.
- **절대 금지**: 해라체(~했다, ~이다)는 사용하지 않는다. 반말, 명령형도 없다.
- **간접 대화**: 인물의 말을 직접 인용할 때만 반말/해라체가 등장한다.
  - 예: 박정희는 "자식이 아버지를 모함하고 고발한다는 것은 천륜에 어긋나는 일이야."라고 지시했다고 합니다.

### 1-2. 문장 길이 패턴
- **1~2문장 단위 줄바꿈**이 기본. 각 줄이 나레이션(씬) 하나에 대응한다.
- **짧은 단문(5~15자)**과 **중간 길이 서술문(30~50자)**이 교대로 출현하여 리듬감을 만든다.
- **긴 문장은 슬래시(/)로 분절**: 원고 내에서 슬래시는 화면 전환 또는 나레이션 호흡 단위를 의미한다.
- **3문장 이상 같은 길이가 연속되면 안 된다**: 짧은-중간-짧은 또는 중간-짧은-긴 순으로 변화를 준다.

### 1-3. 종결어미 순환 패턴
같은 종결어미가 3회 이상 연속되지 않도록 의식적으로 순환한다:
1. **격식 단정**: ~입니다 / ~했습니다 / ~됩니다 / ~이었습니다
2. **친근 전달**: ~었다고 합니다 / ~이라고 합니다 / ~았습니다 / ~인데
3. **공감 확인**: ~었던 겁니다 / ~인 거죠 / ~이기 때문입니다
4. **마침표 단문(여운)**: "바로 스팸입니다." / "그것이 바로 중앙일보입니다." / "완전 폭망이었습니다."

### 1-4. 반복 패턴 (시그니처 표현)
- **"그런데,"**: 전환과 반전의 핵심 시그니처. 모든 원고에서 가장 빈번하게 등장하는 전환어. 단독 줄로 배치하여 극적 효과 극대화.
- **"바로"**: 정체 공개, 결론 강조에 사용. "이 아이가 바로 훗날~", "바로 제일제당입니다."
- **"그렇게"**: 시간 경과나 결과 도출. "그렇게 1936년 3월,", "그렇게 삼성상회는~"
- **"한편,"**: 병렬 서사 전환. 다른 인물/사건으로 시선 이동할 때 사용.
- **"어쨌든"**: 복잡한 상황을 정리하고 본론으로 복귀할 때.
- **"결국"**: 최종 결과 도달 시.
- **"그러던 YYYY년 M월 D일,"**: 시간 전환의 정형화된 공식.

## 2. 스토리텔링 구조

### 2-1. 도입-전개-결말 패턴

#### 도입부 (오프닝)
- **시청자 직접 호출**: "오늘은 ~에 대해 알아보려 합니다", "자, 브랜드 백과사전 ~ 시작하겠습니다"
- **시리즈물은 이전편 연결**: "지난 영상에 이어 ~ 바로 시작하겠습니다."
- **질문으로 호기심 유발**: "과연 삼성은 어떻게 세계적인 브랜드가 될 수 있었을까?"
- **인상적 도입**: 스팸 원고처럼 감각적 묘사("따끈한 흰밥에 스팸 한 조각...")로 시작하기도 한다.

#### 전개부
- **에피소드 중심 시간순 서술**: 인물의 탄생/유년기 → 성장/교육 → 사업 시작 → 위기 → 성공/실패 순서로 전개.
- **챕터 소제목 방식**: 각 시대/사건을 명확한 소제목으로 구분. 소제목은 짧고 임팩트 있게.
  - 예: "의령 금수저, 이병철", "받지 못한 졸업장", "사업의 시작", "왕자의 난"
- **연도 기반 뼈대**: 반드시 연도를 명시하며 사건을 배치. 시간 흐름이 명확해야 한다.
  - "1910년,", "그러던 1921년,", "1938년 3월 1일,"

#### 결말부
- **시리즈물 클리프행어**: "삼성 2편에서 계속됩니다", "(삼성 3편에서 계속)"
- **단편 마무리**: "이상 ~에 대해 알아봤습니다."
- **최종편 소감**: "워낙 내용이 많다 보니 누락된 부분도 많이 있을 것입니다. 하지만, 나름대로 최선을 다해 정리했다는 점 이해해 주시기 바랍니다."

### 2-2. 챕터 구성 방식
- 하나의 원고에 **4~8개의 챕터(소제목 단위)**가 포함된다.
- 각 챕터는 하나의 명확한 에피소드/사건에 집중한다.
- 챕터 간 전환은 시간 점프("그러던 YYYY년,")로 이루어진다.
- 마지막 챕터 끝에 다음 편 예고 또는 다른 주제로의 여운을 남긴다.

## 3. 화자 스타일

### 3-1. 나레이션 방식
- **전지적 관찰자 시점**: 화자는 인물의 행동과 역사적 사건을 관찰하며 서술한다. 1인칭이 아니라 3인칭 관찰자.
- **직접 시청자 호출**: "참고로~", "여기서 잠깐!", "~아십니까?", "사실 제가 옴니아2 유저였습니다..." 등 메타적 발언으로 시청자와 소통.
- **화자 개입 최소화**: 감정 표현은 절제하되, 적절한 지점에서 짧은 코멘트 삽입.
  - "예나 지금이나 1등만 기억하는 더러운 세상..."
  - "하…(한숨)"

### 3-2. 감정 표현 원칙
- **감정은 사실로 보여준다**: "눈물을 흘렸다" 대신 "정신이 번쩍 들었다고 합니다" — 인물의 감정을 직접 서술하기보다 행동/반응으로 드러낸다.
- **위트와 아이러니**: 심각한 상황도 건조하게 전달하여 오히려 임팩트를 높인다.
  - "벌써 전쟁 때문에 사업이 두 번이나 망한 병철…"
  - "경영난은 무슨, 오히려 재고가 없어서 걱정일 정도였다고 합니다."
- **과도한 감탄 금지**: !는 극적 절정에만 사용(챕터당 0~2회). 과장된 리액션("대박이죠!", "정말 놀랍지 않나요?") 절대 금지.

## 4. 수사법

### 4-1. 핵심 기법

#### (1) "그런데," 반전법 (가장 빈번)
모든 원고에서 가장 자주 쓰이는 핵심 기법. "그런데,"를 단독 줄에 배치하여 반전/뜻밖의 사건/예상 뒤집기를 예고한다.
```
사업은 점차 확장했지만,
병철의 마음 한 켠에는 아쉬움이 남아 있었습니다.
그런데,
(새로운 전개)
```

#### (2) 미래 예고법 (Foreshadowing)
인물이 등장할 때 "훗날 ~가 되는"이라는 공식으로 미래를 미리 알려준다. 시청자의 호기심을 자극하는 동시에 맥락을 제공.
```
이 아이가 바로 훗날, 대한민국 경영계에 큰 획을 그으며
삼성그룹의 초대 회장이 되는 호암 이병철입니다.
```
```
같은 반 친구 중에는 구인회라는 아이가 있었습니다.
그가 바로 훗날 락희화학공업사, 지금의 LG를 창립한 인물입니다.
```

#### (3) 현재 연결법
과거의 기관/장소를 "지금의 ~입니다"로 현재와 연결하여 친숙함을 부여.
```
이곳이 바로 현재의 전국경제인연합회, 전경련입니다.
```
```
이 학교는 허준이라는 인물이 세웠는데, 참고로 허준은 GS를 창립한 허만정의 아버지였습니다.
```

#### (4) 의문문 유도
직접적 질문으로 시청자의 사고를 유도하되, 바로 답을 제시한다.
```
과연 1910년에 포드 자동차는 얼마나 팔리게 되었을까?
전년도 보다 훨씬 더 많은 18,664대의 차량이 판매되었다고 합니다.
```

#### (5) 대비와 아이러니
기대와 결과의 대비, 혹은 역설적 상황을 건조하게 서술.
```
국내에서는 명절마다 고급지게 포장된 선물세트로 팔리고 있지만
서양에서는 '싸구려 통조림 햄'으로 취급 받고 있습니다.
```
```
600년 전통 영국 모직과 상대가 되겠어?"
"제일제당에서 돈 좀 벌더니 세상이 만만하지?"
```

#### (6) 숫자로 보여주기
구체적 숫자/금액/비율로 스케일을 체감시킨다. 단순 나열이 아니라 비교 기준을 함께 제시.
```
당시 쌀 한 가마가 13원 정도였다고 하니,
500원은 정말 엄청난 돈이었는데,
```
```
당시 한 달 월급이 15원 정도였기 때문에
3만 원은 정말 어마어마하게 큰돈이었습니다.
```

#### (7) 직접 인용
인물의 발언을 큰따옴표로 직접 인용하여 생동감 부여. 특히 결정적 순간에 사용.
```
"극단적으로 얘기해서, 농담이 아니야 마누라, 자식 빼고 다 바꿔봐"
```
```
"아버지, 반도체는 주식회사와 원자력과 함께
인류의 역사를 바꾼 3대 발명품입니다."
```

## 5. 씬 전환 패턴

### 5-1. 시간 전환
- **연도+날짜 명시**: "그러던 1950년 6월 25일,", "1938년 3월 1일,"
- **"그러던" 공식**: 시간 점프의 시그니처. "그러던 YYYY년," 패턴으로 새 사건 도입.
- **"그렇게" 결과 이행**: 과정 설명 후 결과로 넘어갈 때. "그렇게 1976년 4월 18일,"
- **"한편,"으로 병렬 전환**: 같은 시기 다른 인물/사건으로 시선 이동.
- **"이후"로 후일담**: "이후 삼성물산은~"

### 5-2. 장소 전환
- 장소 이동은 인물의 물리적 이동과 함께 서술: "병철은 부산, 경성, 평양을 거쳐 중국까지 여행하며~"
- 새 장소는 구체적 지명으로 명시: "경남 진주시 지수면에", "경기도 용인군 포목면에"
- "지금의 ~"으로 현재 지명 병기: "경성, 지금의 서울"

### 5-3. 장면 묘사 밀도
- **배경 묘사 최소화**: 인물의 행동과 사건 중심. 풍경/분위기 묘사는 1~2문장으로 압축.
  - "그날따라 밝은 달빛이 창 너머 방안으로 들어오고 있었는데, 달빛에 비친 쌔근쌔근 잠든 세 아이가 병철의 눈에 들어왔습니다."
- **감각 묘사는 결정적 순간에만**: 전환점이 되는 순간에 한정하여 시각/청각 묘사 삽입.
- **동작은 간결하게**: "댕기머리를 순식간에 댕강! 잘리고 말았습니다." — 의성어/의태어 절제 사용.

## 6. 특수 표현 및 관용구

### 6-1. 시그니처 전환어구
| 표현 | 용도 | 빈도 |
|------|------|------|
| 그런데, | 반전/예상 밖 사건 도입 | 매우 높음 (챕터당 2~5회) |
| 그렇게 | 과정→결과 이행 | 높음 |
| 한편, | 병렬 서사 전환 | 높음 |
| 그러던 YYYY년, | 시간 점프 | 높음 |
| 바로 | 정체 공개/강조 | 높음 |
| 어쨌든 | 복잡한 논의 정리 후 본론 복귀 | 중간 |
| 결국 | 최종 결과 | 중간 |
| 참고로 | 부가 정보/여담 | 중간 |
| 덕분에 | 긍정적 결과 연결 | 중간 |
| 게다가 | 추가 정보 누적 | 중간 |
| 뿐만 아니라 | 정보 추가 확장 | 낮음 |

### 6-2. 특유의 어투
- **"~인데,"**: 문장 중간에 배경 설명을 삽입하는 관용적 연결.
- **"~이었던 겁니다"**: 반전의 핵심 원인을 밝힐 때 사용하는 강조형.
- **"~었다고 합니다"**: 전해지는 이야기/회고를 간접 인용할 때. 출처의 불확실성을 인정하면서도 스토리텔링 효과 유지.
- **"~고 말았습니다"**: 부정적 결과에 대한 안타까움.
- **"뭐 ~는 알 수 없지만"**: 진위 불명 사안에 대한 중립적 태도 표현.
- **"~라 불리기도 합니다"**: 별칭/후대 평가를 소개할 때.
- **"(~에서 계속됩니다)"**: 시리즈물 챕터 종료 시.
- **구어체 삽입**: "경영난은 무슨, 오히려~", "뭐 명확히 밝혀진 것은 없습니다", "암튼"

### 6-3. 영상 연출 지시 (원고 내 메모)
- 원고 내에 `←`, `→`, `(사진)`, `(영상)` 등의 메모가 포함될 수 있다. 이는 스토리보드 디렉터를 위한 지시이며 나레이션에는 포함되지 않는다.
- "~에 대해서는 다른 영상에서 다시 알아보도록 하겠습니다": 타 주제 언급 시 분량 조절.

## 7. 주제 전개

### 7-1. 정보 전달 vs 감성 전달 비율
- **정보 전달 70% : 감성/서사 30%**: 팩트와 연대기가 중심이되, 인물의 내면 묘사와 에피소드적 일화로 감성을 보충한다.
- 정보가 밀집된 구간(숫자, 제도, 기술 설명) 뒤에는 반드시 에피소드나 일화를 배치하여 이완시킨다.
- 기술/제도 설명은 비유나 일상 비교로 풀어낸다:
  - "지금 우리가 사용하는 '원'의 1000분의 1의 가치를 가지고 있습니다."
  - "한마디로 에버랜드만 장악하면 삼성그룹 전체를 장악하는 구조"

### 7-2. 팩트 인용 방식
- **연도, 날짜, 금액, 수량 등 구체적 수치를 반드시 명시**: 모호한 표현("얼마 뒤", "꽤 많은 돈")보다 정확한 숫자를 선호.
- **화폐 가치 환산**: 과거 화폐 단위를 현재 기준으로 환산하여 체감 가능하게.
  - "당시 쌀 한 가마가 13원 정도였다고 하니, 500원은 정말 엄청난 돈"
  - "당시 한 달 월급이 15원 정도였기 때문에 3만 원은 어마어마하게 큰돈"
- **출처 언급**: 자서전, 회고록, 기사 등 출처를 자연스럽게 본문에 녹인다.
  - "병철은 자서전인 호암자전을 통해 이렇게 회고했습니다."
  - "조홍제의 회고록, 나의 회고에는~"
- **상반된 주장 병기**: 팩트가 엇갈릴 때 양쪽 모두 소개하고 판단을 시청자에게 맡긴다.
  - "아무튼 누구의 말이 맞는지는 알 수 없지만,"

### 7-3. 에피소드 선택 기준
- **인물의 인간적 면모를 드러내는 일화** 우선: 이병철의 골패 노름, 이건희의 개 사랑, 헨리 포드의 시계 분해 등.
- **반전이 있는 사건**: 기대와 결과가 다른 이야기가 스토리텔링의 핵심 동력.
- **현재와 연결되는 기원**: "이것이 바로 지금의 ~입니다"로 끝맺는 에피소드.
- **인물 간 관계/갈등**: 형제 갈등(아디다스-푸마), 부자 갈등(이병철-이창희), 사업 경쟁(삼성-LG) 등.

## 부록: 원고 작성 체크리스트

Writer 에이전트가 최종 원고를 검토할 때 아래 항목을 확인한다:

- [ ] "그런데,"가 반전 지점에 적절히 배치되었는가
- [ ] 동일 종결어미가 3회 이상 연속 반복되지 않는가
- [ ] 연도/날짜가 사건마다 명시되어 있는가
- [ ] 금액/수치에 비교 기준이 함께 제시되어 있는가
- [ ] 각 챕터에 최소 1개의 인간적 에피소드가 포함되어 있는가
- [ ] 인물 첫 등장 시 "훗날 ~가 되는" 미래 예고가 있는가
- [ ] "지금의 ~" 현재 연결이 적절히 사용되었는가
- [ ] !는 챕터당 0~2회 이하인가
- [ ] 5문장 이상 줄바꿈 없이 몰아쓴 구간이 없는가
- [ ] 번역체(~것은 ~이다, ~에 의해 ~되었다) 표현이 없는가
- [ ] 해라체(~했다, ~이다) 종결이 나레이션에 섞이지 않았는가
- [ ] 챕터 소제목이 짧고 임팩트 있는가 (10자 이내 권장)
- [ ] 도입부에 시청자 호기심을 유발하는 질문 또는 인상적 장면이 있는가
- [ ] 시리즈물이면 클리프행어로 끝나는가
