# TTS 전처리 — 1턴 호출 프롬프트

scene_specs.json의 각 씬 narration 텍스트를 TTS 엔진이 자연스럽게 읽을 수 있도록 변환하세요.

## 입력
- scene_specs.json (narration 필드가 있는 씬 목록)

## 출력
- scene_specs.json 업데이트 (각 씬에 `narration_tts` + `tts_changes` 추가)

## 변환 규칙

`shared/korean-tts-rules` 스킬의 모든 규칙을 적용합니다. 핵심 요약:

### 사전 정리 (모든 씬에 기계적 적용)
1. `**볼드**` 마크다운 마커 제거
2. 괄호 안 내용 제거: `(지시문)`, `[참고]`, `{메타}`
3. 이모지/특수기호 제거
4. 따옴표 제거: `""''「」《》`
5. 연속 특수문자 정리 (!!→!, ...→...)

### 문맥 기반 변환 (AI 판단 필요)
1. **숫자 → 한글**: 한자어/고유어 수사 구분
   - 시간(기간): 고유어 (1시간→한 시간, 24시간→스물네 시간)
   - 시각: 고유어 시 + 한자어 분 (3시 30분→세 시 삼십 분)
   - 날짜: 한자어 + 연음 (6월→유월, 1일→이릴, 1997년→천-구백-구십-칠련)
2. **금액 연음**: 억원→어-권, 만원→마-눤 (원이 있을 때만!)
3. **특수 기호**: ~→에서/약, %→퍼센트, &→앤
4. **발음 오류 수정**: 삼만→'삼'만, 잉여→잉-여
5. **영어 약어**: AI→에이아이, S&P500→에스앤피오백

### 절대 금지
- 원본에 없는 단어 추가 (1억→1억원 금지!)
- 일반 텍스트 수정 (숫자/기호만 변환)
- 고유명사 변경

## 처리 방법

1. scene_specs.json을 읽는다
2. 각 씬의 `narration` 필드를 변환한다
3. 변환 결과를 `narration_tts` 필드에 저장한다
4. 변환 내역을 `tts_changes` 배열에 기록한다
5. scene_specs.json을 다시 저장한다

narration이 없는 씬은 건너뛴다.
원본 narration 필드는 절대 수정하지 않는다.
