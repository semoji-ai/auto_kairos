# Writing Style

유튜브 나레이션 원고의 문체, 톤, 글자 수 제한, 금지 표현, IMG 마커 규칙을 정의합니다.

**참조 에이전트**: write-manuscript, qa-reviewer

---

## 1. 문체 규칙

### 필수
- **대화체**: "~입니다", "~거든요", "~한번 보시죠"
- **짧은 문장**: 한 문장 최대 40자. 나레이션 호흡 단위
- **능동태**: "연구가 발표되었다" → "연구팀이 발표했습니다"
- **구체적 숫자**: "많은" → "1억 5천만 명의"

### 금지
- 번역체 ("~것이 사실이다", "~함에 있어서")
- 과도한 수식어 ("매우 놀라운 혁명적인")
- 논문체 ("~에 의하면", "~것으로 사료된다")
- 영어 남용 (적절한 한국어 대체 우선)

---

## 2. 후킹 기법 (Act 1 도입부)

1. **충격적 수치**: "단 3년 만에 1000배 성장한 시장이 있습니다"
2. **반전 질문**: "여러분이 쓰는 챗봇, 사실은 에이전트가 아닙니다"
3. **일화**: "2024년 어느 날, 한 스타트업에서..."

---

## 3. 페이싱

- 데이터 씬 뒤에는 스토리 씬 배치
- 3-4개 씬마다 브리딩 포인트
- 챕터 전환 시 짧은 요약 문장

---

## 4. VIZ 마커 — 사용 금지

**⚠️ 원고 작성 단계에서 `[VIZ:...]` 마커를 사용하지 않습니다.**

- 시각화 타입(vizType), 차트 종류, 데이터 구조는 모두 **visual-composer**가 나레이션 내용 + `research_report.json`을 분석하여 결정합니다.
- **asset-advisory**가 `research_report.json`에서 정확한 수치/지표명/단위를 매칭하므로, 원고에 메타데이터 힌트를 남길 필요가 없습니다.
- 원고 작성자는 **나레이션 텍스트 작성에만 집중**합니다.

---

## 5. IMG 마커 — 사용 금지

**⚠️ 원고 작성 단계에서 `[IMG:...]` 마커를 사용하지 않습니다.**

- 이미지 필요 여부, 소스 타입(wikimedia/search/generate), 검색어는 모두 **asset-advisory** (Phase 2.5)가 나레이션 내용 + `research_report.json`을 분석하여 결정합니다.
- 원고 작성자가 이미지 판단을 하면 asset-advisory의 전문적 판단과 충돌하거나, 불필요한 이미지를 강제하게 됩니다.
- 원고 작성자는 **나레이션 텍스트 작성에만 집중**합니다.

---

## 6. 씬 분할 규칙 (필수)

하나의 씬에는 **정확히 하나의 개념**만 서술한다.
`scene-segmentation` 스킬의 과밀 씬 정의 참조.

### 분할 신호 — 아래 중 하나라도 해당하면 새 씬으로 분리:

1. "한편", "그런데", "그러나", "이어서" 등 **전환어** 등장
2. 새로운 **인물**이 소개됨
3. **시간/장소**가 전환됨
4. 글자 수가 **100자**를 초과 (`scene-segmentation` 스킬 5번 참조)

### 분할 예시

잘못된 예 (하나의 씬에 몰아쓰기):
```markdown
## Scene 21: 관풍헌 이전과 금성대군의 밀고

홍수가 청령포를 덮쳤습니다. 단종은 관풍헌으로 이전했습니다.
한편, 금성대군이 복위를 꾀했지만 밀고당했습니다.
금성대군은 사사되었고, 송현수도 처형되었습니다.
```

올바른 예 (개념별 분할):
```markdown
## Scene 21: 홍수와 관풍헌 이전

1457년 여름. 큰 홍수가 청령포를 덮쳤습니다.
단종은 영월 관아의 관풍헌으로 거처를 옮겼습니다.

## Scene 22: 금성대군의 복위 시도

세조의 동생 금성대군. 순흥 유배지에서 단종 복위를 꾀하고 있었습니다.

## Scene 23: 밀고와 처형

그런데, 한 관노가 이 계획을 밀고해 버렸습니다.
금성대군은 사사되었고, 단종의 장인 송현수도 처형되었습니다.
```

---

## 7. 원고 포맷

```markdown
# Ch1. 챕터 제목

## Scene 1: 씬 제목

나레이션 텍스트...

## Scene 2: 씬 제목

나레이션 텍스트...
```

> **참고**: VIZ 마커 없이 `## Scene N: 제목` + 나레이션만 작성합니다.
> 시각화/차트/에셋 결정은 후속 단계(visual-composer, asset-advisory)가 담당합니다.
