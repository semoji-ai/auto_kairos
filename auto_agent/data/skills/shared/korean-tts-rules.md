# Korean TTS 전처리 규칙

한국어 나레이션 텍스트를 TTS 엔진(ElevenLabs)이 자연스럽게 읽을 수 있도록 변환합니다.

**실행 방식**: Claude Code 1턴 호출 (문맥 기반 판단이 필요한 변환을 정확하게 수행)
**입력**: scene_specs.json의 각 씬 narration
**출력**: scene_specs.json의 각 씬 narration_tts + tts_changes

---

## 0. 사전 정리 (규칙 기반 — 반드시 먼저 수행)

### 0-1. 마크다운 마커 제거
```
**볼드** → 볼드
*이탤릭* → 이탤릭
```

### 0-2. 괄호 안 내용 제거
```
(연출 지시) → 제거
[참고 사항] → 제거
{메타데이터} → 제거
```

### 0-3. 씬 번호/지시문 제거
```
#1 텍스트 → 텍스트
장소: 회의실 → 제거
시간: 오후 → 제거
```

### 0-4. 이모지/특수 유니코드 제거
```
🔥 📊 ★ ☆ ♥ ■ □ ▶ ▲ ♪ ♫ → 모두 제거
```

### 0-5. 따옴표 정리
```
"큰따옴표" → 큰따옴표
'작은따옴표' → 작은따옴표
「일본식」『겹따옴표』《꺾쇠》→ 모두 제거
```

### 0-6. 연속 특수문자 정리
```
!!!! → !
???? → ?
...... → ...
~~~~ → ~
```

## 1. 특수 기호 문맥 기반 변환

### ~ (물결표/틸드)
- **범위 표현**: "에서"로 변환
  - 1~10 → 일에서십
  - 서울~부산 → 서울에서부산
  - 월~금 → 월에서금
- **숫자 5 + ~ 특수 처리**: 5 뒤에 ~가 오면 '오'에 작은따옴표 필수
  - 5~10 → '오'에서십
  - 15~20 → 십'오'에서이십
- **대략/약**: "약 N" 또는 "N 정도"
  - ~100명 → 약 백 명
  - 30분~ → 삼십 분 정도

### . (마침표/점)
- **소수점/버전**: "쩜"으로 변환
  - 3.14 → 삼쩜일사
  - 0.5 → 영쩜오
  - 3.5% → 삼쩜오 퍼센트
- **문장 끝 마침표**: 그대로 유지
- **약어의 점**: 제거 (Dr. → 닥터, vs. → 대)

### % (퍼센트)
- 반드시 "퍼센트"로 변환 (퍼쎈트 아님!)
  - 50% → 오십 퍼센트
  - 100% → 백 퍼센트

### & (앰퍼샌드)
- "앤"으로 변환
  - R&D → 알앤디
  - S&P → 에스앤피
  - Q&A → 큐앤에이

### / (슬래시)
- 문맥에 따라 "또는", "및", "당"
  - 남/여 → 남 또는 여
  - km/h → 시속

### + (플러스)
- 1+1 → 원 플러스 원
- +10% → 플러스 십 퍼센트

## 2. 숫자 변환 규칙

### 한자어 수사 (일, 이, 삼...)
다음 단위와 함께 사용:
- 년, 월, 일, 분, 초 (시간)
- 차, 회, 번째, 조, 항, 호 (순서)
- 층, 호, 번지, 동 (위치)
- 학년, 반, 학기 (교육)
- 원, 달러, 퍼센트, 점 (금액/수치)
- 킬로미터, 미터, 센티미터 (단위)
- 번, 페이지, 쪽

### 고유어 수사 (한/하나, 두/둘, 세/셋...)
다음 단위와 함께 사용:
- 개, 가지 (개수)
- 명, 사람, 분 (사람)
- 마리 (동물)
- 살 (나이)
- 시 (시각. ※분/초는 한자어)
- **시간** (기간) — 매우 중요!
  - 1시간 → 한 시간
  - 2시간 → 두 시간
  - 24시간 → 스물네 시간
- 권, 장, 편 (서적)
- 병, 잔, 그릇 (음식)
- 대, 자루, 송이 (사물)
- 배 (배수)

### 숫자+인(人) 변환
하이픈으로 구분:
- 1인 → 일-인
- 2인 → 이-인
- 10인 → 십-인

## 3. 금액(원) 연음 규칙 — 매우 중요!

⚠️ "원"이 명시적으로 있는 경우에만 연음 처리!

### 기본 단위 발음
```
억원 → 어-권
만원 → 마-눤
천원 → 처-눤
백원 → 배-권
```

### 예시
```
1000원 → 처-눤
5만원 → 오마-눤
1억원 → 이러-권
100억원 → 배거-권
```

### 삼만원 특수 처리 (TTS 발음 오류 방지)
3이 포함된 만원: '삼'에 작은따옴표 필수 (하이픈 없이!)
```
3만원 → '삼'마눤
13만원 → 십'삼'마눤
103만원 → 백'삼'마눤
```

### 복합 금액 (최종 단위만 연음)
⚠️ 중간 단위에 "원" 추가 절대 금지!
```
❌ "2억 5천만원" → "이억원 오천만원" (금지!)
✅ "2억 5천만원" → "이억 오천마-눤" (마지막만 연음)
```

### "원" 추가 금지 규칙
원본에 "원"이 없으면 절대 추가하지 않음:
```
"1억" → "일억" (원 추가 금지)
"1억원" → "이러-권" (원 있으니 연음)
```

## 4. 날짜 연음 규칙

### 연도 (년)
하이픈으로 구분. 1,6,7,8로 끝나면 "련":
```
1997년 → 천-구백-구십-칠련
2024년 → 이천-이십-사년
2001년 → 이천-일련
1876년 → 천-팔백-칠십-육련
```

### 월
특수 발음: 6월→유월, 10월→시월
```
1월 → 이뤌
2월 → 이월
6월 → 유월
7월 → 칠뤌
8월 → 파뤌
10월 → 시월
11월 → 시비뤌
```

### 일
특수 발음: 1일→이릴, 6일→유길, 10일→시빌
```
1일 → 이릴
6일 → 유길
10일 → 시빌
15일 → 시보일
21일 → 이십-이릴
31일 → 삼십-이릴
```

### 완성 예시
```
1997년 11월 31일 → 천-구백-구십-칠련-시비뤌-삼십-이릴
2024년 6월 15일 → 이천-이십-사년-유뤌-시보일
```

### 약어 발음
```
AI → 에이아이          API → 에이피아이
CEO → 씨이오          GPU → 지피유
LLM → 엘엘엠          GPT → 지피티
IT → 아이티            SNS → 에스엔에스
URL → 유알엘          PDF → 피디에프
USB → 유에스비         ETF → 이티에프
S&P → 에스앤피         R&D → 알앤디
```

### 단위 변환
```
km → 킬로미터          m → 미터
cm → 센티미터          mm → 밀리미터
kg → 킬로그램          g → 그램

```

```
Claude → 클로드
```

## 6. 한글 발음 오류 수정 (ElevenLabs 버그 대응)

하이픈(-) 또는 작은따옴표(')로 올바른 발음 유도:
```
잉여 → 잉-여 (잉겨로 잘못 발음됨)
삼만 → '삼'만 (사만으로 잘못 발음됨)
삼천 → '삼'천 (사천으로 잘못 발음될 수 있음)
삼백 → '삼'백 (사백으로 잘못 발음될 수 있음)
```

---

## 7. 끝부분 처리

- 마지막 문자가 `.!?` 등 마침표가 아니면 마침표 추가
- `...` 또는 `…` 말줄임표 추가 금지 — 원본에 없으면 넣지 않는다

---

## 8. 출력 규칙

1. 변환된 텍스트만 출력 (설명, 주석 금지)
2. 원본의 줄바꿈과 문장 구조 유지
3. 숫자/기호가 아닌 일반 텍스트는 수정하지 않음
4. ⚠️ 원본에 없는 단어를 추가하지 않음 (예: "1억"→"1억원" 금지)
5. 고유명사는 원형 유지 (인물명, 기관명)

### 출력 포맷

각 씬에 `narration_tts` 필드 추가:

```json
{
  "sceneNumber": 5,
  "narration": "2025년 AI 에이전트 시장은 150억 달러를 넘어섰습니다.",
  "narration_tts": "이천-이십-오년 에이아이 에이전트 시장은 백오십억 달러를 넘어섰습니다.",
  "tts_changes": [
    {"original": "2025년", "converted": "이천-이십-오년", "rule": "year_liaison"},
    {"original": "AI", "converted": "에이아이", "rule": "abbreviation"},
    {"original": "150억", "converted": "백오십억", "rule": "korean_number"}
  ]
}
```
