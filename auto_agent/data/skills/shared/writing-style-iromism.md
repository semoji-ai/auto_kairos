# Writing Style — 이로미즘

quirky_cartoon 아트스타일 전용 나레이션 문체 가이드입니다.
이 스킬이 활성화되면 `writing-style`과 `scene-segmentation`의 글자 수·씬 분할 규칙을 **오버라이드**합니다.

**참조 에이전트**: write-manuscript, qa-reviewer

---

## 1. 핵심 톤: "옆자리 형이 술자리에서 알려주는 느낌"

이로미즘 문체는 **교양 있는 수다**입니다.
어렵고 복잡한 주제를 마치 옆자리에서 맥주 한 잔 하며 설명해주는 듯한 톤으로 풀어냅니다.
격식 없지만 가볍지 않고, 유머가 있지만 팩트는 정확합니다.

---

## 2. 문체 규칙

### 필수 패턴

| 패턴 | 설명 | 예시 |
|------|------|------|
| **자문자답** | 질문을 던지고 직접 답하는 리듬. 챕터당 최소 2~3회 | "왜 그럴까요? '시스템'이 아닌 '도박'을 했기 때문입니다" |
| **도발적 후킹** | 통념을 뒤집거나 독자의 감정을 자극하는 도입 | "솔직히 말해봅시다. 우리는 모두 '대박'을 꿈꿉니다" |
| **일상 비유** | 복잡한 개념을 일상 사물·경험에 대입 | "마법의 과일 바구니", "어벤져스 팀을 고용하는 것" |
| **현장감 서술** | 연도·장소·인물을 구체적으로 묘사, 다큐 느낌 | "1954년 1월 21일, 코네티컷주 그로튼의 템스강" |
| **서프라이즈 전개** | 기대를 뒤집는 숫자/사실을 극적으로 제시 | "놀라지 마십시오. 약 536억 원이 됩니다" |
| **독자 호칭** | "여러분"을 적극 사용. 독자를 이야기 안으로 끌어들임 | "여러분이 S&P 500 ETF를 딱 1주 사는 순간" |
| **명언 인용** | 도입부·전환부에 유명인 말 활용 (출처 명시) | "아인슈타인은 말했습니다. '복리는 세계 8대 불가사의다'" |

### 어미 스타일

- **기본 어미**: ~입니다, ~습니다 (격식체 기반)
- **감정 유발 어미 혼용**: ~거든요, ~거예요, ~죠, ~니까요, ~한 거예요
- **도발/강조**: ~한번 보시죠, ~아십니까?, ~보셨습니까?
- **공감 유도**: ~않나요?, ~어떤가요?, ~상상해 보세요

### 문장 길이

- 기존 writing-style의 **40자 제한을 적용하지 않음**
- 짧은 문장(10~20자)과 긴 문장(40~80자)을 **리듬감 있게 교차**
- 핵심 포인트는 짧게 끊고, 설명·맥락은 길게 풀어줌
- 한 문장이 100자를 넘지 않도록 주의

### 금지 표현 (기존과 동일)

- 번역체 ("~것이 사실이다", "~함에 있어서")
- 과도한 수식어 ("매우 놀라운 혁명적인")
- 논문체 ("~에 의하면", "~것으로 사료된다")
- 영어 남용 (적절한 한국어 대체 우선)

## 3. 후킹 기법 (Act 1 도입부)

이로미즘의 후킹은 **독자의 감정을 먼저 건드리고, 그 다음 주제로 진입**합니다.

### 패턴 1: 공감형 도발
> "솔직히 말해봅시다. 우리는 모두 '대박'을 꿈꿉니다. 옆자리 김 대리가 코인으로 5배를 벌었다는 소리에 배가 아픕니다."

### 패턴 2: 뉴스 속보형
> "2025년 10월 30일, 도널드 트럼프 미국 대통령이 한국의 핵추진 잠수함 건조를 공식 승인했다는 소식이 전 세계를 놀라게 했습니다."

### 패턴 3: 일상 진입형
> "서울 강남의 한 학원가에서 만난 유학생 학부모 김씨는 '딸아이 미국 대학 등록금 송금하는데, 작년보다 몇 백만 원이 더 나갔다'며 한숨을 쉬었어요."

### 패턴 4: 명언+반전형
> "'내일 지구가 멸망하더라도 나는 한 그루의 사과나무를 심겠다.' 스피노자의 말처럼 들리지만, 사실 투자자에게는 다른 의미로 다가옵니다."

---

## 4. 스토리텔링 구조

### 챕터 구성

이로미즘은 **에세이형 챕터 구조**를 사용합니다. 하나의 챕터 안에서 여러 개념을 **서사적 흐름으로 자연스럽게 연결**합니다.

```
프롤로그 → Ch1 → Ch2 → ... → ChN → 에필로그
```

- **프롤로그**: 독자의 감정을 건드리는 후킹 + 주제 선언
- **본문 챕터**: 각 챕터는 소주제를 깊이 파고듦. 챕터 내에서 번호 매긴 소제목(1, 2, 3...)으로 하위 논점 정리
- **에필로그**: 전체 요약 + 독자에게 던지는 메시지 + 여운 남기는 마무리

### 챕터 내부 흐름

하나의 챕터 안에서 다음 순서를 반복:

1. **질문 던지기** → 독자의 호기심 유발
2. **일상 비유** → 복잡한 개념을 쉽게 풀기
3. **구체적 팩트/수치** → 신뢰 확보
4. **서프라이즈** → "놀라지 마십시오", "보셨습니까?"
5. **한 줄 정리** → 핵심 메시지 압축

## 5. 씬 분할 규칙 (오버라이드)

**⚠️ 이 섹션은 `writing-style` 6번 및 `scene-segmentation` 4번의 과밀 씬 규칙을 오버라이드합니다.**

### 기존 규칙과의 차이

| 항목 | 기존 (writing-style) | 이로미즘 (오버라이드) |
|------|---------------------|---------------------|
| 씬당 글자 수 상한 | 100자 | **250자** |
| 씬당 개념 수 | 정확히 1개 | **1~2개** (서사적으로 연결된 경우 허용) |
| 문장 길이 제한 | 40자 | **100자** |
| 전환어에 의한 분할 | 전환어 등장 시 무조건 분할 | 서사 흐름 내 전환어는 **유지 가능** |

### 이로미즘 분할 기준

아래 중 하나라도 해당하면 새 씬으로 분리:

1. 나레이션 글자 수가 **250자 초과**
2. **시간대가 크게 전환**됨 (예: 1954년 → 1958년)
3. **장소가 전환**됨 (예: 코네티컷 → 하와이)
4. **새로운 주요 인물**이 등장하며 별도 맥락이 시작됨
5. 챕터 내 **번호 소제목**(1, 2, 3...) 전환 시

### 분할하지 않는 경우

- 자문자답 패턴 중간 ("왜일까요? ... 때문입니다")
- 비유를 풀어서 설명하는 도중
- 서프라이즈 전개의 빌드업과 반전 사이

---

## 6. 페이싱

- 팩트 밀도가 높은 구간 뒤에는 **비유·감정 구간** 배치
- 3~4개 씬마다 자문자답 또는 독자 호칭으로 **브리딩 포인트**
- 챕터 전환 시 "그런데 말입니다" 같은 **전환 시그널**

---

## 7. 원고 포맷

```markdown
# 프롤로그: 프롤로그 제목

프롤로그 나레이션...

# Ch1. 챕터 제목

## Scene 1: 씬 제목

나레이션 텍스트...

## Scene 2: 씬 제목

나레이션 텍스트...

# Ch2. 챕터 제목

## Scene 3: 씬 제목

나레이션 텍스트...

# 에필로그: 에필로그 제목

에필로그 나레이션...
```

> **참고**: VIZ/IMG 마커 없이 `## Scene N: 제목` + 나레이션만 작성합니다.
> 시각화/차트/에셋 결정은 후속 단계(visual-composer, asset-advisory)가 담당합니다.

---

## 8. VIZ/IMG 마커 — 사용 금지

기존 `writing-style` 4번, 5번과 동일. 원고 작성자는 **나레이션 텍스트 작성에만 집중**합니다.

---

## 9. 체크리스트 (자가 검증)

원고 완성 후 아래 항목을 확인:

- [ ] 프롤로그에서 독자의 감정을 건드리는 후킹이 있는가?
- [ ] 챕터당 자문자답 패턴이 최소 2회 이상 있는가?
- [ ] 복잡한 개념마다 일상 비유가 붙어 있는가?
- [ ] 구체적 수치/연도/인물명이 포함되어 있는가?
- [ ] 서프라이즈 전개가 최소 1회 이상 있는가?
- [ ] "여러분"을 통한 독자 참여가 자연스럽게 녹아 있는가?
- [ ] 에필로그에 여운을 남기는 마무리가 있는가?
- [ ] 번역체/논문체가 섞여 있지 않은가?
- [ ] VIZ/IMG 마커가 포함되어 있지 않은가?
