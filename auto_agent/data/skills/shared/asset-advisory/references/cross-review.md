## 3. Step 3 상세: 상호 검토

4개 관점의 제안이 나온 후, **씬의 핵심 목적**을 기준으로 최적 조합을 판단한다.

### 판단 기준

> **"이 씬에서 시청자가 가장 기억해야 할 것은 무엇인가?"**

| 씬의 핵심 목적 | 주 에셋 | 보조 에셋 (공존 가능) |
|---------------|---------|---------------------|
| 수치 비교 이해 | 차트 | 배경이미지(낮은 opacity), 아이콘 |
| 브랜드/기업 인지 | 로고그리드 | 배경이미지(낮은 opacity) |
| 감정적 임팩트 / 시각 묘사 | 이미지(**fullscreen**) | 최소 headline 텍스트 |
| 인물 소개 | 이미지(사이드 left/right) | 아이콘 |
| 인물 다수 나열 | 이미지(**inline**, itemImages) | 이름+설명 텍스트 |
| 개념/절차 이해 | 아이콘 리스트 | 배경이미지(중간 opacity) |
| 분위기 전환 / 브릿지 | 이미지(**fullscreen**) | 전환 텍스트만 |
| 국가 비교 | 국기 + 차트/아이콘 | 배경이미지(낮은 opacity) |

### 상호 검토 예시

```
씬: "Apple, Microsoft, NVIDIA가 S&P500의 22%를 차지합니다"

차트 관점: "pie로 22% vs 78% 비중을 보여주면 효과적" (적합도 높음)
심볼 관점: "logo_grid로 3개 기업 브랜드를 보여주면 효과적" (적합도 높음)
이미지 관점: "해당없음 — 차트나 로고가 충분" (적합도 없음)
레이아웃 관점: "pie + logo는 과밀. 하나를 선택해야 함"

상호 검토:
- 핵심 메시지는 "22% 비중"인가, "이 3개 기업이 누구인가"인가?
- 나레이션이 "22%를 차지합니다"에 강조 → 비중이 핵심 → pie 선택
- 단, pie 슬라이스에 로고를 highlightIndex로 강조하여 기업도 인지 가능

최종: pie chart (3사 합산 22% + 나머지 78%) + 아이콘 없음 + 이미지 없음
```

```
씬: "워런 버핏은 이렇게 말했습니다. '인덱스 펀드에 투자하세요'"

차트 관점: "데이터 없음, 해당없음" (적합도 없음)
심볼 관점: "해당없음" (적합도 없음)
이미지 관점: "워런 버핏 초상화를 왼쪽에 배치하면 인용문 임팩트 극대화" (적합도 높음)
레이아웃 관점: "텍스트 적음, 이미지 left + quote 오른쪽 배치 최적"

최종: imageAsset(wikimedia, left, opacity 0.9) + 아이콘 없음 + 차트 없음
```

```
씬: "미국, 영국, 호주 세 나라의 장기 수익률을 비교하면..."

차트 관점: "bar chart로 3국 수익률 비교" (적합도 높음)
심볼 관점: "국기 3개로 즉각적 국가 인식" (적합도 높음)
이미지 관점: "세계지도 배경으로 글로벌 분위기" (적합도 중간)
레이아웃 관점: "bar + 국기는 공존 가능 (막대 위 국기 배지). 배경이미지는 opacity 0.12면 OK"

상호 검토:
- 차트 관점 동의: bar가 비교에 최적
- 심볼 관점 수긍: 국기는 bar의 레이블 보조로 공존 가능
- 이미지 관점 조정: 차트가 주 요소이므로 배경은 opacity 0.12로 은은하게

최종: bar chart + itemFlags + background image(opacity 0.12)
```
