# Research Requirements — 세모지

세상의모든지식 586편 원고에서 역추적한 **카테고리별 필수 리서치 항목**입니다.

> **⚠️ 조건부 적용**: `art_style.json`의 `name`에 "세모지" 또는 "semoji"가 포함될 때만 이 스킬을 적용합니다.
> 다른 아트스타일일 경우 이 스킬을 **무시**하세요.

리서치 단계(research-orchestrator)와 아웃라인 설계(write-manuscript) 모두에서 참조합니다.

**참조 에이전트**: research-orchestrator, write-manuscript

## 1. 공통 리서치 원칙

### 1-1. 세모지 원고의 데이터 특성
- **구체적 날짜**: "1954년 1월 21일" — 연/월/일 단위로 특정
- **구체적 숫자**: "26개월간 9만3천 해리", "228.56점", "740만 명"
- **비교 수치**: "디젤 시속 11~15km vs 핵잠수함 시속 37~47km"
- **금액**: "한 켤레에 150만 원", "3억 7000만 달러, 우리 돈으로 약 5037억 원"
- **출처 포함율**: 전체 원고의 약 30%가 말미에 출처 목록 포함

### 1-2. 소스 신뢰도 우선순위
| Tier | 소스 유형 | 예시 |
|------|----------|------|
| 1 | 공식 문서·통계 | 통계청, 국세청, OECD, WHO, 기업 IR 자료 |
| 2 | 전문 연구기관 | 한국노동사회연구소, IISS, SIPRI, RAND |
| 3 | 주요 언론 | 조선일보, 중앙일보, 동아일보, 한겨레, 매경, 한경, Reuters, AP |
| 4 | 백과사전 | Wikipedia, 나무위키 (1차 검증 후 사용) |
| 5 | 블로그·커뮤니티 | 네이버 블로그, 인스티즈 (일화·에피소드 보조용) |
| 6 | 서적 | 자서전, 전기, 학술서 (직접 인용 시 저자/출판사/연도 명시) |

### 1-3. 필수 출력 형식
리서치 결과는 반드시 다음을 포함:
- **타임라인**: 핵심 사건 연표 (연도 + 사건 + 관련 인물)
- **수치 데이터**: 최소 5개 이상의 구체적 숫자/통계
- **인용 가능한 대사/발언**: 핵심 인물의 직접 인용 2~3개
- **대비/비교 소재**: 라이벌, Before/After, 국가 간 비교 등

## 2. 카테고리별 필수 리서치 항목

### 2-1. 브랜드/기업

원고에서 역추적한 필수 정보:

#### A. 창업자 개인사
- [ ] 출생 연도, 출생지, 부모 직업/배경
- [ ] 어린 시절 에피소드 (가난, 특이한 재능, 결정적 경험)
- [ ] 학력 (중퇴 여부 포함)
- [ ] 첫 직장/첫 사업 경험
- [ ] 결혼, 파트너 관계

> 세모지 공식: "XXXX년 X월 X일, [장소]에서 한 사내아이가 태어납니다"를 쓰려면 **정확한 생년월일과 출생지**가 필수

#### B. 기업 연혁
- [ ] 창업 연도, 창업 장소, 초기 자본금
- [ ] 사명 변경 이력 (예: 블루리본 스포츠 → 나이키)
- [ ] 핵심 제품 출시 연도 + 개발 배경 에피소드
- [ ] 위기/실패 사건 (연도, 원인, 규모)
- [ ] 턴어라운드 사건 (누가, 어떻게, 결과)
- [ ] 현재 매출, 시가총액, 직원 수

#### C. 경쟁/업계 맥락
- [ ] 동시대 경쟁사 (이름, 규모, 차별점)
- [ ] 업계 전체 규모 (시장 크기, 성장률)
- [ ] 역사적 시대 배경 (전쟁, 경제위기, 정책 변화)

#### D. 감성 소재
- [ ] 창업자의 유명한 발언/명언 2~3개
- [ ] 결정적 일화 (거북선 500원 지폐, 나이키 와플 메이커 등)
- [ ] 가족 관련 에피소드

#### 소스 전략
```
기업 IR → Wikipedia/나무위키 → 뉴스 아카이브 → 서적/자서전
```

### 2-2. 인물 전기

#### A. 기본 프로필
- [ ] 출생: 연/월/일, 장소, 부모 직업, 형제 관계
- [ ] 사망: 연/월/일, 사인, 향년 (해당 시)
- [ ] 학력, 주요 경력 타임라인

#### B. 영웅 서사 요소 (독립운동가/스포츠)
- [ ] 재능 발견 에피소드 (코치의 추천, 첫 대회 등)
- [ ] 슬럼프/좌절 사건 (부상, 경제난, 정치 탄압)
- [ ] 극복 에피소드 (구체적 행동, 누구의 도움)
- [ ] 클라이맥스 사건 (올림픽 금메달, 저격 거사 등)
- [ ] 라이벌 정보 (이름, 배경, 대결 기록, 훗날 발언)

#### C. 가족/인간적 소재
- [ ] 부모의 희생 (경제적 지원, 매니저 역할)
- [ ] 배우자/자녀 관련 에피소드
- [ ] 은퇴/사후 레거시

#### D. 직접 인용
- [ ] 본인의 유명 발언 2~3개 (출처 명시)
- [ ] 라이벌/동료의 평가 발언
- [ ] 가족의 증언
- [ ] 역사적 유언/한시 (독립운동가)

#### 소스 전략
```
자서전/전기 서적 → Wikipedia → 뉴스 인터뷰 → 다큐멘터리
독립운동가: 독립기념관, 국가보훈처 자료 우선
미국 대통령: White House 공식 자료, presidential library
```

### 2-3. 일반상식/과학

#### A. 현상 설명
- [ ] 현상의 정의 (일상어로 번역)
- [ ] 과학적 원리/메커니즘 (단계별 분해)
- [ ] 비유 소재 (머랭 → 달고나 커피 원리)

#### B. 역사적 맥락
- [ ] 기원/발명 연도 + 배경
- [ ] 시대별 발전 과정 (3~5단계)
- [ ] 한국 도입/적용 시기

#### C. 데이터/통계
- [ ] 국내 통계 (통계청, 국세청, 연구소)
- [ ] 국제 비교 데이터 (OECD, WHO)
- [ ] Before/After 수치 비교
- [ ] 시장 규모, 이용자 수, 성장률

#### D. 시의성 연결
- [ ] 현재 뉴스/트렌드와의 접점
- [ ] 관련 법률/제도 변경
- [ ] 사회적 이슈와의 연관성

#### 소스 전략
```
통계청/국세청 → 연구기관 보고서 → 학술 논문 → 뉴스 → Wikipedia
과학: Nature, Science, 국내 연구기관 보도자료
사회: 한국노동사회연구소, 한국개발연구원(KDI)
```

---

### 2-4. 지정학/역사

#### A. 배경 정보
- [ ] 관련 국가 기본 정보 (인구, GDP, 군사력)
- [ ] 역사적 맥락 (과거 분쟁, 조약, 동맹)
- [ ] 지리적 요인 (위치, 자원, 전략적 가치)

#### B. 사건 타임라인
- [ ] 핵심 사건 연표 (연/월/일 단위)
- [ ] 각 사건의 원인 → 경과 → 결과
- [ ] 주요 인물별 역할

#### C. 군사/외교 데이터
- [ ] 군사력 비교 (IISS Military Balance, GlobalFirepower)
- [ ] 경제 제재 현황
- [ ] 동맹 구도 매핑

#### D. 분석/전망
- [ ] 전문가 발언/분석 인용
- [ ] 시나리오별 전망
- [ ] 한국에 미치는 영향

#### 소스 전략
```
공식 정부 문서/조약 → IISS, SIPRI, RAND → Reuters, AP, BBC → Wikipedia
```

### 2-5. 쇼츠 (60초 콘텐츠)

쇼츠는 **1개 질문 + 1개 핵심 원리**만 다루므로 리서치 범위가 좁지만 정확해야 함.

#### 필수 항목
- [ ] 질문에 대한 **정확한 답** (과학적 원리 1개)
- [ ] **대비 수치** 1쌍 (자동차 10m vs 기차 3km 등)
- [ ] **반전 팩트** 1개 (안전벨트가 오히려 위험한 이유 등)
- [ ] 출처 1~2개

## 3. 아웃라인 설계를 위한 리서치 체크포인트

아웃라인(outline.json)을 잡기 전에 리서치 결과에서 다음을 반드시 확인:

### 3-1. 서사 골격 확인
- [ ] **"그런데" 반전 포인트** 3개 이상 식별되었는가?
- [ ] **"하지만" 역전**에 쓸 장애물/좌절 에피소드가 2개 이상 있는가?
- [ ] **"그렇게" 매듭**으로 정리할 단락이 챕터 수만큼 있는가?

### 3-2. 후킹 소재 확인
- [ ] 도입부에 쓸 **충격 수치** 또는 **시사 이슈** 준비되었는가?
- [ ] 브랜드/인물의 경우 **출생 정보**가 정확한가?

### 3-3. 감정 곡선 소재 확인
- [ ] **직접 인용**(대사/발언) 2개 이상 확보했는가?
- [ ] **가족/인간적 에피소드** 1개 이상 있는가?
- [ ] **클라이맥스 사건**이 명확한가?

### 3-4. 데이터 시각화 소재 확인
- [ ] **비교 가능한 수치** 쌍이 3개 이상 있는가?
- [ ] **타임라인** 그릴 수 있을 만큼 연표가 풍부한가?
- [ ] **지도/맵** 필요 시 지리 정보가 있는가?

## 4. 리서치 결과 → 아웃라인 매핑 가이드

리서치 결과의 각 요소가 아웃라인의 어디에 매핑되는지:

```
리서치 요소                → 아웃라인 위치
──────────────────────────────────────────
충격 수치/시사 이슈         → Act 1 후킹 (Ch1)
출생/기원 정보             → Act 1 또는 Act 2 첫 챕터
장애물/좌절 에피소드        → Act 2 중반 ("하지만" 역전)
핵심 전환점 사건           → Act 2 후반 ("그런데" 반전)
직접 인용(대사)            → 클라이맥스 씬 또는 감정 씬
비교 수치                  → 데이터 시각화 씬
가족 에피소드              → Act 2 후반 또는 독립 챕터
타임라인 연표              → 전체 서사 골격
현재 상황/전망             → Act 3 마무리
```

## 5. 카테고리 자동 판별

주제가 주어졌을 때 어떤 리서치 템플릿을 적용할지:

| 주제 키워드 | 카테고리 | 적용 템플릿 |
|------------|---------|-----------|
| 기업명, 브랜드명, 창업자 | 브랜드 | §2-1 |
| 인물명, ~의 일대기, ~의 삶 | 인물 | §2-2 |
| 왜~?, ~의 역사, ~의 과학, ~의 비밀 | 일반상식 | §2-3 |
| 전쟁, 국가 간, 지정학, ~의 진짜 이유 | 지정학 | §2-4 |
| 60초, 쇼츠, 숏폼 | 쇼츠 | §2-5 |
