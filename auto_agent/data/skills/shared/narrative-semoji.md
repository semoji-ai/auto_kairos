# Narrative — 세모지 (구성)

세상의모든지식 586편 분석에서 뽑은 **이야기를 어떻게 짤 것인가**의 규칙입니다.
어떤 순서로 무엇을 보여줄지, 어디서 긴장을 걸고 어디서 풀지를 다룹니다.

> **문체는 여기 없습니다.** 어미·리듬·"그런데" 횟수 같은 표현 규격은 `voice-semoji`가 담당하며
> 윤문 단계(`step_2_polish`)에서 적용됩니다. **초고 작가는 문체 규격을 맞추려 하지 말고
> 내용과 구성에 집중하세요.** 문장이 다소 투박해도 됩니다 — 뒤에서 다듬습니다.

> **⚠️ 조건부 적용**: `writing_style`이 `semoji`일 때만 적용합니다.

## 1. 도입부 후킹 (첫 30초)

주제 유형에 따라 **최적의 후킹 패턴**을 선택한다.

### 패턴 A: 규모 제시형 (브랜드)
구체적 숫자로 스케일을 제시 → 주제 소개.
> "전 세계 약 200개의 국가에서 하루 평균 18억 명의 사람들이 마시는 음료가 있습니다."

### 패턴 B: "한 사내아이가 태어납니다" (브랜드/인물 1편)
창업자/인물의 출생부터 시작하는 서사형 도입.
> "1910년 2월 12일, 이들 부부 사이에서 한 사내아이가 태어납니다. 이 아이가 바로 훗날 삼성그룹의 초대 회장이 되는 호암 이병철입니다."

### 패턴 C: 시사/트렌드 연결형 (일반상식)
현재 화제 사건 → 궁금증 유발 → 본론.
> "2026년 2월, 한국 극장가에 사극 한 편이 돌풍을 일으켰습니다."

### 패턴 D: 질문형 (일반상식/과학)
일상적 현상에 "왜?"를 던짐.
> "프리랜서가 언제부터 존재했는지 아시나요?"
> "도대체 커피와 설탕과 물에게 무슨 일이 일어났길래 달고나로 변해버린 걸까?"

### 패턴 E: 뉴스 팩트 충격형 (지정학/시사)
구체적 날짜 + 충격적 사실 → "그런데 말입니다" 반전.
> "2025년 10월 30일, 도널드 트럼프 미국 대통령이 한국의 핵추진 잠수함 건조를 공식 승인했다는 소식이..."

### 패턴 F: 시리즈 연결형 (장편 시리즈)
> "지난 영상에 이어 현대 6편 바로 시작하겠습니다."

### 도입부 공통 규칙
1. **30초 이내** (3~5문장)
2. 반드시 **"그런데" 또는 질문**으로 전환점 생성
3. 전환 후 **(타이틀)** 삽입 → 본격 스토리 시작

## 2. 서사 구조 — 카테고리별

### 4-1. 브랜드/기업 서사
```
[후킹] → (타이틀) →
Ch1. 기원/출생 → Ch2. 초기 도전 → Ch3. 위기 →
Ch4. 핵심 전환점 → Ch5. 성장/확장 → Ch6. 현재/레거시
```
- 챕터 수: **4~7개**
- 창업 서사 공식: 출생연도 + 출생지 → "한 사내아이가 태어납니다" → "훗날 ~이 되는 인물"
- 감정 곡선: 가난→좌절→기회→성공→위기→재도약

### 4-2. 인물 전기
```
[후킹] → (타이틀) →
Ch1. 어린 시절 → Ch2. 재능 발견/첫 도전 →
Ch3. 역경/좌절 → Ch4. 극복/성공 →
Ch5. 더 큰 도전 → Ch6. 클라이맥스 → Ch7. 레거시/마무리
```
- 챕터 수: **5~9개**
- "하지만" 역전이 **2~5회** 반복
- 가족 에피소드: 독립 챕터형 또는 삽화형으로 삽입
- 라이벌 대비 구조 활용 (김연아 vs 아사다 마오)

### 4-3. 일반상식/과학
```
[질문/트렌드 후킹] → (타이틀) →
현상 소개 → 원리 A 설명 → 원리 B 적용 →
역사적 맥락 → 현재 상황 → 결론
```
- 챕터 유무: **55%가 챕터 없음** (자연스러운 흐름)
- 전문 용어: 등장 즉시 일상어로 번역
- 비유 활용: 복잡한 개념 → 일상 사물에 대입

### 4-4. 지정학/역사
```
[뉴스 팩트 후킹] → (타이틀) →
현재 상황 → 역사적 기원 → 시대별 발전 →
핵심 전환점 사건 → 현재 상황 → 전망
```
- 시간 점프 시 연도 명시: "그리고 [연도]"
- 숫자/데이터로 스케일감 확보

## 3. 챕터 전환 패턴

### 시간 점프
> "그리고 2004년 12월, 헬싱키에서 열린 <주니어 그랑프리 파이널> 대회에서..."

### "그렇게" 매듭 → 새 챕터
> "그렇게 끈질긴 설득 끝에 마음을 돌린 연아는..." → 다음 챕터

### "한편" / "이에" 시점 전환
> "한편 이 무렵 김학렬 경제부총리는 주영을 찾아왔다고 합니다."

### 대비 전환
이전 상황과 대조적인 새 상황 제시.
> "하지만 여전히 회사 내부에서는 회의론이 끊이지 않았다고 합니다."

## 4. 클로징 패턴

### 감성 마무리 (인물/브랜드)
> "지금까지 그 시절, 그 겨울, 우리들의 마음을 뜨겁게 만들었던 피겨 여왕, 김연아 선수에 대해 알아봤습니다."

공식: **"지금까지 [수식어] + [주제]에 대해 알아봤습니다"**

### 간결 마무리 (일반상식)
> "오늘 영상 여기까지입니다."

### 전망 마무리 (시사/기술)
> "앞으로 또 어떤 모습으로 우리 앞에 나타나게 될 것인지~"

### 시리즈 예고 (장편)
> "다음 편에서 계속됩니다."

## 5. 숫자의 힘

구체적 숫자로 스케일감과 신뢰성을 동시에 확보한다.

- 연도: "1954년 1월 21일"
- 수량: "26개월간 9만3천 해리"
- 점수: "228.56점"
- 금액: "한 켤레에 150만 원인 스케이트화"
- 비교: "디젤 잠수함 시속 11~15km vs 핵잠수함 시속 37~47km"

**"무려"와 조합**: "무려 20점 이상의 큰 점수 차이로"

## 6. 페이싱

- 데이터/팩트 밀집 구간 뒤에는 **스토리/감정 구간** 배치
- 3~4개 씬마다 **브리딩 포인트** (일화, 대사 인용, 비유)
- 챕터 전환 시 "그렇게" 매듭 문장으로 호흡 정리
- 짧은 문장 연타(2~3회) → 긴 문장으로 전환 = 리듬감

## 7. 심화 규칙 (NotebookLM 분석 기반)

586편 원고를 NotebookLM으로 심층 분석한 결과, 고성과 영상에서 공통적으로 발견되는 패턴을 강화 규칙으로 정리한다. 기존 규칙과 겹치는 부분은 **강도를 높이는 방향**으로 적용한다.

### 15-1. 입체적 인물 묘사 (필수)
- 인물 서사에서 **성공 + 실패 + 고뇌** 3요소를 모두 다뤄야 한다
- 성공만 나열하면 **감점** — 실패/좌절 없는 인물 서사는 세모지가 아니다
- 예: 정주영의 조선업 도전 → 주변의 반대 → 내면의 갈등 → 극복
- 체크: "이 인물이 어떤 실패/고뇌를 겪었는지" 최소 1회 이상 서술

### 15-2. 현재와의 연결 (필수)
- 과거 이야기는 반드시 **현재에 미친 영향**으로 착지해야 한다
- 패턴: 과거 사건 → "그리고 이것은 오늘날 ~에 영향을 미치고 있습니다"
- 예: 한명회의 정치 → 면리제(행정구역 체계)가 현재까지 이어짐
- "그래서 뭐?" 질문에 답하지 못하는 역사 서술은 금지

### 15-3. 이면의 진실 파헤치기
- **"공식 기록과 다른 사실"** 서사 장치를 적극 활용
- 예: "역사 교과서에는 ~라고 나와 있지만, 실제로는..."
- 예: "우리가 알고 있는 ~의 이미지와 달리, 그의 실제 모습은..."
- 시청자의 기존 인식을 깨뜨리는 반전이 세모지의 핵심 매력

### 15-4. 데이터와 근거 기반
- 주장에는 반드시 **구체적 출처/수치**를 동반
- 실록 날짜: "조선왕조실록 세종 12년 3월 15일 기록에 따르면"
- 보고서 수치: "당시 매출 2,340억 원, 영업이익률 12.3%"
- 인용: "~의 회고록에서 밝힌 바에 의하면"
- 기존 9번(숫자의 힘)보다 **출처 명시**를 더 강하게 요구

### 15-5. 서사 구조 공식
```
트렌드(입구) → 심층 지식(본문) → 현재적 통찰(결론)
```
- **입구**: 현재 화제/트렌드에서 시작하여 시청자의 관심을 끈다
- **본문**: 표면 아래의 역사·맥락·이면을 깊이 파헤친다
- **결론**: 과거의 이야기가 현재/미래에 갖는 의미로 마무리한다
- 이 3단 구조가 세모지 고성과 영상의 공통 뼈대

## 8. 씬 분할 — 원고 작가는 하지 않음

**원고에 씬 번호(`## Scene N:`)나 씬 구분선(`---`)을 넣지 않는다.**
씬 분할은 visual-composer가 나레이션 텍스트를 분석하여 자동으로 수행한다.

원고 작가가 할 일:
- 챕터 내에서 빈 줄로 호흡을 구분 (씬 경계 힌트가 아님)
- 자연스러운 서사 흐름에만 집중

visual-composer가 참고하는 분할 신호 (원고 작가가 의식할 필요 없음):
- "그런데", "하지만", "한편" 등 전환어
- 새로운 인물 소개
- 시간/장소 전환
- "그렇게" 매듭 후 새로운 서사 시작
- 볼드체 클라이맥스

## 9. VIZ/IMG 마커 — 사용 금지

기존 `writing-style` 4번, 5번과 동일.
원고 작성자는 **나레이션 텍스트 작성에만 집중**합니다.
