# Direction — 이로미즘 (연출)

씬을 어떻게 자를 것인가의 규칙입니다. **원고 작가는 이 스킬을 쓰지 않습니다** —
씬분할(`step_2`) 단계의 것입니다.

> 구성은 `narrative-iromism`, 문체는 `voice-iromism`.

> **⚠️ 조건부 적용**: `writing_style`이 `iromism`일 때만 적용합니다.

---

## 1. 씬 분할 규칙

판단 자료는 공유 스킬 `scene-splitting`이다(혼자 서는가 → 화면이 바뀌는가 → 길이).
이로미즘에서 특히 볼 것:

- **한 씬 = 한 장면.** 텍스트로 설명하려 하지 말고 그림으로 보여 줄 씬을 만든다
- 자문자답은 질문이 화면을 세울 때 질문 씬 + 답 씬으로 나눈다. 질문이 답 없이 서지 않으면 묶는다
- 반전 접속어는 지움 실험으로 판정한다 — 무조건 가르지 않는다
- 이로미즘 씬은 대개 1~3문장, 80자 안팎이다(관찰값). 넘으면 화면이 둘 필요한지 다시 본다
