# Writing Style — 세모지

세상의모든지식 유튜브 채널 586편 원고를 분석하여 추출한 나레이션 문체 가이드입니다.

> **⚠️ 조건부 적용**: `art_style.json`의 `name`에 "세모지" 또는 "semoji"가 포함될 때만 이 스킬을 적용합니다.
> 다른 아트스타일일 경우 이 스킬의 모든 규칙을 **무시**하고 기본 `writing-style` 또는 해당 스타일의 스킬을 따르세요.

적용 시 `writing-style`의 문체/후킹/페이싱 규칙을 **오버라이드**합니다.

**참조 에이전트**: write-manuscript, qa-reviewer

## 1. 핵심 DNA — 3대 서사 장치

세모지 원고를 관통하는 3가지 시그니처 장치. **모든 원고에 반드시 포함**해야 한다.

### 1-1. "그런데" 반전
서사 전환점에서 "그런데" 또는 "그런데,"를 **단독 행**으로 배치.
시청자의 기대를 깨고 새로운 방향을 제시한다.

```
(이전 서사)

그런데
(반전 내용)
```

- 편당 **3~7회** 사용
- 변형: "그런데 말입니다.", "그런데,", "그런데"
- 위치: 도입부 전환, 챕터 내 전환점, 클라이맥스 직전

### 1-2. "하지만" 역전 리듬
긍정적 흐름 → "하지만" → 장애물/역경 → 극복의 순환 구조.
한 원고에 **2~5회** 반복하여 긴장-이완 리듬을 생성한다.

> "하지만 이런 주영의 뜻에 주변 사람들은 건설회사에서 무슨 조선업까지 욕심을 내냐며 혀를 내둘렀다고 합니다."

### 1-3. "그렇게" 매듭
한 단락의 서사가 완결될 때 "그렇게"로 시작하는 문장으로 매듭.
편당 **5~10회** 사용.

> "그렇게 블루리본 스포츠는 나이키로 탈바꿈하게 됩니다."
> "그렇게 연아와 마오의 통산 전적은 10승 6패로 마무리됩니다."

## ⭐ 참조 원고 — 세모지 브랜드백과 문체 예시

아래는 실제 세모지 영상 원고입니다. **이 톤과 흐름을 반드시 따르세요.**
뚝뚝 끊어지는 건조한 문장이 아니라, 자연스럽게 흘러가는 스토리텔링입니다.

**예시 1 — 스타벅스 (도입부):**
> 여러분은 스타벅스에서 커피를 사신 적 있으신가요? 그런데 하워드 슐츠는 커피를 팔려고 한 게 아니었습니다. 그가 정말로 팔고 싶었던 것은 '제3의 공간'이었죠. 오늘은 시애틀의 작은 커피 원두 가게에서 시작해 전 세계 3만 개가 넘는 매장을 운영하는 글로벌 기업이 된 스타벅스의 놀라운 이야기를 들려드리려고 합니다.

**예시 2 — 스타벅스 (전환):**
> 하지만 진짜 전환점은 1983년 이탈리아 출장에서 일어났습니다. 밀라노의 작은 에스프레소 바에 들어선 슐츠는 충격을 받았죠. 사람들이 단순히 커피를 마시는 게 아니라, 대화를 나누고, 신문을 읽고, 친구를 만나고 있었습니다.
>
> "이거야! 이게 바로 미국에 필요한 거야!"

**예시 3 — 아식스 (도입부):**
> 일본 청소년들에겐 '꿈의 운동화'로, 스포츠 선수들에겐 '땀의 운동화'로 불리는 운동화가 있습니다. 바로 아식스인데요.
>
> 그런데 최근, 아식스가 스포츠 분야를 넘어 MZ들 사이에서 패션 아이템으로 그 인기가 심상치 않다고 합니다.

**예시 4 — 아식스 (반전):**
> 그런데 아식스는 불과 2~3년 전만 해도 다소 오래된 브랜드 이미지에 일본 불매운동까지 겹쳐 국내에서는 패션 아이템으로는 언급조차 되지 않던 브랜드였는데요.
>
> 그런데 최근, 아식스코리아의 2023년 영업이익은 136억 원으로 2022년 대비 394%나 증가해 시장에 놀라움을 안겨줬습니다.

**핵심 — 이 문체의 DNA:**
- 문장이 **길고 자연스럽게 흘러감** (뚝뚝 끊지 않는다)
- "~인데요", "~었죠", "~거든요"로 **다음 문장을 예고**하며 연결
- **에피소드가 감정적으로 연결** (사실 나열이 아닌 이야기)
- **직접 인용**("이거야!")으로 생동감
- "그런데" 반전이 **다음 단락과 자연스럽게 이어짐**
- 수치도 **감탄과 함께** ("무려 394%나", "놀랍게도")

## 2. 문체 규칙

### 2-1. 톤: 3인칭 전달체
- 기본 어미: **~습니다, ~입니다** (격식체 기반)
- 공감/구어 혼용: ~거든요, ~거죠, ~잖아요, ~인 거예요
- 전달체: **~다고 합니다, ~했다고 합니다** (이야기를 듣는 느낌)
- 팩트 전달은 "~습니다", 공감 유도는 "~거죠"

### 2-2. 문장 설계
- 한 문장 = 나레이션 1호흡
- 짧은 문장(10~30자)과 중간 문장(30~60자) 교차
- 핵심 문장은 **단독 행** 배치
- 긴 문장은 줄바꿈으로 호흡 분리:
```
1966년 대한조선공사에서 자체 기술로 건조한
2,600GT급 화물선 신양호가 만들어졌고,
```

### 2-3. 강조/감탄 표현
| 표현 | 용도 | 사용 위치 |
|------|------|----------|
| **"바로"** | 핵심 등장 직전 | "이것이 바로 ~입니다" |
| **"무려"** | 숫자 강조 | "무려 228.56점으로" |
| **"그야말로"** | 감탄/클라이맥스 | "그야말로 기적과도 같은 일" |
| **"이것은 단순한 ~이 아니었습니다"** | 의미 부여 | 챕터 말미 |
| **"~라고 합니다"** | 전해지는 이야기 | 일화/에피소드 서술 |

### 2-4. 금지 표현
- 번역체 ("~것이 사실이다", "~함에 있어서")
- 과도한 수식어 ("매우 놀라운 혁명적인")
- 논문체 ("~에 의하면", "~것으로 사료된다")
- 영어 남용 (적절한 한국어 대체 우선)

## 3. 도입부 후킹 (첫 30초)

주제 유형에 따라 **최적의 후킹 패턴**을 선택한다.

### 패턴 A: 규모 제시형 (브랜드)
구체적 숫자로 스케일을 제시 → 주제 소개.
> "전 세계 약 200개의 국가에서 하루 평균 18억 명의 사람들이 마시는 음료가 있습니다."

### 패턴 B: "한 사내아이가 태어납니다" (브랜드/인물 1편)
창업자/인물의 출생부터 시작하는 서사형 도입.
> "1910년 2월 12일, 이들 부부 사이에서 한 사내아이가 태어납니다. 이 아이가 바로 훗날 삼성그룹의 초대 회장이 되는 호암 이병철입니다."

### 패턴 C: 시사/트렌드 연결형 (일반상식)
현재 화제 사건 → 궁금증 유발 → 본론.
> "2026년 2월, 한국 극장가에 사극 한 편이 돌풍을 일으켰습니다."

### 패턴 D: 질문형 (일반상식/과학)
일상적 현상에 "왜?"를 던짐.
> "프리랜서가 언제부터 존재했는지 아시나요?"
> "도대체 커피와 설탕과 물에게 무슨 일이 일어났길래 달고나로 변해버린 걸까?"

### 패턴 E: 뉴스 팩트 충격형 (지정학/시사)
구체적 날짜 + 충격적 사실 → "그런데 말입니다" 반전.
> "2025년 10월 30일, 도널드 트럼프 미국 대통령이 한국의 핵추진 잠수함 건조를 공식 승인했다는 소식이..."

### 패턴 F: 시리즈 연결형 (장편 시리즈)
> "지난 영상에 이어 현대 6편 바로 시작하겠습니다."

### 도입부 공통 규칙
1. **30초 이내** (3~5문장)
2. 반드시 **"그런데" 또는 질문**으로 전환점 생성
3. 전환 후 **(타이틀)** 삽입 → 본격 스토리 시작

## 4. 서사 구조 — 카테고리별

### 4-1. 브랜드/기업 서사
```
[후킹] → (타이틀) →
Ch1. 기원/출생 → Ch2. 초기 도전 → Ch3. 위기 →
Ch4. 핵심 전환점 → Ch5. 성장/확장 → Ch6. 현재/레거시
```
- 챕터 수: **4~7개**
- 창업 서사 공식: 출생연도 + 출생지 → "한 사내아이가 태어납니다" → "훗날 ~이 되는 인물"
- 감정 곡선: 가난→좌절→기회→성공→위기→재도약

### 4-2. 인물 전기
```
[후킹] → (타이틀) →
Ch1. 어린 시절 → Ch2. 재능 발견/첫 도전 →
Ch3. 역경/좌절 → Ch4. 극복/성공 →
Ch5. 더 큰 도전 → Ch6. 클라이맥스 → Ch7. 레거시/마무리
```
- 챕터 수: **5~9개**
- "하지만" 역전이 **2~5회** 반복
- 가족 에피소드: 독립 챕터형 또는 삽화형으로 삽입
- 라이벌 대비 구조 활용 (김연아 vs 아사다 마오)

### 4-3. 일반상식/과학
```
[질문/트렌드 후킹] → (타이틀) →
현상 소개 → 원리 A 설명 → 원리 B 적용 →
역사적 맥락 → 현재 상황 → 결론
```
- 챕터 유무: **55%가 챕터 없음** (자연스러운 흐름)
- 전문 용어: 등장 즉시 일상어로 번역
- 비유 활용: 복잡한 개념 → 일상 사물에 대입

### 4-4. 지정학/역사
```
[뉴스 팩트 후킹] → (타이틀) →
현재 상황 → 역사적 기원 → 시대별 발전 →
핵심 전환점 사건 → 현재 상황 → 전망
```
- 시간 점프 시 연도 명시: "그리고 [연도]"
- 숫자/데이터로 스케일감 확보

## 5. 챕터 전환 패턴

### 시간 점프
> "그리고 2004년 12월, 헬싱키에서 열린 <주니어 그랑프리 파이널> 대회에서..."

### "그렇게" 매듭 → 새 챕터
> "그렇게 끈질긴 설득 끝에 마음을 돌린 연아는..." → 다음 챕터

### "한편" / "이에" 시점 전환
> "한편 이 무렵 김학렬 경제부총리는 주영을 찾아왔다고 합니다."

### 대비 전환
이전 상황과 대조적인 새 상황 제시.
> "하지만 여전히 회사 내부에서는 회의론이 끊이지 않았다고 합니다."

## 6. 직접 인용 (대사 활용)

핵심 순간에 인물의 말을 **직접 인용**하여 생동감 부여.

### 사용 위치
- **클라이맥스**: 역사적 순간의 한마디
- **감정적 전환점**: 인물의 내면 고백
- **권위 부여**: 제3자의 평가

### 예시
> "핵동력으로 항해 중" (릭오버 제독)
> "김연아가 없었다면 나도 이렇게 잘할 수 없었다" (아사다 마오)
> "앞으로 정 회장이 어떤 사업을 한다고 해도 전부 거절하시오" (박정희)

## 7. 클로징 패턴

### 감성 마무리 (인물/브랜드)
> "지금까지 그 시절, 그 겨울, 우리들의 마음을 뜨겁게 만들었던 피겨 여왕, 김연아 선수에 대해 알아봤습니다."

공식: **"지금까지 [수식어] + [주제]에 대해 알아봤습니다"**

### 간결 마무리 (일반상식)
> "오늘 영상 여기까지입니다."

### 전망 마무리 (시사/기술)
> "앞으로 또 어떤 모습으로 우리 앞에 나타나게 될 것인지~"

### 시리즈 예고 (장편)
> "다음 편에서 계속됩니다."

## 8. 볼드체 = 영상 강조 마커

원고에서 **볼드 처리된 문장**은 영상에서 텍스트 강조/특수 연출이 들어가는 부분이다.

### 사용 대상
- **클라이맥스 순간**: 결정적 성취, 역사적 사건
- **핵심 메시지**: 원고의 테마를 압축한 문장
- **직접 인용**: 인물의 중요한 발언
- **대비/반전**: 기대를 뒤집는 순간

### 빈도
- 챕터당 **1~3회**
- 남용 금지 — 정말 강조할 때만 사용

## 9. 세모지 연출 규칙 (Layout + 이미지)

### 데이터 시각화 적극 활용
세모지는 **수치와 팩트 중심** 채널이다. 모든 챕터에 최소 1개 이상의 데이터 레이아웃을 포함한다.

| Layout | 용도 | 필수 데이터 |
|--------|------|-----------|
| `items_list` | 리스트형 정보 나열 | items 배열 |
| `counter` | 핵심 숫자 강조 (매출, 성장률) | values + unit |
| `icon_stat` | 아이콘 + 수치 조합 | items + values + icon |
| `bar` / `pie` | 비교/비중 차트 | items + values + unit |
| `before_after` | 변화 비교 (인수 전/후) | items(2개) + values(2개) |
| `metric_wall` | 핵심 지표 모아보기 | items + values 복수 |
| `timeline` | 시간순 사건 나열 | items(연도+사건) |

### 이미지 연출 — 2단계 구조 (기본 연출 100% + 우선순위 배정)

**⚠️ 1단계: 모든 씬에 `imageAsset.prompt` (장면 연출) 작성 = 100% 필수**

어떤 레이아웃이든 상관없이, 모든 씬에 `imageAsset.prompt`로 해당 장면의 시각적 묘사를 작성한다.
데이터 씬이어도, 클로징 씬이어도, "이 장면을 이미지로 그린다면 어떤 장면인가"를 작성한다.

```json
// 데이터 씬이어도 장면 연출 작성
{
  "layout": "bar",
  "items": ["2021년", "2022년", "2023년"],
  "values": [30, 413, 1396],
  "imageAsset": {
    "source": "generate",
    "prompt": "가파르게 상승하는 매출 그래프 앞에서 자신감 있게 서 있는 30대 한국 남성 CEO",
    "placement": "background"
  }
}
```

**2단계: 매니페스트 반영 우선순위 배정**

모든 씬에 장면 연출이 있지만, 최종 영상에서는 씬 성격에 맞는 방식이 우선된다:

| 씬 성격 | 최종 반영 우선순위 | imageAsset 역할 |
|---------|-----------------|----------------|
| cinematic (감성/전환) | **이미지 생성 우선** | fullscreen |
| 인물 등장 | **이미지 생성/검색 우선** | fullscreen 또는 side |
| 데이터 (bar/counter/items) | **데이터 레이아웃 우선** | background (배경으로 깔림) |
| 맵씬 | **지도 우선** | background |
| headline_only | **텍스트 우선** | background (있으면 깔림) |

→ 사용자가 대시보드에서 우선순위를 전환할 수 있음 (이미지 생성 ↔ 데이터 레이아웃)

**imageAsset.source 선택 기준:**
- `search`: 실존 인물, 브랜드 로고, 실제 제품, 실제 건물/장소
- `generate`: 역사적 장면 재현, 추상적 개념, 분위기 이미지, 캐릭터 등장 장면

### 파이프라인 처리
- **TTS**: `korean_tts_preprocessor.py`가 `**` 마커를 자동 제거 → 자막에 포함 안 됨
- **visual-composer**: 볼드 문장 감지 → `emphasis: "keyword"`, `reveal: "dramatic_pause"` 등 극적 연출 적용
- **원고 작가는 볼드만 쓰면 됨** — 나머지는 파이프라인이 처리

## 9. 숫자의 힘

구체적 숫자로 스케일감과 신뢰성을 동시에 확보한다.

- 금액: "한 켤레에 150만 원인 스케이트화"
- 비교: "디젤 잠수함 시속 11~15km vs 핵잠수함 시속 37~47km"

**"무려"와 조합**: "무려 20점 이상의 큰 점수 차이로"

## 10. 페이싱

- 데이터/팩트 밀집 구간 뒤에는 **스토리/감정 구간** 배치
- 3~4개 씬마다 **브리딩 포인트** (일화, 대사 인용, 비유)
- 챕터 전환 시 "그렇게" 매듭 문장으로 호흡 정리
- 짧은 문장 연타(2~3회) → 긴 문장으로 전환 = 리듬감

---

## 11. 씬 분할 — 원고 작가는 하지 않음

**원고에 씬 번호(`## Scene N:`)나 씬 구분선(`---`)을 넣지 않는다.**
씬 분할은 visual-composer가 나레이션 텍스트를 분석하여 자동으로 수행한다.

원고 작가가 할 일:
- 챕터 내에서 빈 줄로 호흡을 구분 (씬 경계 힌트가 아님)
- 자연스러운 서사 흐름에만 집중

visual-composer가 참고하는 분할 신호 (원고 작가가 의식할 필요 없음):
- "그런데", "하지만", "한편" 등 전환어
- 새로운 인물 소개
- 시간/장소 전환
- "그렇게" 매듭 후 새로운 서사 시작
- 볼드체 클라이맥스

원고 작성자는 **나레이션 텍스트 작성에만 집중**합니다.

## NotebookLM 분석 기반 강화 규칙

586편 원고를 NotebookLM으로 심층 분석한 결과, 고성과 영상에서 공통적으로 발견되는 패턴을 강화 규칙으로 정리한다. 기존 규칙과 겹치는 부분은 **강도를 높이는 방향**으로 적용한다.

### 15-1. 입체적 인물 묘사 (필수)
- 인물 서사에서 **성공 + 실패 + 고뇌** 3요소를 모두 다뤄야 한다
- 성공만 나열하면 **감점** — 실패/좌절 없는 인물 서사는 세모지가 아니다
- 예: 정주영의 조선업 도전 → 주변의 반대 → 내면의 갈등 → 극복
- 체크: "이 인물이 어떤 실패/고뇌를 겪었는지" 최소 1회 이상 서술

### 15-2. 현재와의 연결 (필수)
- 과거 이야기는 반드시 **현재에 미친 영향**으로 착지해야 한다
- 패턴: 과거 사건 → "그리고 이것은 오늘날 ~에 영향을 미치고 있습니다"
- 예: 한명회의 정치 → 면리제(행정구역 체계)가 현재까지 이어짐
- "그래서 뭐?" 질문에 답하지 못하는 역사 서술은 금지

### 15-3. 이면의 진실 파헤치기
- **"공식 기록과 다른 사실"** 서사 장치를 적극 활용
- 예: "역사 교과서에는 ~라고 나와 있지만, 실제로는..."
- 예: "우리가 알고 있는 ~의 이미지와 달리, 그의 실제 모습은..."
- 시청자의 기존 인식을 깨뜨리는 반전이 세모지의 핵심 매력

### 15-4. 데이터와 근거 기반
- 주장에는 반드시 **구체적 출처/수치**를 동반
- 실록 날짜: "조선왕조실록 세종 12년 3월 15일 기록에 따르면"
- 보고서 수치: "당시 매출 2,340억 원, 영업이익률 12.3%"
- 인용: "~의 회고록에서 밝힌 바에 의하면"
- 기존 9번(숫자의 힘)보다 **출처 명시**를 더 강하게 요구

### 15-5. 서사 구조 공식
```
트렌드(입구) → 심층 지식(본문) → 현재적 통찰(결론)
```
- **입구**: 현재 화제/트렌드에서 시작하여 시청자의 관심을 끈다
- **본문**: 표면 아래의 역사·맥락·이면을 깊이 파헤친다
- **결론**: 과거의 이야기가 현재/미래에 갖는 의미로 마무리한다
- 이 3단 구조가 세모지 고성과 영상의 공통 뼈대
