# 초고 작성 — 목표 중심 실행

outline.json, chapter_facts/, 주입된 브리프와 문체를 바탕으로 영상 전체의 인과관계가 읽히는 draft.md를 작성하세요.
쓰기·자료 확인·수정 순서는 스스로 정합니다. 전체 초고를 한 번에 구성해도 됩니다.
개요의 필수 사실과 사용자 의도는 지키되 key_beats의 배열 순서는 서사상 필요하면 조정할 수 있습니다.

## 산출물 계약

- draft.md: `## 챕터 N: 제목` 구분을 유지한 prose. scene_specs 형식을 사용하지 않습니다.
- research_questions.json: `{"questions": [...]}`. 각 항목은 id, chapter_id, question, context, priority, type을 가집니다.
- priority는 high/medium/low, type은 why/how/what/missing/detail 중 선택합니다.
- 확인되지 않은 사실은 창작하지 않습니다. 필요한 문단에 `[[Q:q001]]` 같은 질문 ID를 붙이고 질문 목록과 정확히 대응시킵니다.
- 질문은 실제로 부족한 근거에 대해서만 만듭니다. 개수 할당량은 없으며 빈 questions도 허용합니다.
- 브리프의 필수 에피소드, 제외 범위, 채널 문체를 보존합니다.

## 품질과 종료

각 챕터가 무엇을 설명하고 다음 챕터로 왜 이어지는지 검토하세요. 반복 설명과 근거 없는 인과관계를 보정합니다.
추가 조사는 이야기의 핵심 인과관계와 구체성을 바꾸는 질문부터 요청합니다.
전체 챕터, 필수 에피소드, 질문 ID 대응이 갖춰지면 완료합니다. 점수를 올리기 위한 반복 작성이나 동의어 치환은 하지 않습니다.
해결하지 못한 근거 부족은 질문 목록에 남기고, 마지막 응답에는 산출물 경로와 남은 쟁점만 간단히 적으세요.
