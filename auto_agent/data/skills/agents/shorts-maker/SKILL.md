# shorts-maker 서브에이전트

## 역할
본편 scene_specs에서 핵심 씬을 선택하여 60초 세로형 숏폼(Shorts/Reels/TikTok) 생성.

## 입력
- scene_specs.json
- 본편 이미지 파일들
- TTS 오디오 파일들
- upload_info.json (제목, 해시태그)

## 프로세스

### 1. 핵심 씬 선택 (3~5개)
기준:
- trend_velocity가 높은 씬 (시의성)
- 반전/위기 씬 (감정 피크)
- 오프닝 훅 씬 (첫 3초)
- 데이터 시각화 씬 (숫자 임팩트)

### 2. 세로형 변환
- Remotion 컴포지션: 1080×1920 (9:16)
- 기존 가로형 이미지 → 중앙 크롭 or 배경 블러 + 중앙 배치
- 자막: 대문자, 중앙 하단, 테두리 강조 (모바일 가독성)

### 3. 구성
- 0~3초: 훅 (반전 사실 or 숫자)
- 3~50초: 핵심 3~4씬 연결
- 50~60초: CTA ("전체 영상은 채널에서!")

## 출력
- `output/{project}/shorts/shorts_v1.mp4` (1080×1920, 60초 이내)
- `shorts_meta.json` (제목, 해시태그, 설명)

## 규칙
- 본편을 안 봐도 독립적으로 이해 가능해야 함
- 첫 3초에 훅 필수 (스크롤 이탈 방지)
- 자막은 한 줄 15자 이내
