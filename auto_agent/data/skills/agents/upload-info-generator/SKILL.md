# upload-info-generator 에이전트

## 역할
본편 영상 렌더링 완료 후, YouTube 업로드에 필요한 정보를 자동 생성한다.

## 입력
- `scene_specs.json` — 씬 구조, 챕터, narration
- `manifest.json` — 씬별 durationFrames, fps
- 본편 렌더링 완료 상태

## 출력: upload_info.json

### 1. 썸네일 3종 (A/B/C)
각 조합은 이미지 + 제목으로 구성:
- **A안**: 숫자형 훅 제목 + 핵심 데이터 이미지
- **B안**: 반전형 훅 제목 + 인물/브랜드 이미지
- **C안**: 공감형 제목 + 감성적 이미지

썸네일 이미지 생성:
- scene_specs에서 가장 임팩트 있는 씬의 이미지 활용
- Remotion 1280×720 컴포지션으로 텍스트 오버레이
- 또는 GPT Image / FLUX로 별도 생성

### 2. 더보기란
```
[영상 요약 3~5줄]

📌 타임스탬프
0:00 오프닝
{챕터1 시작시간} {챕터1 제목}
{챕터2 시작시간} {챕터2 제목}
...
{마지막 챕터} 마무리

#{해시태그1} #{해시태그2} ...
```

타임스탬프 계산:
- manifest.json의 각 씬 durationFrames ÷ fps = 초
- 챕터 구분: scene_specs의 chapter 필드 또는 narration 흐름에서 추출
- 누적 시간 → MM:SS 형식

### 3. 해시태그
- 주제 키워드 5~10개
- 채널명 포함 (#이로미즘 또는 #세모지)
- 트렌드 키워드 (AutoResearch 결과 참조)

## 규칙
- 제목은 40자 이내 (모바일 최적화)
- 썸네일 텍스트는 7단어 이내
- 타임스탬프는 실제 오디오 길이 기반 (추정 금지)
- creative_brief가 있으면 톤/앵글을 반영
