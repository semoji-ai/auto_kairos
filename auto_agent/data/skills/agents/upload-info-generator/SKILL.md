# upload-info-generator 에이전트

## 역할
본편 영상 렌더링 완료 후, YouTube 업로드에 필요한 정보를 자동 생성한다.

## 입력
- `scene_specs.json` — 씬 구조, 챕터, narration
- `manifest.json` — 씬별 durationFrames, fps
- 본편 렌더링 완료 상태

## 출력: upload_info.json

### 1. 썸네일 3종 (A/B/C) — 배경 이미지 + 오버레이 텍스트 분리

**Step 1: 배경 이미지 생성 (FAL AI nano-banana-2)**
- 콘텐츠의 "어필 포인트"를 시각화하는 배경 이미지
- 1920×1080, 아트스타일 프리셋 적용
- **텍스트 포함 금지** — 순수 이미지만
- 3종 모두 같은 배경 or 다른 앵글의 배경

**Step 2: 오버레이 텍스트 (Remotion 합성)**
- 배경 이미지 위에 제목 텍스트 오버레이
- 채널 디자인 토큰 (폰트, 색상, 그림자) 적용
- A/B/C 각각 다른 제목:
  - A안: 숫자형 훅 ("75조원이 들어오는데...")
  - B안: 반전형 훅 ("당신이 몰랐던 진실")
  - C안: 공감형 훅 ("왜 지금 중요한가")
- 1920×1080 PNG export

**썸네일 제목 원칙:**
- 7단어 이내 (모바일 가독성)
- 핵심 숫자 or 반전 사실 포함
- 콘텐츠의 가장 클릭을 유도하는 포인트

### 2. 더보기란
```
[영상 요약 3~5줄]

📌 타임스탬프
0:00 오프닝
{챕터1 시작시간} {챕터1 제목}
{챕터2 시작시간} {챕터2 제목}
...
{마지막 챕터} 마무리

#{해시태그1} #{해시태그2} ...
```

타임스탬프 계산:
- tts_results.json의 각 씬 duration → 누적 시간 계산
- 챕터 구분: scene_specs의 chapter 필드 기준
- 누적 시간 → MM:SS 형식
- ⚠️ **챕터 제목 필수** — "챕터 2" 같은 번호만 쓰지 말 것. scene_specs에서 해당 챕터의 title 또는 첫 씬의 headline/concept에서 제목 추출
- ⚠️ `{{텍스트}}` 형태의 Remotion 마크업은 **반드시 제거** — 더보기란에 `{{`, `}}` 포함 금지. 순수 텍스트만 사용

### 3. 해시태그
- 주제 키워드 5~10개
- 채널명 포함 (#이로미즘 또는 #세모지)
- 트렌드 키워드 (AutoResearch 결과 참조)

## 규칙
- 제목은 40자 이내 (모바일 최적화)
- 제목에 핵심 수치를 반드시 포함 (예: "3억→10조", "1위") — 수치 누락 금지
- 썸네일 텍스트는 7단어 이내
- 타임스탬프는 실제 오디오 길이 기반 (추정 금지)
- `{{}}` Remotion 마크업 제거 필수 — 순수 텍스트만
- creative_brief가 있으면 톤/앵글을 반영
