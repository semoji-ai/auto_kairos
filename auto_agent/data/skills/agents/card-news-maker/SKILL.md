# card-news-maker 서브에이전트

## 역할
본편 scene_specs에서 핵심 인사이트를 추출하여 카드뉴스(캐러셀) 10장 생성.

## 입력
- scene_specs.json (headline, narration, 이미지)
- upload_info.json (제목, 해시태그)

## 프로세스

### 슬라이드 구성 (10장)
1. **커버**: 제목 + 채널명 + 배경 이미지
2~8. **본문**: 각 핵심 인사이트 1개씩
   - 상단: 소제목 (bold)
   - 중앙: 핵심 문장 1~2줄
   - 하단: 보조 설명 or 데이터
   - 배경: 해당 씬 이미지
9. **요약**: 전체 결론 3줄
10. **CTA**: "전체 영상 보러가기" + 채널 QR/링크

### 디자인
- Remotion 1080×1080 컴포지션
- 채널 디자인 토큰 적용 (색상, 폰트)
- 텍스트 가독성: 배경 위 반투명 오버레이

## 출력
- `output/{project}/card_news/slide_01.png` ~ `slide_10.png`
- `card_news_meta.json` (슬라이드별 텍스트, 순서)

## 규칙
- 슬라이드 1장 = 1개 인사이트 (과부하 금지)
- 텍스트: 슬라이드당 30자 이내 (핵심만)
- 이미지: 본편 씬 이미지 재활용 (추가 생성 최소화)
