# Editorial Brief DNA — 5대 품질 레버

세모지 586편 원고 분석(`writing-style-semoji.md` 15-1~15-5) 기반으로 추출한
**기획 단계에서 확정되어야 할 품질 레버 5가지**.

이 5개가 editorial_brief에 구체적으로 박혀 있어야 원고·씬 분석이 기계적 체크박스에
떨어지지 않고 실제 깊이를 가진다.

---

## Lever 1. narrative_arc — 3단 서사 공식

**공식**: 트렌드(입구) → 심층 지식(본문) → 현재적 통찰(결론)

```json
"narrative_arc": {
  "entry_trend": "오늘 기준 화제/트렌드 — 시청자가 지금(프롬프트에 주입된 현재 날짜 기준) 검색하고 있거나 뉴스에서 보는 것",
  "deep_knowledge": "표면 아래의 역사/맥락/이면 — 본문에서 파헤칠 실제 지식",
  "present_insight": "과거 이야기가 오늘/미래에 갖는 의미 — 결론의 착지점"
}
```

### 구체성 기준

- ✅ entry_trend: 프롬프트에 주입된 **현재 날짜 기준** 최신 뉴스 (예: 오늘이 2026-04이면 "2026년 4월 주요 뉴스")
- ❌ entry_trend: "반도체 산업의 현재 상황" ← 추상, 트렌드 아님
- ❌ entry_trend: 훈련 데이터의 과거 시점(예: 오늘이 2026년인데 2024년 뉴스를 "현재"로 제시) — **오늘과 어긋나면 `needs_research` 플래그** + Stage 1 deepener가 실제 최신 뉴스로 교체

- ✅ deep_knowledge: "이건희의 1993년 프랑크푸르트 선언과 반도체 도박의 실제 경위"
- ❌ deep_knowledge: "삼성의 역사" ← 너무 광범위

- ✅ present_insight: "그때의 도박이 오늘 HBM 왕좌를 결정한 이유"
- ❌ present_insight: "삼성은 계속 성장했다" ← 구체 연결 없음

### 작성 체크

- 각 3단이 **검증 가능한 사실/사건**으로 기술되었는가?
- 3단이 **인과적으로 연결**되는가? (단순 3개 나열 ≠ 서사 아크)
- 시청자가 `entry_trend` → `deep_knowledge`로 유도되는 **심리적 궁금증**이 느껴지는가?

## Lever 2. human_truth — 입체적 인물 묘사 (3요소)

**원칙**: 인물/브랜드 서사는 반드시 **성공 + 실패 + 내면의 고뇌** 3요소를 모두 다룬다.
성공만 나열하면 세모지 고성과 공식에서 이탈한다.

```json
"human_truth": {
  "success": "주인공의 구체적 성취 (연도/수치/사건 단위)",
  "failure": "구체적 실패/좌절 에피소드 (무엇을, 언제, 왜 실패했는가)",
  "inner_conflict": "내면의 고뇌/갈등 — 회고록/인터뷰/증언 기반"
}
```

### 구체성 기준

- ✅ failure: "1984년 세미콘덕터 사업 1300억 원 적자, 이병철 사망 직전 철수 요구"
- ❌ failure: "사업이 어려웠다" ← 에피소드 단위 아님

- ✅ inner_conflict: "이건희 회고록 '제2창업' 中 '선대 회장이 반대한 사업에 내 운명 걸었다'"
- ❌ inner_conflict: "고민이 많았다" ← 증거 없음

### 적용 범위

- **인물 전기**: 필수 (주인공에 대해 작성)
- **브랜드/기업**: 필수 (창업자 또는 핵심 의사결정자에 대해 작성)
- **일반상식/지정학**: 선택 — 주요 인물이 등장하는 챕터가 있을 때만

### 작성 체크

- 실패가 **구체적 시점/액수/사건**으로 기술되었는가?
- 내면 갈등에 **출처(회고록/인터뷰 인용 힌트)**가 있는가?
- 성공 이전에 실패가 **먼저** 오는 서사 순서가 설계되었는가?

## Lever 3. hidden_truth — 이면의 진실 (반전 장치)

**원칙**: 시청자가 기존에 알고 있는 "공식 기록"이나 "상식"과 다른 **반전 사실**을
확보한다. 이게 세모지 채널의 핵심 매력이자 클릭/완시청의 주 동력.

```json
"hidden_truth": "시청자의 기존 인식을 깨뜨리는 반전 포인트 — '사실은 ~였다' 구조"
```

### 구체성 기준

- ✅ "교과서에는 이병철이 반도체 도박의 영웅으로 그려지지만, 실제로는 도박에 반대하다
   이건희에게 끝까지 굴복하지 않았고 사망 직전까지 철수를 요구했다"
- ❌ "삼성은 단순한 성공이 아니었다" ← 반전 내용 없음

- ✅ "정주영의 현대조선 500원짜리 거북선 일화는 실제로는 박정희가 차관을 보증해 준 덕분에
   성사된 것이지, 정주영 혼자의 담판이 아니었다"
- ❌ "우리가 모르는 사실이 있다" ← 뭐가 반전인지 불명

### 검증 질문

다음 질문에 모두 YES여야 진짜 반전:
- [ ] 시청자의 **기존 인식**이 먼저 성립하는가? (반전할 기반이 있나)
- [ ] 반전 내용이 **검증 가능한 출처**(실록/회고록/보고서)로 뒷받침되는가?
- [ ] 반전 후 시청자의 **감정 반응**(놀람/재평가)이 예상되는가?

### 안티패턴

- "알고 보면 더 대단한 사람" — 단순 칭찬 확장, 반전 아님
- "숨겨진 일화가 있습니다" — 내용 공개 없음, 클릭베이트
- "많은 사람이 모르는 사실" — 상식 수준이면 반전 아님

## Lever 4. present_connection — 현재와의 연결 (착지점)

**원칙**: 과거 이야기는 **반드시 오늘에 살아있는 영향**으로 착지한다.
"그래서 뭐?" 질문에 답하지 못하는 역사 서술은 세모지에서 금지.

```json
"present_connection": "과거 사건이 오늘날 어떻게 이어지고 있는가 — 결론의 구체 링크"
```

### 구체성 기준

- ✅ "1993년 프랑크푸르트 선언이 2024년 HBM 시장 점유율 55%로 이어진다"
- ❌ "그의 유산은 오늘날까지 남아있다" ← 추상

- ✅ "한명회가 도입한 면리제가 오늘날 대한민국 행정구역 체계(읍/면/리)의 원형"
- ❌ "역사적 의의가 크다" ← 구체 연결 없음

### 결론 패턴

- 과거 결정 → 현재 제도/산업/문화의 직접 근원
- 과거 인물의 철학 → 현재 기업/조직의 DNA
- 과거 사건 → 현재도 반복되는 동일 구조 (역사는 반복된다)

### 작성 체크

- "~이 오늘날 ~로 이어진다" 형태의 **구체 문장**이 작성되었는가?
- 현재 시점의 **검증 가능한 증거**(수치/제도명/회사명)가 있는가?
- 시청자의 **일상**과 연결되는 고리가 있는가?

## Lever 5. evidence_anchors — 증거 앵커

**원칙**: 모든 주장에 **구체적 출처/수치**를 사전 확보한다.
기획 단계에서 앵커가 없으면 Stage 1 리서치에서 반드시 채워야 할 `needs_research` 플래그를 단다.

```json
"evidence_anchors": [
  {
    "claim": "이건희가 1993년 프랑크푸르트에서 '마누라와 자식 빼고 다 바꿔라' 선언",
    "source_hint": "이건희 에세이 '생각 좀 하며 세상을 보자' 또는 당시 수행 임원 회고록",
    "status": "available"
  },
  {
    "claim": "1984년 세미콘덕터 누적 적자 1300억",
    "source_hint": "삼성전자 사업보고서 1984",
    "status": "needs_research"
  }
]
```

### status 3종

- `available`: 이미 출처가 특정되어 있음 (vault wiki에 있거나 공개 자료)
- `needs_research`: 기획 단계에서 추정, Stage 1/2_target에서 실물 확보 필요
- `risky`: 출처 특정 어려움 — 해당 주장 원고에서 회피하거나 hedging 표현 사용

### 앵커 밀도 기준

- **인물 전기**: 최소 5개 (주요 에피소드마다)
- **브랜드/기업**: 최소 4개 (핵심 의사결정 시점)
- **일반상식/지정학**: 최소 3개 (핵심 수치/날짜)

### 작성 체크

- 각 앵커가 **실존 가능성 있는 출처**를 힌트로 포함하는가?
- `needs_research` 앵커가 전체의 50% 이하인가? (너무 많으면 기획 미성숙)
- 가장 중요한 주장(hidden_truth, present_connection)이 앵커로 뒷받침되는가?

## Lever 6. coherence_spine — 맥락 일관성 (척추)

**원칙**: 영상은 **단 하나의 질문**(`spine_question`)에 답한다. 모든 막·모든 필수요소·모든 다른 레버는 그 질문의 답을 향해 **유기적으로 수렴**해야 한다. 한 영상에서 서로 다른 두 질문에 동시에 답하려 하면, 시청자가 영상을 본 뒤 "이게 무슨 영상이었지?"에 단답을 못한다.

> ⚠️ 이 레버는 **다른 모든 레버보다 먼저** 확정되어야 한다. spine 없이 narrative_arc/human_truth/hidden_truth를 작성하면 각각이 다른 질문을 향하기 시작한다 — 1956억 케이스의 실패 원인.

```json
"coherence_spine": {
  "spine_question": "이 영상이 답하는 단 하나의 질문 (한 문장)",
  "spine_answer": "그 질문에 대한 영상의 답 (한 문장, audience_takeaway와 정렬)",
  "layer_map": {
    "act1_hook": "1막이 spine_question을 어떤 각도로 여는가 (1줄)",
    "act2_body": "2막 본문이 spine_question에 어떤 증거/심화를 더하는가 (1줄)",
    "act3_landing": "3막 결론이 spine_question에 어떤 답으로 착지하는가 (1줄)"
  },
  "must_include_links": [
    {"item": "필수요소1", "spine_link": "이 요소가 spine_question에 어떻게 기여하는가 (1줄)"},
    {"item": "필수요소2", "spine_link": "..."}
  ]
}
```

### 다른 레버에 spine_link 강제

`coherence_spine` 자체뿐 아니라 모든 핵심 레버에 **spine_link** 필드를 첨부:

```json
"hidden_truth": {
  "content": "...",
  "spine_link": "이 반전이 spine_question 답에 어떻게 기여하는가"
},
"human_truth": { ..., "spine_link": "..." },
"present_connection": { "content": "...", "spine_link": "..." }
```

spine_link가 비어 있거나 spine_question과 무관하면 → 그 요소는 **다른 영상**으로 분리해야 함을 의미.

### 검증 질문 (전부 YES여야 통과)

- [ ] `spine_question`이 **한 문장**으로 명확히 답변 가능한가? (선언형 답변이 가능한가)
- [ ] 1막/2막/3막 각각의 `layer_map`이 spine_question을 향해 수렴하는가? (한 막이 다른 질문을 여는가?)
- [ ] 모든 `must_cover` 항목에 spine_link가 있는가?
- [ ] 각 spine_link를 빼면 spine_answer가 약해지는가? (NO면 그 요소는 분리 대상)
- [ ] `hidden_truth` / `human_truth` / `present_connection`이 모두 같은 spine_question을 보강하는가? (각자 다른 질문에 답하지 않는가?)
- [ ] 시청자가 영상을 본 뒤 "이 영상은 ___에 대한 것"의 빈칸을 **한 문장**으로 채울 수 있는가?

### 안티패턴 (즉시 REVISE)

- ❌ **이중 척추**: 한 영상에서 spine_question이 2개 이상 (예: "왜 자본이 쏠리는가?" + "AI 시대에 어떻게 살아남는가?" 동시 답변)
- ❌ **층 분리**: 1막은 A 질문, 2막은 B 질문, 3막은 C 답을 내림 → 시청자 혼란
- ❌ **장식형 필수요소**: must_cover 항목이 "주제는 맞지만 spine_question 답에는 기여 안 함" — 다른 영상으로 분리
- ❌ **spine 사후 작성**: 다른 레버 다 채운 다음에 spine_question을 끼워맞춤 → 강제 수정 흔적이 layer_map 모순으로 드러남
- ❌ **추상 spine**: "AI의 본질을 탐구한다" — 단답 가능한 구체 질문 아님

### 1956억 케이스 적용 예시

**잘못된 브리프 (실제 발생):**
- spine_question 후보 3개가 한 브리프에 공존: A "왜 1956억이라는 자본이 한 회사에 쏠렸는가?" / B "AI 혁신은 정체기인가?" / C "AI 시대에 어떻게 살아남는가?"
- 1막은 A를 열고, 2막은 B로 가고, 3막은 C로 착지 → 한 영상이 세 영상

**spine 게이트 통과 버전 (예):**
- spine_question: "왜 지금 1956억이 한 AI 회사에 쏠렸는가, 그것이 우리에게 무엇을 말하는가?"
- spine_answer: "혁신 정체기에 자본이 한 곳으로 모이는 구조적 패턴이며, 과거에도 반복된 신호다"
- C(생존 가이드)는 spine_link가 약함 → **다른 영상**으로 분리

## 6개 레버 상호 관계

```
                coherence_spine (척추)
                       ↑
                       │ 모든 레버는 이 질문에 수렴
       ┌───────────────┼───────────────┐
       │               │               │
narrative_arc      human_truth      hidden_truth
   (뼈대)         (인물 입체)       (본문 반전)
       │               │               │
       └───────────────┼───────────────┘
                       │
              present_connection (결론 착지)
                       ↑
                       │ (모든 주장은)
                       │
                evidence_anchors (전체 기반)
```

- **coherence_spine 없으면**: 다른 5레버가 각자 다른 질문에 답하기 시작 → 한 영상이 N영상으로 분열 (1956억 케이스)
- **narrative_arc 없으면**: 서사 구조 없는 사실 나열 → 이탈 증가
- **human_truth 없으면**: 성공 스토리 → 평면적 → 세모지 DNA 이탈
- **hidden_truth 없으면**: 공식 기록 반복 → 클릭/완시청 저하
- **present_connection 없으면**: "그래서 뭐?" 문제 → 교육 콘텐츠 착시
- **evidence_anchors 없으면**: 주장의 신뢰성 붕괴 → 원고 단계에서 확증 편향

## 사용 에이전트

| 에이전트 | 용도 |
|---------|------|
| `content-planner` | **spine 먼저 → 5레버 작성** (각 레버에 spine_link 첨부) |
