# 경로 하드코딩 반복 패턴

## 패턴
CLI 도구, 아트스타일, 이미지 출력 등의 **경로를 하드코딩**해서 환경이 바뀌면 깨지는 문제가 반복됨.

## 발생 이력
1. [[errors/아트스타일-경로-반복실패]] — 아트스타일 JSON 절대경로 하드코딩
2. [[errors/2026-03-24-auto-prompt-cli-path]] — Claude CLI `~/.local/bin/claude` 하드코딩
3. [[errors/이미지-생성-경로-버그]] — 이미지 생성 출력 경로 문제

## 방지 규칙
1. 외부 CLI: `shutil.which()` 또는 환경변수로 탐색
2. 프로젝트 내 파일: `get_workspace_dir()` / `get_data_dir()` 기준 상대경로
3. 새 경로 추가 시: 해당 경로가 다른 머신에서도 유효한지 자문
4. CLAUDE.md 규칙 7 참조: 항상 WORKSPACE_DIR vs PACKAGE_DIR 구분
