# 대시보드 안정성 패턴

## 패턴
대시보드가 파이프라인 실행 중 먹통이 되는 문제가 반복됨.

## 원인들
1. `--reload` 모드가 output/ 파일 변경을 감지해서 서버 무한 재시작
2. 좀비 프로세스가 포트를 점유

## 방지 규칙
1. 프로덕션/테스트 시 `--reload` 절대 사용 금지
2. 대시보드 시작 전 포트 점유 확인: `lsof -i :8000`
3. 에셋 변경 감지는 SSE (`sse.py`)가 담당 — uvicorn reload 불필요
4. 대시보드 시작 표준 명령:
   ```bash
   .venv/bin/python -m uvicorn app:app --host 0.0.0.0 --port 8000 --timeout-keep-alive 30
   ```
