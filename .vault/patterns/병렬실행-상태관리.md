# 병렬 실행 시 상태 분기 누락 패턴

## 패턴
`ThreadPoolExecutor`로 스텝을 병렬 실행할 때, 반환 상태(completed/skipped/failed)의 **모든 분기를 처리하지 않아** 예상치 못한 동작이 발생.

## 핵심 원인
순차 실행 경로(`_run_steps_sequential`)와 병렬 실행 경로(`_run_parallel_steps`)의 상태 처리 로직이 **동기화되지 않음**.

## 방지 규칙
1. StepResult 상태값은 반드시 **모든 경우**(completed, skipped, failed)를 명시적으로 처리
2. 새 상태값 추가 시 순차/병렬 **양쪽** 경로 모두 업데이트
3. `elif` catch-all 대신 명시적 분기 사용
