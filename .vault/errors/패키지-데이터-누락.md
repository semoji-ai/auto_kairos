# 패키지 설치 후 데이터 파일 누락

## 증상
`pip install` 후 스킬 파일, scene-editor.js, 아트스타일 등이 누락되어 파이프라인 실패.
- asset-advisory 스킬 누락 → Phase 2.5 무시
- scene-editor.js 누락 → 대시보드 Studio 탭 작동 불가
- remotion_template 렌더링 결과물(533MB) 포함 → 설치 용량 폭발

## 원인
1. `pyproject.toml`의 `package-data`에 신규 파일 미등록
2. `.gitignore`가 필요한 파일까지 제외
3. `MANIFEST.in` 미업데이트

## 해결
- pyproject.toml package-data에 누락 파일 추가
- .gitignore에서 scene-editor.js 제외 해제
- remotion_template/public/ 등 빌드 산출물 제외

## 수정 파일
- `pyproject.toml` — package-data 업데이트
- `.gitignore` — scene-editor.js 허용
- `MANIFEST.in` — include 패턴 추가
