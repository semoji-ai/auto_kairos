# 이미지 생성 경로 버그

## 증상
- placement=background인 이미지가 생성되지 않음
- 이미지 경로가 절대경로/상대경로 혼용으로 로드 실패
- import 순서 버그로 모듈 로드 실패

## 원인
1. generate_images.py에서 placement 필터 조건 오류
2. WORKSPACE_DIR vs PACKAGE_DIR 경로 혼동
3. image_generate.py에서 get_workspace_dir import 순환 참조

## 해결
- placement 필터 조건 수정
- resolveAsset() 유틸로 경로 통일
- import 순서 재배치

## 재발 방지
- [x] resolveAsset() 유틸 사용 필수화
- [ ] 경로 관련 수정 시 WORKSPACE_DIR/PACKAGE_DIR 양쪽 테스트
