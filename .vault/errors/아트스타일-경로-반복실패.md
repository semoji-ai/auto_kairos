# 아트스타일 경로 resolve 반복 실패

## 증상
"아트스타일 파일 없음: quirky_cartoon" 에러가 매번 발생.
이미지 소싱 스텝이 실패하여 수동 재실행 필요.

## 원인
config에 아트스타일이 다양한 형태로 저장됨:
- `"quirky_cartoon"` (스타일명만)
- `"artstyle/styles/quirky_cartoon.json"` (상대경로)
- 절대경로

각 모듈(runner.py, generate_images.py, project_manager.py)이 **각자 다른 방식으로 경로를 조합**하여 불일치 발생.

## 해결
`resolve_art_style_path()` 중앙 함수 도입 — 어떤 형태든 올바른 경로로 resolve.
project_manager.py, runner.py, generate_images.py 세 곳 모두 이 함수 사용.

## 근본 문제
복제(copy) 기반 아트스타일 관리 — 프로젝트마다 복사본을 만들어 경로가 분산됨.
→ 중앙 참조 방식으로 전환 필요 (아트스타일은 읽기 전용, 프로젝트별 오버라이드만 별도)
