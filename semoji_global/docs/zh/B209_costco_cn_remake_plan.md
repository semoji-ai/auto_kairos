# B209 코스트코 중국판 재구성 — 원본 분석 + 구성안 (초안 v1, 2026-10-28)

방향(사용자 결정 2026-10-28): 번역이 아니라 **중국 시청자 정서로 다시 스토리텔링**. 원본은 재료 — 살릴 건 살리고 바꿀 건 바꾼다. 영상 렌더는 mp4만.

## 1. 중국판의 축 — "한 스승, 두 제자"

원본 497~616초에 이미 들어 있는 사실이 중국판의 축이 된다.
- 월마트 창업자 샘 월튼이 솔 프라이스를 찾아와 프라이스 클럽을 벤치마킹 → **1983년 샘스클럽(山姆会员店)**
- 같은 해 9월, 솔의 30년 제자 짐 시네갈이 **코스트코** 창업
- 40년 뒤: 미국에선 코스트코가 승자, **중국에선 山姆가 67곳 vs 开市客 7곳** — 중국 시청자가 매일 보는 두 간판의 "족보"

→ 중국 시청자 질문: "山姆和开市客，原来是同一个老师教出来的？" "为什么在美国开市客赢，在中国却是山姆赢？"
→ 원본의 미국 역사가 "남의 나라 옛날 얘기"가 아니라 **지금 중국 마트 전쟁의 기원 설화**가 된다.
