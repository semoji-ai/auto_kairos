# B023·B024 맥도날드 1·2편 중국어판 「品牌百科：麦当劳（上·下）」 — 중국 관점·최근 이야기 보강안 (초안 v1, 2026-11-01)

원칙: 출처 확인된 사실만(불확실은 "据说"). 홍보성 최상급 금지("最大/最成功" 등은 출처가 그렇게 말할 때만, 그리고 "当时" 한정). 식품안전 사건(2014 上海福喜, 2026-09 北京通州 临期奶浆 举报)은 다루지 않음. 외자 대 국산 구도("中国人买下麦当劳""洋快餐输给…") 쓰지 않음 — 2017년 거래는 회사 구조 변화로만 서술. 홍콩·대만은 "中国香港""中国台湾地区"로만, 가능하면 언급 자체를 피함. 위안화 저평가(빅맥지수) 해석은 쓰지 않음.
원본은 2019년 제작. 한국 전용 내용은 1편 도입 CF송, 2편 빅맥지수 원화 환산(4,500원), "맥모닝" 명칭. 수치 최신화 + 2편 끝에 중국 이야기 삽입.

## 원고 흐름 요약
- **1편(B023, 창업~인수)**: 도입(CF송·빅맥지수·매장 수) → 1909 리처드 맥도날드 출생, 가난한 집안, "50살 전에 백만장자" → 할리우드 세트 일 → 1930 비콘 영화관, 대공황으로 1937 매각 → 몬로비아 경마장 핫도그 → 1940 샌버너디노 드라이브인(대출 5,000달러) → 카홉 문제·매출 87%가 버거·감자·음료 → 1948 3개월 휴업 후 메뉴 9개, 테니스장 분필 주방 설계, 스피디 서비스 시스템(30초·15센트) → 1952 잡지 소개, 1953 프랜차이즈 실패 → 1954 레이 크록(멀티믹서 8대 주문) → 1955 디스플레인스 1호 가맹점, QSC&V → 1.9% 로열티 구조의 한계 → 부동산(땅 매입·임대) 모델 → 1961 270만 달러에 모든 권리 인수, 형제의 백만장자 꿈 달성 → "이제 상징들이 탄생한다"로 끝.
- **2편(B024, 상징들)**: 로고 변천(1940 바비큐 → 1948 → 1953 스피디 → 1961 황금아치·짐 쉰들러 → 1968 M → 1975·1992·2000 → I'm lovin' it → 2006) → 로널드 맥도날드(윌러드 스콧, 1963, 1966 교체) → 빅맥(짐 델리게티, 1967 유니언타운, 1968 전국, 버거킹 빅킹) → 빅맥지수(1986 이코노미스트, 2019 원화 예시) → 해피밀(1977 딕 브람스, 1979 스타트렉) → 에그 맥머핀(1972 허브 피터슨) → 맥카페, 119개국 37,000곳으로 끝.

## 중국 본토 심의·정서상 피할 것
- **지역 표기**: 홍콩 1975년 첫 매장, 대만 매장 등은 넣지 않음. 부득이하면 "中国香港""中国台湾地区". 국가 열거는 "国家和地区". 지도는 국경선 있는 세계지도 대신 점 분포·대륙 실루엣(B019 지도 재작업 사례).
- **식품안전**: 2014 上海福喜(맥도날드·KFC 공급사), 2026-09 北京通州 临期奶浆 실명 举报(虎嗅) — 다루지 않음.
- **외자 대 국산**: "麦当劳卖给了中国人""麦当劳变成中国企业/加入国家队"(2017 网友 반응 중 일부)는 인용하지 않음. 俏老头 농담만. 蜜雪冰城·华莱士 등과의 매장 수 비교·순위 금지.
- **정치·환율**: 빅맥지수로 위안화 저평가를 말하지 않음(미중 환율 쟁점). 2019 홍콩 시위 관련 매장 이슈, 보이콧 사례 언급 금지.
- **최상급**: "中国最大的快餐""最成功" 금지. 王府井 "当时全世界面积最大"는 据说+当时.
- **로고·IP**: 금색 M·KFC 로고는 공식 로고 첨부로만, 지어낸 로고 금지. 麦门 표정包·연예인(陈奕迅 《麦当劳无限好》) 재현 안 함.
- **종교 비유**: 원고 B023 #98 "교회 십자가처럼 황금아치를" — 그대로 옮기면 무난하나 결말 문장에서는 "街角"으로 바꿈(위 맺음말).
