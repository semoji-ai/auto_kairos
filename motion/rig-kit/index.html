가장 짧은 사용 순서

python3 tools/build.py my_story.js my_story.html
node tools/reach.js my_story.html            # "OK"가 나올 때까지 고친다
node tools/shot.js my_story.html '[[1.6,"a.png"]]'
node tools/render.js my_story.html out.mp4 60
node tools/jumps.js my_story.html out.mp4

필요한 것은 node, playwright와 chromium, ffmpeg, python3, 그리고 한글 폰트(Noto Sans CJK KR)입니다.
