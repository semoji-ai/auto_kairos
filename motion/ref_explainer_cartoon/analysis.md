## 7. 캐릭터 연기
- **리미티드지만 화면은 매 프레임 움직인다**: 상시 푸시인 때문에 정적인 프레임이 거의 없다(측정 샷 11개 모두 29.5 draws/s). 캐릭터 그림 자체는 **포즈·표정 하드 스왑**(한 대사에 1~2회)이고 입 모양 교체 립싱크는 거의 없다. 말할 때도 입이 벌어진 채 고정된 그림이 많다.
- 부위 애니메이션은 최소다: 김 퍼프 루프(분노 머리 옆 4~6개, 8f 주기), 땀방울, 눈물 줄기. 반복 동작(먹기·빗질)은 2~3장 교대 약 8fps.
- 표정 스왑이 개그의 절정이다: 무표정 → **얼굴 절반을 차지하는 비명 입 + 빨간 혈관 이마**. 크래시 줌과 같은 프레임에서 바꾼다(jb0 0:17.8).
- 코스튬 콩트: 같은 캐스트가 주제 인물을 연기한다(사또·춘향·엉클샘·과학자).

## 8. 텍스트 강조
- 대형 단어 카드: 파스텔 바탕 중앙에 검정 명조 헤비 약 160px('사또') → 같은 자리에서 한자 '使道'로 교체 디졸브(jb0 1:21~1:22)
- 목록 줄 누적 + 파랑 키워드(위 참고), 챕터 카드 노랑 타이핑
- 속마음 잔상 텍스트: 어두운 배경에 흐린 흰 붓글씨 독백이 캐릭터 주변에 떠 있다('권위도 그다지…', 약 50% 알파, jb0 4:15)
- 모니터 차트 위 **외곽선 손글씨**(흰 글자 + 검정 외곽선) 결론을 한 줄씩 추가(jb0 2:09.7~2:15)
- 사료 인용: 청록 두루마리 안 흰 종이에 명조 5줄 + 출처 괄호(jb0 3:36)

## 9. 지도·차트·자료
- 지도: 파스텔 바탕에 회색 국토 + 해당 지역만 빨강 #D23C50(jb0 2:27). 실사 통계 지도(choropleth)는 원본 그대로 쓰고 붓 스미어로 드러낸다(OR 4:28~4:33)
- 차트: 직접 만들기보다 **모니터·화이트보드 소품 안에 넣는** 식(jb0 2:06)
- 캡처: 뉴스 기사(형광펜), 유튜브 댓글(번역 문구 포함), 책 표지·목차(참고 도서, 형광 노랑 행 하이라이트, mBh 5:36~5:48), 광고 포스터
- 실사 사진·영상: 검정 바탕 가운데(좌우 여백 약 15~20%), 느린 푸시인, 여러 장을 하드컷으로 이어 붙임. 실존 인물은 캐리커처로 그리거나(트럼프) 사진 누끼를 실사 배경에 합성(오바마 + 백악관)
- 패러디 UI: 모바일 게임 보상 팝업('5,000냥의 곡식을 받으세요 [받기]', jb0 4:57), 드레이크 밈 2단 템플릿(OR 6:45)

## 10. 오디오
- BGM 상시: 문장 사이 쉼 구간 RMS p5 -32~-38dB, 대사 중앙값 -20.6dB → **BGM은 대사보다 약 13~18dB 낮다**. -45dB 아래 무음은 2%뿐
- 효과음은 전환 시점의 고역 에너지로 구별되지 않았다(대사에 묻힘, 정량 불가). 시각적으로는 휩·팝·뚜껑 '쾅'·김 '칙' 정도가 있다고 추정

## 11. 편집 리듬

### (B) 세모지 디자인으로 옮겨 올 신규 기법 — 7개
1. **학명·원어 뜻풀이 타이틀**(`word-gloss-title`): 배경 딤 45% → 굵은 원어(라틴·한자·영문) + 단어마다 밑에 작은 한글 뜻. 세모지 버전은 종이 카드 위 검정 글자 + 세이지 뜻풀이 필.
2. **밈 템플릿 2단 비교**(`reject-approve-panels`): 2×2 칸, 왼쪽 세모지 캐릭터가 싫다/좋다 포즈, 오른쪽 대상 이미지. 실존 밈 사진은 쓰지 않음.
3. **속마음 잔상 텍스트**(`ghost-monologue-text`): 캐릭터 주변에 흐린 손글씨 독백 2~3개를 알파 40~50%로 띄우고 천천히 드리프트.
4. **챕터 범퍼**(`cast-bumper`): 7번 캐릭터 블롭 와이프 → 세모지 로고 3f 팝 → 캐스트가 로고 뒤에서 5f 솟음 → 0.6s 유지 → 와이프. 3.5s. HUD가 있는 세모지에선 챕터 카드 대신 쓰는 에피소드 구분용.
5. **뚜껑 로고 스팅**(`lid-reveal-sting`): 주제 소품(뚝배기·찜기·냄비) 뚜껑이 3f 튀어 올라 로고를 덮음 → 김 8f → 뚜껑이 빠지며 로고 공개 8f. 3.4s. 음식편 전용.
6. **브러시 스미어 리빌**(`brush-smear-reveal`): 자료 이미지(지도·표)가 굵은 붓 스트로크 마스크 2~3번으로 15f 동안 칠해지며 드러남.
7. **탈것 플라이바이 구름 와이프**(`flyby-cloud-wipe`): 캐스트를 태운 탈것이 별 섬광과 함께 가로질러 0.5s → 흰 구름(세이지 음영)이 0.4s 만에 덮고 엔드카드로.
(보류 후보: 분노 크래시 컷 = 1번 줌블러 + 적색 그라데이션 배경 + `steam` + 떨림 + 대사 자막 모드. 집중선만 빼면 A 조합으로 된다.)

### (C) 세모지 정체성과 충돌해서 비추천 — 6개
1. **검정 불투명 자막 박스**: 세모지 종이 카드 자막이 브랜드 핵심이다. 교체 금지(대사 모드만 A로 도입).
2. **만화 집중선·스피드라인 배경**(jb0 0:18): 방사 패턴이라 도감이 금지한 것(`manga-focus-lines`·`manga-speedline-rage-bg`). 대체재는 `fire-background-loop`/`GlowPulse`.
3. **모든 샷 상시 푸시인**: `camera-static-default`(샷 절반 정지, 일러스트 고정)와 정면충돌. 사진에만 `photo-slow-zoom`.
4. **실사 사진을 검정 바탕 단독 배치 + 연속 하드컷 슬라이드**: 세모지는 `blur-fill-photo`와 종이 배경 정체성을 쓴다.
5. **실사 밈 얼굴 합성·실존 인물 사진 누끼·실제 댓글 캡처**: 그림체 일관성이 깨지고 초상권·저작권 위험. 세모지는 캐리커처와 가상 UI(`chat-parody`)로 대체.
6. **웹툰 붓선 그림체·장면마다 파스텔 단색 바탕·보라 네온 크레딧 팔레트**: 디자인 요소라 가져오지 않는다.

**신규 기법 수: 7개(B)** + 옵션 확장 14개(A).
