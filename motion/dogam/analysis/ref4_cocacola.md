## 0. 채널 포맷 진화 (초기 포맷으로 판단)

이 통합편은 채널 **초기 포맷**으로 보인다. 현재 구현된 리뉴얼 HUD와 다른 점:

| 요소 | 이 영상(초기) | 기존 구현 |
|---|---|---|
| 로고 | 좌상단 정사각 스케치 초상 + 세로쓰기 '세상의 모든 지식' | 원형 로고 |
| 챕터 표시 | 상단 긴 캡슐 안 탭 5~6개, 활성 탭만 회색 #9a9a9a 채움 (하드 이동) | 진행바 활성 필 expo-out 13f |
| 챕터카드 | **흰 배경** #fbf6f3 + 작은 검정 볼드 '1. 존 펨버턴' | 크림 배경 중앙 텍스트 |
| 연도 인터스티셜 | **세이지 #c2ccc3** + 중앙 볼드 '1831년', 음절 타자(약 5f/음절) | (타자 인터스티셜 있음, 배경색 다름) |
| 자막 | 하단 전폭 반투명 흰 띠 + 검정 볼드 (동일 계열) | 동일 |
| 출처 칩 | 거의 없음 | 우하단 출처 칩 |
| 엔딩 | **후원자 크레딧 두루마리 + 군중 프레임** (세이지) | 세이지 그린 엔드카드 |

일러스트 톤은 같다(플랫 캐릭터, 파스텔 배경). 다만 초기 포맷답게 **실사 스톡·광고 영상 삽입 비중이 높다.** 크림 여백 카드 안에 영상·사료를 크로스페이드로 넣고(산타 광고 회화, 프리스타일 홍보 영상 등), 카메라 무빙보다 컷과 팝 위주로 편집했다.

## 1. 신규 기법 상세

### 1) 픽토그램 군중 행진 채움 — 00:00:01
- 세계지도(하늘색 #c1e6f5) 위로 #3a3a3a 사람 픽토그램 행이 수평 등속으로 들어온다. 행마다 방향이 번갈아 바뀌고, 약 50f 만에 4~5행이 차며, 채운 뒤에도 계속 흐른다.
- 이어서 3.7s에 검정 병 실루엣 '?'가 0.3→1.05→1.0으로 6f 팝(세로 모션블러). 말풍선 '내 라이벌?'이 블러→선명으로 따라온다.
- 쓰임: '하루 18억 명'처럼 사람 수가 큰 수치로 여는 훅.

### 2) 동심원 암흑 펄스 — 00:03:30
- 탁한 적갈색 #784646 위에서 소프트 원이 8~9f 간격으로 생성되고 약 25f 동안 화면 밖까지 번진다. 겹칠수록 중심이 #323232까지 어두워진다.
- 쓰임: '코카인!' 같은 충격 리빌 직전의 불길한 분위기.
- 방사형 **줄무늬**가 아니라 동심 원판이므로 금지 대상은 아니다.

### 3) 직전 장면 디포커스 백드롭 — 00:06:09 / 00:08:03 / 00:28:53
- 컷을 바꾸지 않고 현재 장면을 약 12~15px 블러로 8f 동안 흐린 뒤, 그 위에 새 인포그래픽 레이어를 팝한다(0.2→1.25→1.0, 6f).
- 블러 채움 사진·스포트라이트 딤과 달리 **직전 맥락을 흐린 배경으로 남긴 채 전경만 바꾸는** 레이어 전환이다.

### 4) 제품 앵커 수치 필 + 수요/공급 바 — 00:08:03
- 원액 통 팝 6f → 빨간 캡슐 #eb1029가 통 뒤에서 오른쪽으로 8f 동안 늘어남(가로 모션블러) → '284,830L' 흰 볼드 약 90px 컷인.
- 이어서 캡슐 안에 파랑 '수요량' 바가 약 20f 성장하고, 녹색 '공급량' 바는 짧게 멈춘다. 땀방울로 부족을 강조한다.

### 5) 확산 풀백 + 레이더 파문 — 00:07:53
- 약 3.0x에서 1.0x로 45f 동안 풀백하면서, 새로 화면에 들어온 주마다 아이콘이 2~3f 간격으로 팝한다.
- 풀백이 끝나면 출발지(애틀랜타)에 반투명 빨강 동심원 3겹(#d2172b)이 약 20f 주기로 호흡한다.
- 기존 '풀백 리빌'에 **아이콘 증식**과 **발원지 파문**을 더한 형태다.

### 6) 탁상달력 연도 태그 — 00:07:58, 00:12:11, 24:2x, 27:0x
- 좌상단(약 125px)에 만화 연기 퍼프가 12f 동안 번졌다 걷히면 빨간 링 바인딩 탁상달력이 나타나고, 장면이 끝날 때까지 머문다.
- 두루마리 연도 태그의 대체 스킨이다.

### 7) 매달린 아이콘 드롭 — 00:17:22
- 끈 2px + 리본 매듭에 매달린 흰 라인 아이콘이 약 10f 동안 떨어진 뒤 약 15px 오버슈트하고, 감쇠 바운스 2회로 정지한다(총 약 25f).
- 라벨은 가로선이 먼저 벌어진 뒤 텍스트가 나온다(4~5f). 두 번째 아이콘은 약 40f 뒤 같은 모션으로 이어진다.

### 8) 역순 순위 리스트 적층 — 00:17:29
- 검은 배경. 흰 캡슐 행이 하단에서 scaleY 0→1로 3f 동안 펼쳐지며 기존 행을 위로 밀어 올린다(간격 약 12f). 좌측의 완성된 랭킹과 나란히 비교된다.

### 9) 대진 배너 + 7세그 스코어보드 — 00:20:40
- 사진 하단 물결 와이프(4f) → 네이비 우주 #002442에 별 스트릭 워프(6f) → VS 배너가 1.4→1.0으로 6f 동안 떨어짐 → 양끝 엠블럼이 5f 슬라이드인 → 7세그 '0 0'이 3f 페이드업.
- 결과는 기존 '실패' 도장으로 마무리한다.

### 10) 세그먼트 온도계 배출 — 00:20:32
- 5칸 온도계가 위 칸부터 칸당 약 5f에 걸쳐 원색 → 핑크 → 흰색으로 탈색된다(총 약 40f, 계단식).
- 동시에 스프레이 노즐에서 흰 점선 호가 0→250px로 자란다. 기존 '능력치 게이지'와 달리 **감소를 계단식으로 탈색**해서 보여준다.

### 11) 연도 칩 고속 롤 + 라인업 몽타주 — 00:30:36 ~ 00:32:2x
- 네이비 칩 #18308a를 좌측에 붙여 배치(x 0~311, y 212~365, 약 312×153px). 연도가 **1프레임에 1단계씩** 하드스텝으로 롤링한다(1958→1974, 약 10f).
- 제품 PNG는 롤이 시작되는 프레임에 하드스왑하고, 맛별 색 라벨 캡슐을 붙인다. 연도마다 1~3초씩 몽타주한다.

### 12) 트월 리퀴드 전환 — 00:18:44 (북극곰 광고 구간에도 비슷한 스미어)
- 연도 텍스트 회전 -20°, 스케일 1.0→1.8, RGB 분리 약 20px(8f) → 화면 전체 트월 + 크로매틱 스미어(10f) → 다음 영상이 왜곡 상태에서 풀림(10f). 합계 약 28f.
- 기존 글리치·줌스루와 다른 **액체 소용돌이 계열**이다. 스미어가 방사형 줄무늬로 보이지 않도록 소용돌이 형태를 유지할 것.

### 13) 파스텔 그라디언트 광원 워시 — 00:19:19, 00:24:25
- 크림 #fff8d0 → 핑크 #f6c0d0 방사 그라디언트가 좌측 가장자리에서 6f 동안 번지고, 텍스트는 검정 → #e0453a로 4f 크로스페이드한다.
- 회상 퇴장형은 과노출 파스텔이 12f 동안 걷힌다. 기존 '컬러 플리커 라이트릭 19f'와 달리 **깜빡임이 없는 느린 워시**다.

### 14) 하늘 그라디언트 고도 상승 — 00:19:20
- 로켓과 구름은 거의 고정하고, 하늘만 핑크 #e8406a → 노을 → 황혼 → 딥틸 #1f4a5a로 약 30f 동안 보간해 고도가 오르는 느낌을 준다.

### 15) 눈 내림 파티클 루프 — 00:23:37
- 3개 크기 층(반지름 3/6/10px, 낙하 1.5/2.5/4px/f, 흔들림 ±8px)으로 눈이 내린다.
- 산타는 ±5° 뒤뚱 걸음으로 15f 동안 워크인한다.

### 16) 후원자 크레딧 엔딩 — 00:32:32
- 세이지 #b0bcaa. 다양한 시대·국적의 캐릭터 군중 기둥이 좌우를 채우고, 가운데 크림 두루마리(벚꽃 장식)에 후원자 이름을 3열로 적는다. 약 7초 이상 정지.

### 17) 초기 포맷 (HUD·자막·포맷)
- 위 0절의 표 참조.
