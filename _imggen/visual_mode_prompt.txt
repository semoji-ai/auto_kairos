__INPUT__ 의 씬들을 읽고 **각 씬을 무엇으로 보여줄지** 정하세요.

「자료를 구할 수 있나」가 아니라 **「이 내용을 어떻게 보여줘야 알아듣나」**를
먼저 묻습니다. 지금 찍혀 있는 `now_source`·`now_prompt`는 초안입니다. 뒤집어도 됩니다.

## 고를 수 있는 방식

| mode | 언제 |
|---|---|
| `reenact` | 사람이 무엇을 한다 · 감정이 실린 순간 · 공간의 공기가 내용이다 · 인물이 이어지는 구간 |
| `real` | 실물 자료(`real_asset`)가 있고 그것이 그 씬이 말하는 바로 그것일 때 |
| `infographic` | 아래 「인포그래픽이 이기는 자리」에 해당할 때만 |
| `collage` | 실물 사진을 오려 붙여 구성할 때 (제품 병 + 수치·풍미 요소 등) |
| `map` | 「어디」가 내용일 때 |

## ⚠️ 인포그래픽은 예외입니다

EP01에서 재분석이 35씬을 인포그래픽으로 돌렸는데, 실제로 그려서 견줘 보니
**5씬만 맞았습니다.**

| | 인포 | 씬 그림 |
|---|---|---|
| 알아듣는가 | **22** | 8 |
| 보고 싶은가 | 5 | **25** |

이해는 도해가 빠릅니다. 그런데 **보고 싶지가 않습니다.** 도해가 이어지면 사람이
사라지고, 사람이 사라지면 이야기가 아니라 발표가 됩니다.

> **둘 다 이길 때만 인포그래픽.** 하나라도 씬 그림이 나으면 씬 그림입니다.
> 이해가 조금 늦어도 사람이 남는 편이 낫습니다.

**인포그래픽이 이기는 자리**

| 이길 때 | 예 |
|---|---|
| **「없음」을 보여야 한다** | 「독립 근거가 확인되지 않았다」 — 재연으로는 그릴 수 없다 |
| 수치가 합쳐지거나 환산된다 | 2,000 + 1,800 = 3,800 |
| 둘을 견준다 | 내려놓은 것 ↔ 새로 잡은 것 |
| 구조가 바뀐다 | 기둥 둘이 빠져도 남는 것 |

첫 줄이 가장 중요합니다 — **도해만 할 수 있는 일**입니다.

숫자가 하나 나온다고 인포그래픽이 아닙니다. 「도수 43%」는 씬 그림 위에 수치를
얹으면 됩니다. **합쳐지거나 환산되거나 견주어질 때**만 도해가 이깁니다.

## collage — 실물을 오려 붙이는 자리

제품 병처럼 **실물 형태가 정확해야 하는** 오브젝트가 있고, 그 옆에 수치나 풍미
요소가 함께 놓여야 하는 화면입니다. 병 사진 한 장을 통째로 까는 것과 다릅니다.

```
「700ml, 도수 46%, 허니와 시트러스, 미묘한 스파이스가 층층이」
  → 병(실물 콜라주) + 700ml + 46% + 꿀 + 감귤 + 향신료
```

같은 병이 여러 씬에 나와도 **씬마다 함께 놓이는 요소가 달라** 화면이 반복되지
않습니다. 실물 사진을 반복해 까는 것보다 낫습니다.

## assets — 무엇을 따로 그릴 것인가

`infographic`·`collage` 로 정한 씬은 **화면에 놓을 요소를 나열**하세요.

**하나의 뜻 = 하나의 에셋.** 「844가마」는 포대 하나가 아니라 쌓인 더미 하나입니다.
낱개로 자르는 것은 낱개가 의미일 때뿐입니다.

**인물은 은유하지 말고 그 인물을 씁니다.** 집안·관계를 도형으로 바꾸면 아무도
못 알아봅니다. `cast`에 있는 인물은 캐릭터 시트를 오려 씁니다(새로 그리지 않음).

```
집안·인물·관계  →  캐릭터 시트에서 오려 씀     (assets 에 넣지 않음)
자금·기록·제품  →  사물 에셋을 그린다          (assets 에 넣음)
시간·구조·판정  →  도형과 선 — 영상이 그린다   (assets 에 넣지 않음)
```

에셋은 **넷 안팎**입니다. 다섯을 넘으면 시선이 흩어집니다.

각 에셋의 `prompt`는 **그 물건 하나**를 묘사합니다. 배경·글자·수치는 쓰지 마세요 —
배경은 크로마로 빼고 글자는 영상에서 얹습니다.

## 출력

**확인을 묻지 말고 바로 작성하세요.** 설계를 설명한 뒤 승인을 기다리면 안 됩니다.
판단이 서면 곧바로 __OUTPUT__ 에 저장하고 종료하세요.

__OUTPUT__ 에 저장하세요.

```json
{"scenes":[
  {"n":41,"mode":"collage",
   "why":"제품 사양과 풍미 요소가 병과 함께 놓여야 하는 화면",
   "assets":[
     {"id":"bottle","prompt":"클라이넬리쉬 14년 위스키 병 하나"},
     {"id":"honey","prompt":"꿀이 흘러내리는 벌집 조각 하나"},
     {"id":"citrus","prompt":"반으로 자른 감귤 하나"},
     {"id":"spice","prompt":"통후추와 계피가 한 줌 모인 더미 하나"}
   ]},
  {"n":42,"mode":"reenact","why":"인물이 이어지는 구간 — 도해가 끼면 사람이 끊긴다"}
]}
```

- 씬 전부에 대해 한 줄씩 내세요. 빠뜨리지 마세요.
- `why`는 한 문장. **왜 그 방식이 이기는지**를 적습니다.
- `assets`는 `infographic`·`collage` 에만 넣습니다.
- `id`는 영문 소문자·숫자·밑줄만.
