# scene-image

씬 이미지는 **아트스타일 텍스트 + 첨부 이미지(캐릭터 시트·베이스) + 구도 텍스트 + explainer**로 통제 생성한다.

> ⚠️ **콘티 스케치는 씬 이미지 생성에 첨부하지 않는다.** 콘티의 인물 figure가 캐릭터 비율을 끌어당겨 드리프트시킴(실증: 콘티 O → 비율 깨짐 / 콘티 X → 시트 비율 유지). **구도·앵글·포즈는 텍스트로 기술한다.** 콘티(스토리보드)는 Seedance 비디오 생성 전용으로만 사용.

## 공통 4요소
1. **아트스타일 텍스트** — `data/artstyle/semoji.md` 전문. 반드시 포함(이미지 전체 그림체). **단, 비율 수치는 넣지 않음** — 비율은 첨부 이미지가 정함.
2. **첨부 이미지** — codex `-i` (아래 분기 참조).
3. **구도 텍스트** — 장면 설명: 인물 위치·동작, 사물·배경 배치, 카메라(와이드/클로즈 등).
4. **explainer** — 첨부 이미지가 각각 무엇이고 어떻게 쓰는지 명시.

## 분기 — 캐릭터 유무

### A. 캐릭터가 있는 씬
**첨부**: `-i <char_ref.png>` (기준 캐릭터 시트) + `-i data/artstyle/semoji_base.jpg`
- explainer:
  - "1번 캐릭터 시트의 인물을 **그대로 사용** — 신체 비율·체형·등신·얼굴·헤어·의상을 **100% 동일하게**, 비율을 바꾸거나 새로 디자인하지 말 것."
  - "2번 세모지 베이스 = 이미지 전체의 그림체·색감 기준(인물 정체성 복사 금지)."
- 구도·동작은 텍스트로.

### B. 캐릭터가 없는 씬
**첨부**: `-i data/artstyle/semoji_base.jpg` (아트스타일 참고용만)
- explainer **필수**:
  - "첨부 이미지는 **그림체·색감 참고용**이다 — **베이스의 인물(사람)은 사용하거나 포함하지 말 것.** 이 장면에는 인물이 등장하지 않는다."
- 사물·배경·다이어그램 등 장면 요소만 텍스트로.

## 호출 형태
```bash
# A. 캐릭터 씬
printf '%s' "$ARTSTYLE_TEXT

$SCENE_PROMPT   # 구도·동작 텍스트

$EXPLAINER      # 1번 캐릭터 그대로 / 2번 베이스 그림체

aspect ratio 16:9. 글자/말풍선/로고 없음." \
  | codex exec --skip-git-repo-check -s workspace-write \
      -i <char_ref.png> -i data/artstyle/semoji_base.jpg -

# B. 무캐릭터 씬 — 베이스만, 인물 사용 금지 explainer
```

## 비율 일관성 (핵심)
- **비율을 텍스트로 지시하지 말 것** — 캐릭터 시트·베이스가 비율을 정함. 텍스트 수치 락은 인물을 새로 그려 깨뜨림(실증).
- **콘티를 첨부하지 말 것** — 콘티 인물이 비율을 끌어당김(실증).
- 인물 전신이 거의 다 보이게 — 비율 판단을 위해.

## codex 주의
- **깨끗한 cwd에서 생성** — cwd에 같은 이름 파일 있으면 codex가 새로 그리지 않고 복사함(실증, md5 동일).

## 파이프라인 위치
원고 → 기준 캐릭터([[character-sheet]]) → **scene-image(아트스타일+캐릭터+베이스+구도텍스트 → 씬)** → 씬 레이어 분리 → AE

## 용어 정리
- **스토리보드(콘티)** = 흑백 스케치, 구도/샷 설계 — **Seedance 비디오 생성 전용**(씬 이미지엔 미사용).
- **기준 캐릭터** = 인물 외형·비율 단일 소스([[character-sheet]], 베이스 리스타일).
- **세모지 베이스** = 그림체·비율 그라운드 트루스.
- **씬 이미지** = 위 요소로 생성된 결과(영상/AE용).
- **에셋 이미지** = 씬에서 분리한 요소 레이어.
