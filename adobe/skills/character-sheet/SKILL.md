# character-sheet

캐릭터 시트는 이후 씬 생성의 **인물·스타일 단일 소스**다.

## 방식 — 베이스 캐릭터 리스타일 (확정·실증)
**세모지 베이스 캐릭터(`data/artstyle/semoji_base.jpg`)를 `-i`로 첨부하고, "1번 이미지의 캐릭터를 OO로 변경해서 그려줘" 형태로 리스타일한다.** 베이스를 최소 편집하므로 비율·체형·얼굴 구조·그림체가 그대로 보존된다.

> ⚠️ **비율을 텍스트로 지시하지 말 것.** "5.5등신"·"3등신·머리 1/3" 같은 수치 락을 넣으면 codex가 인물을 새로 그려 비율·정체성이 깨진다(실증: 수치 락 → 머리 너무 큼 / 마른 성인으로 드리프트). **비율은 오직 첨부한 베이스 이미지가 정한다.**

## 프롬프트 템플릿
**첨부**: `-i data/artstyle/semoji_base.jpg` (필수)
```
첨부된 1번 이미지의 캐릭터를 '<이름>'(이)라는 캐릭터로 변경해서 새로 그려줘.
- 신체 비율·체형·얼굴 구조·그림체·포즈·배경은 1번 이미지 그대로 유지.
- 헤어와 의상만 <이름>(으)로 변경: <헤어 묘사>, <의상 묘사>, <표정>.
글자·로고 없음. ./char_<이름>.png 로 저장.
```

## 출력
- PNG, 캐릭터별 `char_<name>.png`. 단일 인물·전신·격리 피사체, 글자·로고 없음.
- 정사각/세로가 필요하면 캔버스(aspect ratio)만 프롬프트에 추가. (베이스가 가로라 미지정 시 16:9로 나옴)
- 이 시트 = 이후 [[scene-image]]가 `-i`로 첨부하는 인물·스타일 단일 소스.

## 주의 (codex 동작)
- **깨끗한 cwd에서 생성**할 것. cwd에 같은 인물 파일이 이미 있으면 codex가 새로 그리지 않고 **기존 파일을 복사**해 버린다(실증: md5 동일).

## 파이프라인 위치
원고 → 캐릭터 추출(roster.json) → **character-sheet(베이스 리스타일 → 인물 시트)** → [[scene-image]] → 씬 레이어 분리 → AE

## 핵심 원칙
- 비율·그림체·얼굴 구조 = **베이스 이미지**가 단일 소스. 텍스트는 헤어·의상·정체성만 바꾼다.
- 세모지 베이스 = 모든 캐릭터의 출발점. 항상 첨부.
