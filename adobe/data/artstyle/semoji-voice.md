# 세모지 원고 문체 가이드 (텍스트 전용 — 이미지 스타일은 semoji.md 별도)

출처: 세모지 실제 원고 코퍼스 train 47편 실측(semoji-voice-bands.json) + kairos-vault validated 노트 5종 교차검증.
수치는 전부 코퍼스 실측 — 손으로 적은 값 없음. 검증 게이트가 같은 밴드로 채점한다.

## 눈높이·흐름 (최우선 — 아래 모든 규칙보다 앞선다)
- **중학생이 한 번 듣고 이해되는 문장**. 쉬운 일상 어휘만 — "서면 보증"→"약속을 적은 종이", "이견으로 결정이 미뤄졌습니다"→"의견이 갈려서 결정이 늦어졌습니다" 식으로 풀어쓴다.
- **한 문장 = 정보 1개.** 숫자·사실을 쉼표로 몰아 넣지 않는다. 숫자 연타 뒤에는 반드시 의미 부여 문장("이게 얼마나 대단한 기록이냐면…")이 온다.
- **시간 순서를 지킨다.** 과거로 역행하는 삽입("2007년까지 패배 4번" 식)은 금지 — 이야기 흐름대로.
- 문장 사이는 접속·지시("그래서", "이때", "그 순간")로 이어 붙여 **뚝뚝 끊기지 않게**.
- 어미·수치 규칙을 맞추려고 **억지 문장을 만들지 않는다** — 구어체는 시청자 공감 지점에서만 자연스럽게.

## 어미 체계 (가장 중요 — 게이트 하드 체크)
- 기본 존댓말: **"~습니다/입니다/합니다"** — 문장 종결의 45~93%(중앙값 61%)를 차지. 팩트 전달은 이 어미.
- 구어체 혼용: **"~거죠/~이죠/~잖아요/~거든요/~는데요/~까요"** — 종결의 0~32%(중앙값 17%). 공감·환기 지점에.
- 전달체: 간접 사실은 **"~다고 합니다/~했다고 합니다"** — 1000자당 약 1회(상위 문서 2.7회).
- **평서체("~했다/됐다/이다") 종결 금지** — 실측 0.4%, 사실상 0. 한 문장도 쓰지 않는다.

## 리듬
- 숫자·팩트 → 짧은 문장 2~3연타 → 의미 부여 문장 1개.
- 1문장 = 나레이션 1호흡. 긴 문장은 줄바꿈으로 분리 — 줄 길이는 평균 17~31자, **길이 변화가 커야 함**(단조로운 균일 길이 금지 — 게이트가 하한선으로 탈락시킴).
- "하지만" 역전: 1000자당 0.5~2회. 긍정 서술 → "하지만" → 장애물 → 극복.
- "그런데" 단독 행 반전: 집중도 리셋용. 원고당 0~2회(필수 아님 — 반전 지점이 있을 때만).
- 핵심 순간 인물 대사 직접 인용(따옴표): 1000자당 0~2회.
- 강조어 "바로/무려/그야말로": 1000자당 0.8~3회.

## 구조
- 도입부 30초 이내(3~5문장): 시사연결 / 뉴스팩트충격 / 질문던지기 중 택1
  → "그런데" 또는 질문으로 전환 → **`(타이틀)` 마커 1회** → 본론.
- 챕터 `번호. 제목` 형식: 인물·브랜드 장편 5~7개, 지식 단편 0~3개(분량에 비례).
- 1문단 = 2~5문장, 문단 사이 빈 줄(나레이션 호흡). 핵심 문장은 단독 행.

## 용어 — 직역 금지, 분야 통용어 우선
외국어 자료의 용어를 옮길 때 반드시 3단으로 판단한다:
1. **그 분야에서 실제로 쓰는 한국어 용어가 있으면 그것을 쓴다** — trial→"입단 테스트"(시험 X), penalty shootout→"승부차기", loan→"임대 이적", cap→"국가대표 경기 출전".
2. 통용어가 외래어라면 **외래어 그대로** — "발롱도르", "해트트릭", "프리킥"을 억지로 한국어로 풀지 않는다.
3. 위 둘 다 아닐 때만 풀어 쓴다 — 이때도 단어 대 단어 직역이 아니라 **뜻을 한국어 어법으로** 옮긴다.
판단 기준: "그 분야를 아는 사람이 이 문장을 들으면 자연스러운가?" 어색하면 직역이 샌 것이다.
- 숫자는 **아라비아 숫자**(1954년, 4,040톤) — 실측 1000자당 15~80자가 숫자. "이천이십이년" 같은 한글 수사 금지.
- 일본어 가나·한자 금지. 외래어는 한글 표기 또는 영어.
