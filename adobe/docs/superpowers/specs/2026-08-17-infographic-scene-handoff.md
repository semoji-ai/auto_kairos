# 인포그래픽 씬 — 만드는 순서를 바꿨다

> v3에서 씬 분석 방식을 뒤집었다. 그 결과를 AE 쪽에서 받아 쓸 수 있게 정리한다.
> 시제품 결과 — `~/LocalProjects/auto_kairos_v3/_imggen/ep01_info/`

---

## 1. 무엇을 바꿨나 — 결정 순서를 뒤집었다

전에는 **자산을 어떻게 구할까**를 먼저 물었다.

```
❌  source(search / generate / map) → 레이아웃 → 그림
```

「어떻게 구할까」는 조달 문제인데 그게 맨 앞에 있어서, 조달하기 쉬운 쪽으로
쏠렸다. 실측으로 **12편 780씬 중 533씬(68%)이 「그림 한 장」**이었고
지도는 7씬, 차트는 8씬뿐이었다.

이제는 **어떻게 보여줄까**를 먼저 묻는다.

```
✅  visualMode → 조달 방법 → 레이아웃
```

EP01 68씬을 다시 분류하니 이렇게 갈렸다.

| 모드 | 씬 | 뜻 |
|---|---:|---|
| `infographic` | 35 | 관계·구조·인과. 사람 얼굴로는 안 보이는 것 |
| `reenact` | 21 | 사건·행동·순간이 있다 |
| `document` | 7 | 실물 기록 자체가 의미 |
| `map` | 3 | 지리적 이동 |
| `collage` | 2 | 실물 여러 점을 모아야 하는 것 |

68씬 중 47씬이 바뀌었다. 특히 시청자가 지루하다고 지적한 구간(검증 43~47,
혼맥·역할 52~59)이 통째로 인포그래픽으로 갈아탔다.

## 2. 인포그래픽은 요소를 **따로** 그린다

재연 씬과 파이프라인이 다르다.

```
reenact       한 장 생성 → 무엇을 뗄지 선별 → layerize 분리 → 배치
infographic   요소별 생성 (배경 없는 PNG) → 분리 없음 → 배치
```

**가장 무겁고 불안한 단계(레이어 분리)가 통째로 빠진다.**

씬 명세에 `assets`와 `composition`이 실린다.

```json
{
  "visualMode": "infographic",
  "assets": [
    {"id": "father_fund",   "prompt": "흰 한지로 싼 큰 돈뭉치", "role": "source"},
    {"id": "capital_chest", "prompt": "열린 소형 목제 금고",     "role": "sum"},
    {"id": "rice_pile",     "prompt": "쌀가마가 층층이 쌓인 더미", "role": "scale"}
  ],
  "composition": {"form": "sum_then_scale",
                  "note": "두 돈뭉치를 금고로 합친 뒤 쌀 더미로 환산한다"},
  "labels": ["아버지 2,000원", "구철회 1,800원", "합계 3,800원", "쌀 약 844가마"]
}
```

`form`은 배치의 **성격**이지 고정 틀이 아니다. `branching` / `stack` / `orbit` /
`scale_compare` / `flow` / `sum_then_scale` … 필요하면 새로 지어도 된다.
**비교라고 반드시 좌우 이분할일 필요 없고, 요소가 둘일 필요도 없다.**

## 3. 에셋을 어떻게 자르느냐가 절반이다

시험에서 두 번 틀렸고 둘 다 배치로는 복구되지 않았다.

**① 하나의 뜻 = 하나의 에셋**

「쌀 약 844가마」에 포대 **한 개**를 만들어 화면에 세 번 얹었더니 「많다」가 아니라
「세 개」로 읽혔다. 처음부터 **쌓인 더미 하나**로 그렸어야 한다.

낱개로 자르는 것은 낱개가 의미일 때뿐이다 — 「3대에 걸쳐」는 인장 셋이 하나씩
찍히는 것이 뜻이므로 낱개가 맞다.

**② 인물은 은유하지 말고 그 인물을 쓴다**

「구씨 집안」을 짙은 금색 레일, 「허씨 집안」을 옅은 금색 레일로 그렸더니
구분도 안 되고 **왜 레일인지 이해되지 않았다.** 캐릭터 시트에서 정면 전신을
오려 쓰니 바로 읽혔다. 시청자가 앞 씬에서 이미 본 얼굴이다.

```
집안·인물·관계  →  캐릭터 시트에서 오려 쓴다 (새로 그리지 않는다)
자금·기록·제품  →  사물 에셋을 그린다
시간·구조·판정  →  도형과 선 — 이미지로 만들지 않고 AE가 그린다
```

시트 배경이 `#F9F8F5`라 색으로 지우면 알파가 바로 나온다.

**③ 은유는 시청자가 즉시 아는 것만**

돈뭉치·쌀가마·빈 서류칸·저울은 통한다. 레일·게이트·인장은 설명을 들어야
아는 은유라 실패했다. **추상 개념은 사물로 바꾸지 말고 「관계」로 보여준다** —
「인화」는 레일이 아니라 **두 사람과 그 사이의 선**이다.

**④ 한 화면에 요소는 넷 이하.** 다섯을 넘으면 배치가 성기고 시선이 흩어진다.

## 4. 만드는 법 — 크로마로 뽑고 알파를 만든다

gpt-image-2는 투명 배경을 못 낸다. 균일한 크로마 배경으로 뽑고 잘라 낸다.

```
크로마          #12FF6A  (세모지 팔레트에 없는 색이라 잔상이 안 남는다)
잘라 내기       remove_chroma_key.py --tolerance 70 --soft-matte --despill --spill-cleanup
결과            투명 픽셀 64%, 가장자리 반투명 1,578px — 후처리 없이 바로 쓸 수 있다
```

프롬프트에서 **반드시 걷어낼 세 가지**가 있다. 씬 분석이 내는 문구에 섞여 온다.

| 걷어낼 것 | 왜 |
|---|---|
| 「투명 배경」 | 크로마 지시와 충돌한다 |
| 「문자 없음」 | 부정문은 그 단어를 오히려 렌더한다 |
| 「세모지 3D 화풍」 | 화풍을 이름으로 부르면 첨부한 그림을 제쳐 두고 재해석한다 |

대신 「모든 면을 매끈한 빈 색면으로 남긴다」를 쓴다. **글자는 그리지 않는다** —
라벨은 AE 텍스트 레이어가 얹는다.

## 5. 화면 규격

| 항목 | 값 |
|---|---|
| 배경 | `background/약설_그리드 배경.jpg` (밝은 그리드) |
| 폰트 | **배달의민족 연성체** (`BMYeongSung-Regular.otf`) |
| 잉크 | `#2D3440` · 강조 `#C4783C` · 보조 `#78808C` |
| 요소 그림자 | **feather 30, y+14, 불투명도 88** |

검정 배경에서는 오브젝트가 공중에 뜬 느낌이었다. 밝은 그리드로 바꾸니 **종이 위에
놓인 것처럼** 읽힌다. 대신 흰 오브젝트가 배경에 묻히므로 그림자가 필수다.

연성체는 손글씨 느낌이라 딱딱한 도표가 아니라 **설명하는 화면**이 된다.

「그런데」·「하지만」·「그때」처럼 이야기가 꺾이는 자리는 **흰 배경에 연성체
타이핑**으로 짧게 끊고 다음 장면으로 넘어간다.

EP01에 13곳이 있었다 (그런데 8 · 하지만 4 · 다만 1). 전부 실제로 이야기가
꺾이는 지점이었다 — 「하지만 홍수는 달랐습니다」, 「그런데 구인회는 정반대로
움직였습니다」.

```
배경  #FCFCFA
글자  연성체, #262C38
커서  #C4783C, 깜빡임
```

## 7. AE 쪽에서 받을 것

인포그래픽 씬은 **레이어 분리가 필요 없다.** 요소가 이미 낱장 알파 PNG다.
그래서 `analyze_scene_layers` → `layerize` 경로를 건너뛰고 바로 배치로 간다.

```
씬 매니페스트
  visualMode: "infographic"
  layers: [{name, path(알파 PNG 또는 SVG), kind: "element"}]
  labels: [텍스트 레이어로 얹을 것]
  composition.form / note   ← 배치와 등장 순서의 근거
  camera                     ← 별도 문서(카메라 인수인계) 참조
```

**요소 등장은 카메라의 `reveals`와 같은 얼개**로 다루면 된다. 나레이션 큐 시각에
맞춰 `fade` / `rise` / `pop`으로 하나씩 나타난다.

배치 좌표는 아직 사람이 정한다. v3 시제품은 파이썬으로 손배치했고, 그 화면이
`_imggen/ep01_info/compose_014b.png` · `compose_057b.png`에 있다. **패널에서
`form`을 보고 배치 틀을 제안하는 것**이 다음 단계로 자연스럽다.
